# 新电脑首次启动与验证流程

## 1. 启动前

1. 确认项目与交接目录都已完整复制到本机固定磁盘。
2. 安装 Unity `2022.3.62f3c1` 并激活许可证。
3. 打开终端进入项目根目录。
4. 执行：

```powershell
git rev-parse HEAD
git branch --show-current
git status -sb
```

预期 HEAD、分支和工作区状态见 [02_仓库状态与迁移验收.md](02_仓库状态与迁移验收.md)。

## 2. Unity Hub 导入

1. 打开 Unity Hub。
2. 选择“添加/从磁盘添加项目”。
3. 指向 `MandateOfHeroes` 根目录，而不是 `Assets` 或 `Builds`。
4. 选择精确 Editor `2022.3.62f3c1`。
5. 等待 Package Manager 和 `Library` 重建完成。

首次导入可能较慢。只要 Unity 仍在导入且 Console 没有持续新增错误，不要强制结束进程。

## 3. 场景入口

| 用途 | 场景 |
|---|---|
| 普通可玩入口 | `Assets/Scenes/PlayableDemo.unity` |
| 开发观察台 | `Assets/Scenes/SimulationDashboard.unity` |
| 地图验证 | `Assets/Scenes/MapValidation.unity` |
| 洛阳统一世界验证 | `Assets/Scenes/LuoyangWorldValidation.unity` |
| 全国自然底图 | `Assets/Scenes/HanWorldNaturalBasemap.unity` |
| 当前 Style D 审图 | `Assets/Scenes/HanWorldArtDirectionLab.unity` |

Build Settings 当前默认第一个场景是 `PlayableDemo.unity`。

## 4. 首轮人工检查

1. 打开 `PlayableDemo.unity`，确认 Console 没有编译错误。
2. 点击 Play，确认可以进入主菜单或角色入口。
3. 退出 Play Mode。
4. 打开 `HanWorldArtDirectionLab.unity`，检查 Style D 世界、区域、城市距离、河流、森林和平原视角。
5. 当前 Style D 状态只是 `READY_FOR_USER_REVIEW`，不能因场景能运行就写成最终 Golden。

## 5. 受控自动验证

运行批处理验证前必须关闭 Unity Editor；已有 Editor 打开时，测试应报告 `blocked`，不得擅自关闭。

先执行项目加载烟雾：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File `
  Tools/Run-UnityTestsSafe.ps1 `
  -Mode ProjectLoadSmoke `
  -TimeoutSeconds 120
```

再执行一个 Style D EditMode 精确测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File `
  Tools/Run-UnityTestsSafe.ps1 `
  -Mode EditModeTests `
  -TestFilter Mandate.Tests.StyleDStrategicLandscapeV2Tests.StyleDV2_ProfileAndRequiredCamerasAreFrozen `
  -TimeoutSeconds 120
```

结果必须同时具备安全 Runner 汇总、Unity 日志和有效 NUnit XML，不能仅凭进程退出判断通过。

纯文档检查入口：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File `
  .codex/skills/mandate-unity-development/scripts/verify-project.ps1 `
  -DocumentationOnly
```

完整代码验收顺序是：全工程编译 → 核心测试 → 受控 Unity 测试 → `git diff --check` → 差异审阅。
完整 Core/EditMode 套件需要使用项目 Skill 的分组 Runner；不要用一个无边界进程跑完所有测试。

## 6. 常见问题

### Unity 显示 No cameras rendering

可能打开了验证场景但没有运行控制器，或场景加载/编译尚未完成。先看 Console，确认打开的是正确
场景，再点击 Play。不要据此删除场景或摄像机。

### 批处理没有日志

使用 `Tools/Run-UnityTestsSafe.ps1`，先确认 Hub/许可证环境与 Unity 路径；不要直接无限等待
`Unity.exe -batchmode`。所有外部工具默认 300 秒硬超时。

### 项目锁冲突

关闭手动打开的 Unity Editor 后再跑批处理测试。测试工具不得擅自关闭用户程序。

### Package 恢复失败

先确认网络和 Unity 登录；保留 `Packages/manifest.json` 与 `packages-lock.json`，不要删改版本来绕过问题。

### QGIS 脚本找不到 Python/GDAL

必须通过 `MapPipeline/scripts/Invoke-QgisPython.ps1` 启动，不要直接使用系统 Python。
