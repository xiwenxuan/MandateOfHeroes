# 新电脑环境依赖与安装清单

## 1. Unity 开发必需环境

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10/11 x64 | 当前工具链和路径按 Windows 验证 |
| Unity Hub | 当前稳定版 | 用于安装和登记 Editor、管理 Personal 许可证 |
| Unity Editor | `2022.3.62f3c1` | `ProjectSettings/ProjectVersion.txt` 的精确版本 |
| Git | Git for Windows | 必须保留现有 `.git`；不要只重新克隆远端 |
| IDE | Visual Studio 2022 或 Rider | `.vsconfig` 要求 `Microsoft.VisualStudio.Workload.ManagedGame` |
| PowerShell | Windows PowerShell 5.1；PowerShell 7 推荐 | 项目验证、地图和安全 Unity Runner 使用 |

Unity Packages 由 `Packages/manifest.json` 和 `Packages/packages-lock.json` 管理。首次打开时让
Unity Package Manager 正常恢复，不要手工复制旧电脑的 `Library/PackageCache`。

## 2. Unity Hub 与许可证

1. 登录 Unity Hub。
2. 在“许可证/Manage licenses”中确认 Personal 许可证有效。
3. 安装 `2022.3.62f3c1`；若 Hub 没有直接显示该补丁版，使用项目要求的归档安装入口。
4. 建议安装 Windows Build Support；Android、WebGL 等模块只有需要对应构建时再安装。
5. 将项目目录通过 Hub 的“添加/从磁盘添加项目”导入。

## 3. GIS / 地图流水线依赖

只打开 Unity、运行现有地图或继续普通 C# 开发时，不需要重新生成 GIS 数据。
需要重建全国格网、DEM、河流、区域边界或地图审计数据时，再安装 QGIS。

当前已验证基线：

| 组件 | 当前验证版本 |
|---|---|
| QGIS | `3.44.12` |
| QGIS bundled Python | `3.12.13` |
| GDAL | `3.13.1` |
| PROJ | `9.x` |
| GeoPandas | `1.1.3` |
| Shapely | `2.1.2` |
| PyProj | `3.7.2` |
| NumPy | `2.4.6` |
| Matplotlib | `3.10.9` |
| SciPy | `1.17.1` |

正式入口是：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File `
  MapPipeline/scripts/Invoke-QgisPython.ps1 `
  MapPipeline/scripts/audit_environment.py
```

该脚本从 `C:\Program Files\QGIS *` 选择最新安装，并设置 QGIS 自带 Python、GDAL、PROJ 和
Matplotlib 环境。项目明确不要求 Rasterio；栅格工作使用 `osgeo.gdal`。

部分历史资料脚本还会按需使用 `openpyxl`、Pillow 或 `psutil`。先运行环境审计或目标任务的
验证脚本，只有报告缺失时才在 QGIS 隔离环境中补装；不要污染系统 Python。

## 4. Node 与工作簿生成

`MapPipeline/scripts/*.mjs` 中的工作簿脚本使用 Codex 工作区提供的 Spreadsheet Artifact Tool，
通过以下环境变量定位：

```text
MANDATE_ARTIFACT_TOOL_ENTRY
MANDATE_REPO_ROOT
```

它不是普通的 `npm install` 项目，仓库中没有独立 `package.json`。只运行 Unity 游戏不需要 Node。
在新电脑用 Codex 重新生成工作簿时，应先让 Codex 加载 workspace dependencies，再执行对应任务脚本。

## 5. 可选工具

- GitHub CLI：用于认证、推送和仓库检查；不是本地运行 Unity 的前置条件。
- Git LFS：当前 `.gitattributes` 没有 LFS 跟踪规则，现有文件不依赖 LFS；可安装但不是恢复前置。
- QGIS Desktop：用于人工查看和审计 GIS 数据。
- Microsoft Excel / LibreOffice：查看工作簿；生成和验证仍以项目脚本为准。

## 6. 不应迁移的机器缓存

以下目录由工具重新生成，迁移时已排除：

```text
Library/
Temp/
Logs/
obj/
bin/
根目录 tmp/
根目录 outputs/
.codex-docx-qa/
```

`Docs/HISTORICAL_WORLD_REFERENCE/**/outputs/` 属于正式交付证据，已经保留，不能按名称一概删除。
