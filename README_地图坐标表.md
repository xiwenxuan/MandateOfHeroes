# 地图坐标与对象锚点表模板

## 项目说明

`deliverables/02_地图坐标与对象锚点表.xlsx` 是统一世界地图系统的空白正式录入模板，用于管理世界坐标、固定地理、地点、路径、LOD、建筑、动态状态、美术资产和跨层级连续性验收。

核心原则：所有地图层级表现同一个世界。缩放只增加细节和改变表现，不重新生成另一套城市、道路、河流、建筑或所有权事实。

## 依赖安装

需要 Python 3.11 或更高版本及 `openpyxl`：

```powershell
python -m pip install openpyxl
```

项目受控环境应优先使用已配置的 Python 与依赖，不要为生成模板引入在线 API。

## 文件生成方式

在仓库根目录执行：

```powershell
python scripts/generate_map_anchor_template.py
```

脚本会覆盖同名输出文件，并在终端打印结构、命名区域、公式、数据验证、宏和外部链接检查结果。任一硬检查失败时返回非零退出码。

## 工作簿结构

工作簿按固定顺序包含：

1. `00_使用说明`
2. `01_世界设置`
3. `02_固定地理`
4. `03_地点锚点`
5. `04_路径网络`
6. `05_层级表现LOD`
7. `06_建筑锚点`
8. `07_动态状态`
9. `08_资产清单`
10. `09_连续性验收`
11. `10_数据字典`（普通隐藏，可取消隐藏）
12. `11_校验结果`

业务表预留 500 行表格、数据验证和条件格式。除任务书允许的标准状态字典外，不预填历史地点、道路、河流、建筑或资产。

## 世界坐标规则

- 世界逻辑坐标是所有地图层级共享的权威位置。
- 地图局部坐标只描述某个区域或层级内部的位置。
- 图片像素坐标由世界坐标和画布尺寸换算得到。
- 建筑院落局部坐标用于建筑内部或院落空间。
- 空白表示尚未录入，不能当作零坐标。
- PSB、PNG、程序与数据文件通过稳定对象 ID 关联。

换算示例位于 `01_世界设置`：

```text
母版像素X = 世界X ÷ 世界逻辑宽度 × 母版画布宽度
母版像素Y = 世界Y ÷ 世界逻辑高度 × 母版画布高度
```

预览图换算使用相同规则和预览画布尺寸。

## 如何修改世界尺寸

在 `01_世界设置` 修改世界逻辑宽度、世界逻辑高度、母版尺寸或预览尺寸。其他公式通过命名区域引用这些单元格。世界尺寸进入正式使用后属于兼容合同，修改前必须评估已有坐标、路径、资产锚点和存档数据的迁移。

不要直接删除或重命名 `WorldWidth`、`WorldHeight`、`MasterWidthPx`、`MasterHeightPx`、`PreviewWidthPx`、`PreviewHeightPx` 和 `CoordinateDecimals` 命名区域。

## 如何增加数据字典

取消隐藏 `10_数据字典`，在对应分类的连续区域中增加值，然后扩展该分类的命名区域。新增开放内容应使用稳定命名空间 ID 或字典数据，不要在业务表的数据验证中重复硬编码。

如果通过脚本长期维护字典，应同时修改脚本顶部 `DICT` 和 `DICT_NAMES`，重新生成后检查所有数据验证引用。

## 如何保留已录入数据

生成脚本会覆盖输出文件。正式数据录入后应：

1. 先复制工作簿到版本化备份位置；
2. 保存当前模板版本和修改日期；
3. 修改字段或字典时编写迁移脚本；
4. 通过对象 ID 合并数据，不按行号或中文名称覆盖；
5. 迁移后重新检查引用、坐标范围和连续性。

不要直接用新空白模板覆盖唯一的正式数据文件。

## 如何重新生成模板

确认输出工作簿没有未备份数据后，重新执行：

```powershell
python scripts/generate_map_anchor_template.py
```

脚本具有确定性并覆盖同名文件。若模板已进入多人协作，应先合并脚本和字典修改，再由指定维护者生成正式版本。

## 如何进行质量检查

生成脚本会用 `openpyxl.load_workbook()` 重新打开、往返保存并检查：

- 12 个工作表及固定顺序；
- Excel 表格、冻结窗格和筛选；
- 数据验证和命名区域；
- 坐标换算、坐标偏差及校验汇总公式；
- 无外部链接、无宏；
- 正式业务表没有误填示例数据。

打开工作簿后还应人工检查：中文字体、列宽、筛选、下拉菜单、打印页眉页脚，以及 Excel/WPS/LibreOffice 是否无修复提示。

## 常见问题

### 为什么下一层地图不能重新摆放城市？

因为所有尺度读取同一世界对象。下一层只能增加轮廓、街区和交互细节，不能改变世界坐标或生成另一套拓扑。

### 为什么下拉框不能直接写新值？

字典必须集中维护，避免同义词、错别字和无法迁移的枚举扩散。先登记字典，再使用下拉值。

### 为什么空白坐标不显示为零？

零是合法坐标。模板公式使用空值保护，避免把“尚未录入”误判为世界原点。

### 为什么校验结果没有立即更新？

工作簿设为自动重算。若所用软件未自动计算公式，请执行一次完整重算后保存。

### 可以把地图图片直接当作世界事实吗？

不可以。图片是表现资产；设施、道路、所有权、状态、库存和情报必须来自正式数据和世界存档。
