# M25-P11 任务书：正式公共粮食税粮、汇缴与赈济命令

## 一、任务定位

在 M25-P3 正式食品运行闭环、M25-P7 持久命令合同和 M25-P10 家庭食品月结命令之上，把“家庭税粮—村仓留存—县仓汇缴—县仓赈济”迁移为按县执行的 V33 持久命令与显式事务。

本阶段只迁移正式食品权威世界中的公共粮食链。`VillageLifeSystem.ResolveMonthly` 与 `CountyGovernanceSystem.ResolveMonthly` 继续保留完整直接兼容语义；正式 `WorldSimulator` 使用命令路径，并让其余村庄、县治理步骤跳过已经提交的税粮、汇缴和赈济写入。

## 二、实现合同

### 2.1 有界工作发现

- 仅在 `FormalProductBatches` 世界、30 日月界、县治理尚未完成当日结算时发现工作。
- 每个有下辖村庄且存在年度税粮或赈济压力的县建立一张稳定命令；不扫描永久人物全表。
- 年度税粮只在第十月处理；赈济压力来自已提交的村庄食品安全摘要和正式县市场压力。
- 非月界、无下辖村庄、无税粮家庭且无赈济压力、县已结算或已有同县同日命令时不创建空命令。

### 2.2 公共粮食事务

- 第十月按村庄稳定顺序评估家庭税粮，使用家庭粮仓正式批次向村公共粮仓转移；欠税和村庄税粮累计只记录实际结果。
- 村庄按县配置保留地方份额，其余仅从当日 `FoodTaxTransferred` 流水汇缴至县仓，不得把历史库存重复视为新税粮。
- 县仓按村庄食品安全与市场压力发放赈济，继续使用正式容器转移，保留产品、品质、来源、批次与逐产品守恒。
- 县财政和村庄流水继续提供可追溯证据；兼容标量在正式权威模式下保持为零，不成为库存权威。

### 2.3 命令、验证与事件

- 命令保存 `expected_day` 和 `county_governance_id`；命令、事务和事件 ID 由绝对日与县治理稳定 ID 派生。
- 事务预检正式食品权威、内容引用、月界、县治理到期状态、下辖村庄当日结算状态和同县同日共享预留。
- 日期漂移、县已结算、村庄尚未完成当日结算或引用失效时，在任何库存、税账、流水和事件业务写入前拒绝。
- 成功事务发布一条县级 `formal_public_food.monthly_resolved` 提交后事件；事件消费者只确认投影边界，不重复移动粮食。
- 复用 V33 持久命令、批结果和事件发件箱，不新增存档字段、不升级 V34。

### 2.4 世界调度与兼容

- 正式村庄月结跳过已迁移的食品消费和年度税粮；兼容直接入口仍执行完整月结。
- 公共粮食命令位于 `DailyProjection` 的村庄缓存刷新之后、县治理之前，确保读取本月已提交的家庭与村庄食品安全事实。
- 正式县治理在命令提交后跳过汇缴和县仓赈济，但继续处理行政俸禄、钱税、市场压力和公共秩序反馈。
- 既有 M25-P3 直接调用、M25-P10 家庭食品命令和旧存档行为保持兼容。

## 三、工作包

### WP1：村庄税粮拆分

- 为正式税粮增加按村独立验证与结算入口。
- 为正式模拟器增加“食品与公共粮食均已提交”的其余村庄月结入口。
- 保留 `ResolveMonthly` 和 M25-P10 既有兼容入口。

### WP2：县公共粮食拆分

- 提取县级正式公共粮食结算结果与验证入口。
- 将家庭税粮、村仓留存、县仓汇缴和县仓赈济组成一张按县事务。
- 为命令后的其余县治理提供不重复公共粮食写入的入口，并保持治安反馈可读取当日赈济事实。

### WP3：持久命令与世界接线

- 增加按县工作发现、稳定命令、处理器、事务、提交后事件和投影处理器。
- 在 `WorldSimulator` 注册处理器，并在县治理之前确保和处理到期命令。
- 正式模式走新路径；兼容标量和直接系统调用不改变。

### WP4：测试、文档与交付

- 覆盖读档后仅结算一次、日期漂移零业务修改、无工作不建命令、正式模拟器无重复税粮/赈济和同种子确定性。
- 回归 M25-P3 正式消费—税粮—汇缴—赈济与 M25-P10 家庭食品命令。
- 同步系统总纲、世界模拟、确定性存档、M12、M25-P3/M25-P10 兼容说明和 Skill 路由。

## 四、验收标准

1. 同县同月最多一张公共粮食命令和一张事务，重复调度不产生副本。
2. 第十月每户税粮只扣一次；汇缴只计算当日实际税粮流水；村仓留存与县仓实收可追溯。
3. 县仓赈济只转移真实库存，不能凭空补粮；正式产品与逐批次守恒继续成立。
4. 日期、权威或前置村庄结算漂移在应用前拒绝，库存、税账、流水、治理累计和事件均无业务修改。
5. 正式模拟器通过持久命令执行公共粮食链，其余村县月结不重复税粮、汇缴或赈济。
6. 直接 `ResolveMonthly` 入口与兼容标量世界保持原语义；M25-P3/M25-P10 回归不退化。
7. 相同种子与世界事实产生相同命令、事务、流水、事件和快照。
8. 全工程编译、核心测试、受控 Unity EditMode、`git diff --check` 和范围审阅分别报告。

## 五、不包含

- 自动市场买粮、跨县赈济运输、商人承运、赈济申请审批或完整 AI 决策。

后续兼容说明：M25-P12已在不改变本任务税粮/汇缴语义的前提下，补充赈济请求量、实发量与
未满足量，并让真实未满足发布县级短缺事件；该事件在次日驱动V34本县官府采购委任。跨县
求援和运输仍不属于本任务或M25-P12。
- 钱税、行政俸禄、豪族减免、仓储腐败、鼠害、霉变、劫仓或救济舞弊事务化。
- 逐人全世界饥荒扫描、关注层级改变事实、抽象人口伤害或删除/合并永久人物。
- 新存档字段、V34 迁移、通用事务回滚或外部副作用 exactly-once。
- 提交、推送、创建 PR 或清理工作区既有修改。
