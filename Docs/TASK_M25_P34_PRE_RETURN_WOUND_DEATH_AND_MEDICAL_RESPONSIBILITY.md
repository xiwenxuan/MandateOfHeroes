# M25-P34 返程前伤后死亡、遗体留置与医疗责任任务书

## 一、阶段目标

承接 M25-P33 的治疗后死亡、家庭继承和军队抚恤，把死亡时点前移到“冻结疗程已经完成，
但患者和救护队尚未开始返程”的真实照护阶段：

```text
重伤员完成冻结疗程并取得返程资格
→ 在诊疗地点等待返程期间因伤死亡
→ 永久人物、人口、军籍、家庭继承和组织抚恤一次闭合
→ 保存死亡时的设施、主治医者与照护组织责任快照
→ 遗体留在当前诊疗地点，不建立患者返程旅程
→ 原救护队沿真实道路独立返回来源军队
→ 全员到达后后送和住院责任结案
```

## 二、本阶段范围

1. 存档升级至 V56，为伤后死亡增加稳定死亡情境和医疗责任引用，并新增医疗死亡责任记录。
2. 第一版只处理全部冻结治疗阶段已经完成、住院/后送均处于 `ReadyForReturn`、患者因永久
   伤残应医疗退役且尚未开始返程的情况。
3. 死亡政策继续复用 V55 数据定义；等待期从取得返程资格之日计算，普通新增政策不升级存档。
4. 死亡必须保存当前诊疗设施、设施所属组织、当前主治医者、医者医术、军队授权人和权限快照。
5. 死亡后住院出院政策改为“死亡留置诊疗地”，患者返程政策改为“遗体留置”；人物位置不变，
   不建立患者返程旅程。
6. 原救护队继续保持医疗后送勤务，必须由既有返程入口沿真实道路返回；全员到达后恢复现役，
   患者军籍保持死亡，后送和住院记录完成。
7. 人口、继承、家主、抚恤和人生事件继续复用 V55 原子闭环；财政不足或责任事实不完整时，
   不得先写死亡或修改返程政策。
8. V55→V56 为既有 V55 死亡补入“医疗退役后死亡”情境与空责任引用，只建立空医疗责任集合和
   次日启用边界，不倒推旧设施或医者责任。

## 三、验收条件

- 合法返程前死亡同时产生死亡、继承、抚恤和医疗责任记录，患者永久档案仍存在且位置留在诊疗地。
- 患者没有返程旅程；救护队每人具有真实返程旅程并在到达后恢复现役。
- 等待期不足、疗程未完成、已开始返程、错误权限、无家庭、无继承人或财政不足时原子拒绝。
- 篡改死亡情境、设施、医者、医术、照护组织、出院/返程政策或责任交叉引用时世界校验失败。
- 当前 V56 存档往返保持责任与返程事实；V55 迁移不制造新的死亡或医疗责任。
- 全工程编译、聚焦核心、完整核心、受控 Unity、`git diff --check` 和范围审阅分别完成。

## 四、明确不包含

- 冻结疗程尚未完成时的恶化或死亡；
- 原始后送、跨设施转运或救护队返程途中的死亡；
- 遗体运输、棺木、安葬、祭祀、讣告和家属接回；
- 医疗事故认定、过失比例、司法追责、赔偿或医者关系变化；
- 抚恤欠款、多继承人析产、自动死亡调度和玩家界面。
