# M25-P35 住院中伤情恶化、死亡与医疗资源结案任务书

## 一、阶段目标

承接 M25-P34 的医疗地点死亡和救护队独立返程，把死亡时点继续前移到“伤员已经接诊，
但冻结疗程尚未完成”的住院阶段：

```text
重伤员正在接受冻结疗程
→ 数据政策判定住院伤情恶化并形成健康开闭值
→ 恶化达到死亡阈值，永久人物、人口、军籍、继承和抚恤原子闭合
→ 冻结未完成阶段、当前设施、主治医者和医疗责任
→ 释放跨设施转运后尚未使用的具体药材预留，不返还已经消耗的药材
→ 立即释放床位，遗体留在诊疗地点
→ 原救护队沿真实道路独立返军并最终恢复现役
```

## 二、本阶段范围

1. 存档升级至 V57，新增数据驱动住院恶化政策、住院死亡结案记录及死亡结案引用。
2. 第一版只处理已经接诊、住院和后送均处于活动照护阶段、冻结疗程尚未完成、患者与主治医者
   同处正常运行设施，且当前不在原始后送、跨设施转运或返程旅程中的情况。
3. 一次合法住院死亡必须用冻结恶化政策保存健康开值、损失量和死亡健康闭值；关注层级、读档
   或以后政策变化不得重算本次结果。
4. 死亡、家庭继承、家主继任、组织抚恤和医疗责任继续复用 V55/V56 原子闭环；任何前置事实、
   权限、继承人或财政不足时，不得先降低健康、释放药材或写入死亡。
5. 结案记录冻结已完成/总治疗阶段、死亡时下一协议、当前设施、主治医者和转院引用。
6. 普通住院没有预留药材，未执行的治疗不扣药；已经完成跨设施转运的住院只释放该转运尚未
   消耗的具体批次预留，并用正式库存事务保存预留量开闭值，批次数量不增加。
7. 死亡后住院立即进入死亡出院状态并释放床位；患者返程政策为遗体留置，患者不生成返程旅程。
8. 后送记录进入等待救护队返程状态；既有返程入口允许救护队沿真实道路独立返军，全部到达后
   患者军籍保持死亡、救护队恢复现役，住院和后送结案。
9. V56→V57 只建立核心恶化政策、空住院死亡结案集合、空引用和次日启用边界，不倒推旧恶化、
   未完成疗程或药材释放。

## 三、验收条件

- 合法住院中死亡同时产生恶化/结案、死亡、医疗责任、继承和抚恤记录，并只登记一次人口死亡。
- 已用药材保持消耗；转院预留的未用药材只减少预留量、不增加实物数量，且库存事务可重建。
- 死亡立即释放床位；遗体留在诊疗地点，患者没有返程旅程，救护队可独立返军并恢复现役。
- 未达到住院天数或恶化阈值、疗程已完成、人物正在转运/返程、设施停运、医者缺失、权限错误、
  家庭/继承人/财政不足或预留药材事实不完整时原子拒绝。
- 篡改健康开闭值、疗程阶段、下一协议、设施、医者、药材批次、预留开闭值、库存事务、出院/
  返程政策或交叉引用时世界校验失败。
- V57存档往返保持全部事实；V56迁移不制造死亡、恶化、结案或药材释放。
- 全工程编译、聚焦核心、完整核心、受控 Unity、`git diff --check` 和范围审阅分别完成。

## 四、明确不包含

- 原始后送、跨设施转运或救护队返程旅程中的恶化和死亡；
- 自动日结死亡调度、院内传播、护理班次、手术事故概率或医疗过失认定；
- 遗体运输、棺木、安葬、祭祀、讣告和家属接回；
- 抚恤欠款、多继承人析产、司法追责、额外赔偿或玩家医疗界面；
- 将未执行疗程虚构成治疗记录，或把已经消耗的药材退回库存。
