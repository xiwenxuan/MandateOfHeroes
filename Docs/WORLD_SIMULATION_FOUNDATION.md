# 《群雄志：仕途》世界模拟、人口经济与地方战争总设计

## 1. 文档定位

本文统一归纳项目关于以下系统的长期设计：

- 多层世界地图与城市圈；
- 全地图可开发土地与建筑位；
- 城市、县镇、乡村和产业设施；
- 永久独立人口、分级AI与关注演出；
- 人物数据按需展开与分区加载；
- 城市圈资源、设施生产和商路流通；
- 身份、数量、税基与三级财政；
- 家族、豪族、官府、商人和工匠的自发建设；
- 人物追随、投靠、起义与相性；
- 征兵来源、兵员批次、战争伤亡与人口守恒；
- 军团、乡镇、农庄、坞堡和设施层战斗；
- 战争破坏对人口、生产、税收和声誉的永久影响；
- 控制算力与保持世界真实性的方法。

本文描述的是目标架构，不表示所有内容已经完成。

当前 M1 至 M10 原型已经验证人物开局、地图、旅行、市场、军队、医疗、

具体人物构成的真实服役、编制、军令权限和战争伤亡闭环；存档可由 V1
连续迁移至 V5。独立设施实体、完整产业链、组织财政、NPC 自主建设、
大规模兵员批次、地方战争破坏、永久人口分区存储和人物资料按需展开仍属于后续开发。

人物的多属性、词条、家族教育和代际培养详见
`Docs/CHARACTER_ATTRIBUTES_TRAITS_AND_GROWTH.md`。

135—260年的史料户口锚点、逐年人口基线和空间分配方法详见
`Docs/HISTORICAL_POPULATION_135_260.md`。

## 2. 核心愿景

游戏世界不依靠“城市等级自动产生粮食”“占领城市自动获得全部税收”或“战争结束后人口自动恢复”等抽象结果运行。

世界中的资源变化应当能够追溯：

```text
谁拥有土地
谁建立设施
谁提供资金
谁在那里工作
使用了什么原料
生产了什么商品
商品存放在哪里
由谁运输和购买
谁征收了税款
哪支军队消耗或抢走了物资
哪些人在战争、疾病或灾害中死亡
```

核心原则是：

> 每个人从出生起都拥有永久、唯一、可追溯的身份；只有需要独立关系、财产、
> 记忆、任务或关键决策的人，才持续运行较完整的AI。模拟精度可以升降，
> 人物存在本身不能降级、合并或因玩家未关注而消失。

## 3. 不可违反的系统原则

### 3.1 人口守恒

```text
期末人口
= 期初人口
+ 出生
+ 迁入
- 死亡
- 迁出
- 永久失踪
```

民间人口、在役军人、伤员、俘虏、流民和已实例化人物必须属于同一本人口总账，不能重复计算。

### 3.2 物资守恒

```text
期末库存
= 期初库存
+ 生产
+ 输入
- 消费
- 输出
- 损耗
- 抢夺
- 焚毁
```

军队抢到的粮食必须从农庄、市场或官仓的真实库存转移，不能凭空增加。

### 3.3 兵员守恒

```text
军队期末人数
= 期初人数
+ 征召和补充
+ 伤愈归队
- 阵亡
- 被俘
- 逃亡
- 退伍
- 永久失踪
```

征兵时人口已经从民间转入军队，阵亡时只能从军队扣除，不能再次从原籍民间人口重复扣除。

### 3.4 财政守恒

个人财产、家族财产、设施账本、地方政府财政和势力国库必须分开。

任何财政收入都应来自税收、产业、贸易、贡赋、罚没、借贷、战利品或其他明确来源；任何支出都进入另一主体账户或形成真实消耗。

### 3.5 视角一致

战略地图上的农庄、县镇、港口和坞堡，与玩家进入详细场景后看到的对象必须是同一个世界实体。

战术地图烧毁的仓库，返回战略地图后仍然损毁；战术地图死亡的人物，返回世界模拟后不能复活为原有统计人口。

### 3.6 观察不能创造世界

玩家点击一个家庭或设施，只能展开已有永久人物的详细资料，不能额外创造人口、财产、库存或关系。

重复进入同一地点不能重新随机获得不同家庭或商品。

### 3.7 创世与运行分界

世界只在创世阶段初始化一次：

```text
基础地理与历史行政锚点
→ 城镇、道路、河流和交通节点
→ 人口、家户、土地和自然资源
→ 产业、设施、库存、财政和组织
→ 人物关系、职位和知识
→ 各人物与组织的初始认知
→ 世界时间开始运行
```

创世完成后，出生、死亡、迁徙、建设、生产、交易、灾害和战争只能在既有世界账上
产生变化。缩放、观察、加载场景和切换玩家人物不能成为第二条创世入口。历史事件也
必须读取当前世界条件，不能为了恢复既定剧情重置已经改变的地点、人物或设施。

## 4. 多层地图结构

### 4.1 天下战略地图

主要显示：

- 州郡、势力与法理归属；
- 城市圈和主要据点；
- 大型道路、河流、关隘和港口；
- 军团、补给线和大规模人口迁徙；
- 战争、商业、财政和灾害态势。

### 4.2 州郡与郡县地图

主要显示：

- 郡治、县城、乡镇和地方据点；
- 农业区、林区、矿区、牧区和水域；
- 主要庄园、市场、仓库和工坊区；
- 渡口、驿站、道路、河港和运输容量；
- 地方官府、豪族、军队和宗教组织控制。

这是建设、经营、行军、剿匪和地方治理的主要地图。

### 4.3 城市、县镇和乡村地图

显示具体功能区和设施：

- 官署、民居、市场、客栈；
- 仓库、工坊、医馆、学塾；
- 农庄、牧场、林场和矿场；
- 港口、船坞、车马行和驿站；
- 军营、城门、坞堡和寺观。

### 4.4 具体场所地图

玩家进入家庭、店铺、工坊、客栈、军营或坞堡后，加载已有实体的详细资料和表现对象：

- 家庭成员；
- 所有者和管理者；
- 雇工与学徒；
- 当前客人；
- 当前在场的具体士兵和平民；
- 具体库存、订单、矛盾和任务。

### 4.5 战场地图

野战、攻城、乡镇攻防、坞堡防御和设施争夺使用详细战场，但战果统一回写世界账本。

### 4.6 连续比例尺与语义缩放

地图层级只改变显示精度、图标密度和可用操作，不改变对象是否存在：

- 天下视图显示重大城镇、关港、军团和区域网络；
- 州郡视图显示县乡、路线、主要设施和区域项目；
- 地方视图显示土地、功能区和具体设施；
- 场所视图显示建筑布局、工位、库存与在场人物。

低比例尺可以隐藏对象或把多个子设施聚合为区域网络；放大后必须展开原有稳定ID，
不能重新抽取另一套位置和状态。技术上允许分区加载、不同场景和不同细节层级，逻辑上
仍是一张共享稳定坐标、地理锚点、土地单元和路线网络的世界地图。

### 4.7 主体认知与专题视图

世界事实、人物所知、人物所信和组织档案相互分离。玩家当前能够使用的信息来自：

```text
当前人物的观察与记忆
+ 合法持有的实物文档
+ 家族共享档案
+ 当前职位授权的组织档案
+ 同行者、信使、斥候、商旅和密探报告
```

综合地理、个人、建设、资源、生产、商业、交通、民生、治理、战争、情报和势力视图
只是对主体认知账本的不同筛选器。任何视图都不能绕过来源、授权、观察时间、可信度和
过时程度读取世界真相。大型公开城镇可以是常识，具体库存、矿脉、秘密营寨、驻军和
布防仍需查阅、勘察或侦察。

一条观察记录至少包含：

```text
观察主体或持有组织
目标实体与事实类型
观察值、估计范围或传闻
来源与取得时间
可信度、精度和保密级别
访问权限与过时规则
```

### 4.8 信息资产、复制与传播

个人记忆、实物文档、家族档案和组织档案是不同对象。任职只授予组织资料的访问权；
离任后不再自动获得更新。人物可以在权限允许或承担秘密行动风险的前提下抄录资料，
但复制必须形成真实工作：

```text
选择文字、账表或地图范围
→ 准备简牍、纸、缣帛、笔墨等载体和工具
→ 指派具体抄写与校对人物
→ 消耗世界时间
→ 形成有完整度、误差和来源的新副本
→ 运输、保存、阅读或纳入家族档案
```

副本不会与原档案自动同步。个人阅读和理解还受识字、专业、记忆、语言与内容难度影响；
文档可以被窃取、伪造、损坏、查扣、出售、继承或销毁。后台可以批量结算抄录工单，
但必须保留实际行动者、材料、时间、地点和结果。

抄录工作量至少由文字数量、账表单元、地图面积与符号复杂度组成：

```text
抄录时间
= 内容工作量 ÷ 抄写速度
× 载体与字迹难度
× 校对和保密要求
× 疲劳、照明和工作环境
```

具体字数、简牍或纸张容量、书吏速度和校对误差必须在后续内容数据任务中按史料与玩法
分别校准，不能用“复制完成”按钮绕过工作量。

## 5. 城市圈

一个城市不是孤立节点，而是一个城市圈的行政、市场和军事中心。

```text
城市圈
├─ 中心城市或郡治
├─ 所属县城
├─ 乡镇
├─ 村落和庄园
├─ 农业与牧业分区
├─ 林场、矿山和药材产区
├─ 河流、湖泊、渡口和港口
├─ 道路、驿站和商路
└─ 军营、关隘和坞堡
```

中心城市主要承担行政、市场、仓储、高级加工、教育、城防和商品集散。

乡镇与农村主要承担土地生产、资源采集、初级加工和地方人口生活。

史料中的郡国人口不能直接视为中心城市人口。必须按照行政边界、可耕土地、水源、历史县治、道路、市场和聚落容量分配到所属县镇与乡村。

## 6. 全地图可建设土地

所有土地原则上可以被开发，但不同土地具有不同用途、成本和风险。

每个土地单元记录：

```text
地形与坡度
海拔
气候与降水
水源
土壤肥力
林木储量
草场容量
关联资源体ID
适航条件
洪水、干旱和火灾风险
道路和市场距离
行政归属
土地所有权
当前利用方式
```

设施适宜度由地理、资源、历史传统、人口技能、交通、市场和政策共同决定。

```text
设施适宜度
= 地理条件
+ 资源条件
+ 历史传统
+ 技能人口
+ 交通条件
+ 市场需求
+ 政策支持
```

适宜度影响：

- 建设成本；
- 最大规模；
- 单位产量；
- 维护费用；
- 灾害概率；
- 所需技术和公共工程。

历史和地理决定潜力，不锁死未来。玩家可以通过治水、修路、移民、技术和投资改变地区发展，但不能无成本违背自然条件。

### 6.1 可配置资源创世

资源创世把“采用何种证据”和“世界资源有多丰富”分成独立参数：

- 档案考据：只采用明确史料、考古和可靠历史地理锚点；
- 历史重建：在史料锚点外加入地质、生态和区域产业支持的合理推定；
- 贫瘠或丰富变体：保留历史锚点，调整资源点密度、储量、品位、开发难度、
  土地潜力和可再生速度；
- 自定义：分别设置矿产、林业、草场、水产、药材、土地和稀有资源参数。

资源来源至少标记为史料明确、历史推定、地质生态生成或沙盒补充。增加资源仍受地质、
地形、气候和水文约束，不能为了平均分配让每个县拥有相同资源。创世界面可以告知规则，
不能因此把具体资源位置写入角色认知。

相同内容版本、创世规则、随机算法版本和世界种子必须生成相同的初始资源事实。

### 6.2 资源层级与多矿脉

自然资源不得只压成一个永久不变的地区加成。例如山地矿产使用以下层级：

```text
山系
→ 山地单元
→ 矿区
→ 矿床
→ 多条矿脉或矿体
→ 矿井、采掘点和工作面
```

同一座山可以拥有不同矿种、品位、储量、深度、岩层、地下水、伴生矿和开采风险的
多条矿脉。勘察只提高对既有矿体的位置、规模和可信度认识，不能临时生成资源；开采、
枯竭、坍塌、淹水和新工作面必须改变对应实体及其账本。

实际采矿至少受有效劳动、人员技能、工具、可用工作面、岩层难度、运输、排水、支护、
安全和管理影响。矿石还需经过搬运、选矿、冶炼和加工，发现矿脉不等于直接获得金属。

```text
实际矿石产量
= 有效劳动时间
× 人员技能与工具效率
× 可用工作面和矿石品位
× 排水、支护、通风与管理效率
× 运输能力
```

结果受已经暴露的可采储量和工作面容量硬限制，并同时产生废石、工具损耗、事故风险和
矿脉消耗记录。

## 7. 建筑位与空间容量

### 7.1 战略建筑位

数量较少，在地图上明确存在：

- 官署；
- 城门和城墙；
- 大型市场与仓库；
- 港口和船坞；
- 军营和军械库；
- 官营作坊；
- 大型寺观；
- 豪族庄园与坞堡。

### 7.2 产业地块

代表成片生产区域：

- 农田；
- 牧场；
- 林场；
- 矿区；
- 药田；
- 渔场；
- 工坊区。

一个产业地块可以代表几十至数百户人口，不要求一户一格。

### 7.3 居住容量

普通民居使用容量而不是逐栋建筑：

```text
民居区
├─ 可容纳500户
├─ 当前430户
├─ 当前人口2,160
├─ 拥挤度
├─ 卫生
└─ 火灾风险
```

历史人口上限用于校准整个城市圈的承载规模，而不是要求生成对应数量的可见房屋。

### 7.4 设施空间尺度与区域网络

设施按其独立所有权、建设、运营和损坏事实分为单体设施、聚落设施、战略设施与区域网络。
所谓州级或郡级设施通常表示出资、管辖和影响尺度，不表示一栋没有具体位置的建筑。
驿站网、烽火线、水利体系、粮仓体系和边防线采用母项目与真实子设施：

```text
区域建设项目
├─ 具体道路、桥梁或水渠
├─ 具体仓库、驿站或烽燧
├─ 具体关卡、营寨或港口
└─ 负责人、预算、施工与维护账
```

关卡、渡口堡垒等战略设施必须锚定山口、河渡、道路交汇、城门或其他真实地理要点，
其控制效果作用于实际路线、视野、通行和补给，而不是给予整个州郡无条件加成。

## 8. 城市圈资源与产业档案

每个城市圈建立资料驱动的生产档案：

```text
历史行政范围
史料年份
中心城市与所属县镇
总人口和人口结构
地形单元
可耕土地
水利与河运
林木、草场、矿藏和盐资源
历史产业标签
技术和人才传统
当前设施与库存
道路和运输能力
主要输入需求
主要输出商品
资料来源和可信度
```

资料分级：

- A级：明确史料或考古证据；
- B级：依据地理、区域产业和周边资料合理推断；
- C级：为玩法闭环加入的设计推断，必须明确标注。

《九州》系列主要参考地方商品差异、跑商、商队、仓库、投资和供需玩法；不复制其城市商品表、价格、数值、UI、任务文本和素材。

历史资料和地理资料决定产业基础，市场和人物行为决定最终产量。

## 9. 永久人口与分级模拟

### 9.1 永久基础人口

所有人出生时立即获得永久人物ID。绝大多数普通人口以紧凑基础档案存在，
但不再以可合并、可重随机的无名人口代替。

基础档案至少记录：

```text
原籍郡县乡镇
身份和职业
出生、生死与性别
父母与家户
个人劳动力
财富
健康
技能
土地与生产资料
宗族或组织归属
满意度
税役状态
迁徙倾向
稳定生成种子与规则版本
```

家户、设施、村庄和组织可以批量作出日常决策，但结果必须落实到具体成员。

### 9.2 历史留名人物

以下人物运行较丰富的独立AI：

- 家主和庄主；
- 掌柜与管事；
- 主匠；
- 乡勇首领；
- 屯长和基层军官；
- 商队领队；
- 宗族与流民代表。

该层目标规模为数万名，包括史料人物和动态世界中取得显著影响的人物。

### 9.3 三国重要人物

该层目标规模为数千名，拥有完整性格、能力、志向、认知、主动行动和重要关系，包括：

- 玩家和家族成员；
- 历史人物；
- 官员、将领和豪族家主；
- 名医、名匠和豪商；
- 宗教领袖和密探；
- 与玩家形成重要关系的人；
- 任务、契约和重大事件相关人物。

### 9.4 玩家关注人物

同时几十至几百名人物进入玩家当前关注与演出范围。关注只提高信息、关系网和
表现精度，不决定人物是否存在。

## 10. 人物资料展开与分区加载

未被玩家详细观察的人物仍以永久基础档案存在。家庭和设施可以使用汇总缓存加速结算，
但缓存不得代替或删除其具体成员。

玩家进入时，从永久档案加载详细资料：

```text
进入前：500名永久人物的基础档案
展开：一家五口的详细资料和关系视图
进入后：人口仍为同一批500名永久人物
```

人物生成使用稳定组合：

```text
世界种子
+ 地点ID
+ 家户ID
+ 出生序号
```

离开后可以释放详细视图和表现对象、降低结算频率，但不得删除、合并或重随机人物。
出生、死亡、财产、健康、职业和家庭变化必须写回永久档案及其汇总缓存。

## 11. 设施与生产

设施不是图标，而是有所有权、人员、库存和账本的生产组织。
作物、地方品种、产品、配方、生产方法、职业成长和分层生产委任的详细数据合同见
[`PRODUCTION_AGRICULTURE_INDUSTRY_AND_PROGRESSION_DESIGN.md`](PRODUCTION_AGRICULTURE_INDUSTRY_AND_PROGRESSION_DESIGN.md)。

```text
设施
├─ 所有者
├─ 所在土地
├─ 管理者
├─ 建筑等级和完好度
├─ 最大岗位
├─ 实际雇员
├─ 生产配方
├─ 原料库存
├─ 产品库存
├─ 资金账户
├─ 技术水平
├─ 当前订单
└─ 维护成本
```

实际产出：

```text
实际产出
= 基础产能
× 人员满足率
× 技能效率
× 原料满足率
× 地理适宜度
× 设施完好度
× 治安效率
× 健康效率
× 季节和天气
```

城市粮食、布帛、兵器和船只产量等于所属设施真实产出的汇总，不由城市等级直接产生。

设施可以在地方和场所视图展开建筑布局、工位、运输区、仓储区与安全设施；远方结算时
可以使用工单和设施缓存，但不得改变设施身份、人员来源、库存、进度和损坏事实。亲自劳动、
实时派工、工单、目标指令和组织委任统一进入同一结算链，详见
`GAME_SYSTEMS_MASTER_AND_STATUS.md` 第4.1节。

## 13. 市场与跑商

各地地理、人口、产业和战争需求不同，形成真实价差。

```text
生产过剩地
→ 商人收购
→ 商队或船队运输
→ 短缺地出售
→ 居民、设施、军队和政府消费
```

价格取决于：

- 当前库存；
- 当地人口消费；
- 生产成本；
- 军队与建设需求；
- 战争和灾害；
- 道路安全；
- 运输容量；
- 税收和关卡；
- 商人囤积与竞争。

商人可以投资农庄、作坊、仓库、商铺、车马行、港口和船队，也可以签订预购、军需、运输与贷款契约。

## 14. 世界主体的自发建设

世界建设不只依靠玩家点击。

### 农户

根据粮价、种子、工具、地租、税收、灾害和其他职业收入决定开垦、改种、购买耕牛或弃田。

### 工匠

根据订单、售价、原料、工资、贷款和技术决定扩建、招徒、转产或关闭。

### 商人

根据价差、商路、仓储、税收、匪患和资金成本决定投资和运输。

### 豪族

根据家族资产、粮食自给、政治影响、部曲供养和地方安全决定兼并土地、建设庄园、工坊、学塾或坞堡。

### 官府

根据财政、治安、粮食安全、战争、灾害和政绩建设水利、道路、官仓、城防、港口与官营作坊。

建设必须具备土地权利、资金、劳动力、原料、实际需求、运输和政策许可。设施也会停产、破产、废弃、转让、没收或被战争摧毁。

### 14.1 NPC选址与建设委任

NPC不得随机挑选一个无条件地点，也不能读取其角色或组织未知的资源。自主建设流程为：

```text
发现生计、利润、治理或军事需求
→ 在已有认知中生成候选区域
→ 查阅档案、雇佣向导或组织勘察
→ 评估土地权利、地理、资源、交通、市场、补给、风险和政策
→ 申请或行使权限
→ 筹集资金、材料、劳力和运输
→ 建设、验收、运营和维护
```

选址结果受负责人能力、性格、忠诚、利益、地方经验和情报质量影响。当地人物可能比远方
上级掌握更准确的地理信息；贪腐、偏私、误判和虚假报告可以形成真实后果。

上级可以只指定目标、走廊、预算、期限、权限和红线，由都督、太守、县令、管事、工头
逐级拆解为具体地块、子设施和人物工单。玩家可以在任意有权层级审查候选地、接管施工或
交还委任，已发生的成本、时间和进度不能重置。

## 15. 城市发展

城市不使用单一发展值直接产生资源。

分别记录：

- 农业；
- 工业；
- 商业；
- 行政；
- 军事；
- 交通；
- 民生和医疗；
- 文化和教育。

综合繁荣度只用于界面阅读，是人口、设施、产业、交通、治安和政策的汇总结果，不是产出的来源。

## 16. 身份、数量与税收

数量决定税基，身份决定税种、义务和减免，收入来源决定具体征收方式。

### 人口群体

普通农户、佃农、商贩、工匠、船工和军户按群体结算。

### 家户、设施和组织

玩家家族、豪族庄园、商铺、商队、农庄、牧场、工坊、船坞、寺观和商会单独记账。

### 重要人物

对俸禄、赏赐、产业分红、土地租金、贸易利润、利息和战利品单独结算。

身份财政示例：

| 身份 | 主要税基 | 主要义务 |
| --- | --- | --- |
| 自耕农 | 土地、收成、家户 | 田赋、户赋、徭役 |
| 佃农 | 收成、工资 | 地租、部分户赋、徭役 |
| 商人 | 交易、利润、货物 | 商税、关税、许可费 |
| 工匠 | 作坊销售和利润 | 作坊税、产品或官府订单 |
| 军户 | 军田和家庭 | 服役替代部分税役 |
| 豪族 | 土地、佃户和产业 | 法定税负、包税、军粮或部曲义务 |
| 宗教组织 | 寺产、捐赠和产业 | 减免或特别贡赋 |

多身份人物分别按照不同收入来源结算，不能选择一个最低税率覆盖全部资产。

## 17. 三级财政

```text
县城或城市财政
→ 州郡或地区财政
→ 中央政府或玩家势力财政
```

基层负责实际征收，按留成和上缴比例分配，不能对同一税基重复征收三次完整税率。

税收形式包括：

- 钱币；
- 粮食、布帛、马匹、木材和药材等实物；
- 徭役；
- 兵役；
- 战时军需征发。

实际税收：

```text
实际税收
= 理论税基
× 法定税率
× 户籍覆盖率
× 行政效率
× 实际控制力
× 纳税意愿
- 减免
- 隐瞒
- 贪污
- 截留
- 运输损耗
```

每个地点区分：

- 法理归属；
- 行政管理；
- 军事控制；
- 税收控制。

占领城市不等于立即获得全部财政，必须控制官府、豪族、户籍、仓库、税吏和运输。

## 18. 人物追随、投靠与起义

关系值只是私人信任的一部分。

人物是否追随需要比较追随、留任、投靠他人或自立的预期结果。

主要因素：

- 私人信任；
- 家世与政治合法性；
- 分类名声；
- 人品和道德；
- 志向与价值观；
- 相性；
- 能力与治理成绩；
- 财富和供养能力；
- 军力和未来胜算；
- 可提供的职位；
- 家族、宗族、朋友和同僚态度；
- 当前忠诚；
- 背叛成本；
- 失败后的个人与家族风险；
- 人物对信息的认知可信度。

相性拆为价值观向量，而不是单一循环数字：

- 名分与实力；
- 仁德与刑法；
- 家族与个人；
- 保守与求变；
- 地方与天下；
- 虔诚与世俗；
- 冒险与谨慎。

追随具有多级承诺：

```text
有好感
→ 同情
→ 暗中帮助
→ 公开合作
→ 成为门客或属官
→ 带家族、部曲和资产投靠
→ 成为核心集团
→ 共同起兵并承担灭族风险
```

## 19. 征兵与兵员聚合缓存

大规模军队不生成同等数量的完整AI。

征兵时从永久人物和家户中建立服役关系。下列数字只是在同一本人物账上的聚合结果：

```text
民间人口－征兵人数
在役人口＋征兵人数
```

军团结算可以建立兵员聚合缓存，但缓存必须能够解析回具体服役人物。每个缓存记录：

```text
成员ID索引或稳定分区引用
原籍郡县乡镇
来源身份和职业
人数
年龄结构
兵种
训练
装备
士气
家庭依赖程度
征召日期
所属部队
```

一个缓存可以聚合约100至1,000名永久服役人物。二十万军队可由数百个聚合缓存、
数十个部队和分级人物AI构成，但任何人的服役、家庭和生死事实仍由其永久人物档案保存。

## 20. 战争伤亡分配

总伤亡按以下层级分配：

```text
总伤亡
→ 军团
→ 部队
→ 阵列和兵种
→ 兵员聚合缓存
→ 缓存引用的永久服役人物
```

权重考虑：

- 参战人数；
- 接敌时间；
- 战场位置；
- 兵种暴露度；
- 装备和训练；
- 士气；
- 是否被包围；
- 撤退路线；
- 将领指挥。

分配必须使用整数守恒方法，保证所有缓存伤亡之和严格等于战斗总伤亡，并将结果
确定性落实到具体人物。

战损分为：

- 阵亡；
- 重伤；
- 轻伤；
- 被俘；
- 失踪；
- 逃亡；
- 溃散待归队。

重要人物可以使用更细的风险判定，但仍属于聚合伤亡预算，不能额外叠加。

## 21. 伤亡对原籍的影响

服役关系和兵员聚合缓存保留原籍、家庭和原职业，使伤亡能够回写：

- 遗属和孤儿；
- 主要劳动力家庭；
- 农业和工坊岗位缺口；
- 抚恤债权；
- 地方民怨；
- 未来征兵能力；
- 返乡伤兵和残疾人口。

生产下降不按“死亡比例”直接硬减，而是根据损失的具体职业、家庭补位、流民雇佣、工具牲畜和土地撂荒重新计算。

## 22. 军队的地方行动

军队进入乡镇后可以：

- 通过；
- 驻扎；
- 有偿征购；
- 强制征粮；
- 搜捕敌人；
- 占领官署；
- 攻击坞堡；
- 抢掠农庄；
- 焚毁仓库；
- 破坏水利；
- 强征民夫和工匠；
- 保护产业和居民。

统治者可以制定军纪政策，但实际执行还受将领忠诚、军队纪律、补给、军饷、敌意和督战能力影响。

## 23. 农庄、乡镇与坞堡防御

地方生产单位拥有真实防御：

```text
围墙和木栅
壕沟
箭楼
大门
警戒
常备私兵
临时乡勇
武器库存
粮食和水
避难容量
可坚持时间
```

私兵和乡勇来自真实地方人口，动员会减少生产劳动力；伤亡会永久减少原籍人口。

小型坞堡可以击退侦察队、劫掠队、溃军和缺少攻城能力的小部队。面对正规大军时，主要作用是拖延、保护人口、造成损失和等待援军，不应无条件阻挡主力军团。

攻击、征粮和破坏都需要时间。军队停留越久，补给消耗、疫病和遭遇援军的风险越高。

## 24. 地方战斗与真实破坏

地方接触生成统一战斗对象：

```text
进攻者
防守者
地点
军事目标
军令
居民和防御人口
设施
库存
持续时间
伤亡
破坏
物资转移
责任人物
```

战斗结果回写：

- 居民、私兵和军队死亡；
- 伤员、俘虏和逃亡人口；
- 民居、仓库、工坊和水利损坏；
- 粮食、牲畜、工具和商品被抢；
- 土地弃耕；
- 火灾、尸体和疫病风险；
- 地方仇恨与势力声誉。

农庄被攻破不等于所有居民必然死亡。人口应分为死亡、逃亡、被俘和幸存，除非确实发生屠杀或无法逃生的灾难。

## 25. 后台结算与玩家进入战场

玩家远离时，按部队批次、设施和防御数据自动结算。

玩家在附近或担任指挥官时，可以进入乡镇、农庄、坞堡或攻城战场，直接决定进攻、防守、撤离、灭火、护送和投降。

两种模式共享同一战斗状态和结果结构：

- 进入战术地图不会重新生成一场战斗；
- 已经在后台结算的伤亡不能再次计算；
- 战术选择只改变尚未决定的过程；
- 结束后统一汇总到人口、设施和库存账本。

## 26. 战争的长期影响

地区记录：

```text
战争破坏度
流民
弃耕面积
设施损坏
道路安全
尸体与疫病风险
豪族武装化
居民仇恨
粮食短缺
重建需求
```

同一地区不能被军队无限征粮。第一次征粮减少库存，第二次抢掠导致逃亡和停产，第三次经过时可能已无粮可取。

战争行为形成分类声誉：

- 保护百姓；
- 有偿购粮；
- 约束军纪；
- 抢掠和屠杀；
- 焚毁农田；
- 释放俘虏；
- 强征工匠；
- 战后赈济。

农民、商人、豪族、士人、军人和宗教组织对同一行为会有不同评价，并影响投降、补给、招募、贸易和叛乱。

## 27. 算力控制

### 27.1 分层结算频率

| 内容 | 建议频率 |

| 玩家和重要人物 | 每日或每时段 |

### 27.2 事件驱动与汇总缓存

征兵、迁徙、疾病、转职、叛乱和玩家关注使具体人物进入更细结算。
同原籍、身份、年龄、职业和政治状态的人物可以形成汇总缓存，但缓存不得取代、
删除或合并永久人物档案。

### 27.3 计算复杂度

世界模拟以到期事件、地点、设施、家户、组织、军队聚合缓存和重要人物数量为主要复杂度，
不得按总人口全量运行完整AI。

例如二十万军队可以由：

- 5个军团；
- 30至60个部队；
- 200至1,000个兵员聚合缓存；
- 100至500名代表军官；
- 数十名完整重要人物。

## 29. 世界模拟领域建设依赖

本节说明世界模拟内部的依赖关系，不单独决定当前全局排期。当前状态和推荐后续
建设顺序以 `Docs/GAME_SYSTEMS_MASTER_AND_STATUS.md` 第0E节为准。

### 第一阶段：永久人口、历史映射与存储验证

- 校录历史人口与稳定地理单元；
- 每个出生人物取得永久ID和基础档案；
- 建立事件调度、分区加载、汇总缓存和存档迁移方案；
- 完成M12规定的分级压力测试，未达标前不承诺对应人口档位。

### 第二阶段：基层家庭与设施账本

- 建立200至500人的真实村庄；
- 地点人口落实为人物、家户、劳动力和职业；
- 把现有设施标记升级为独立设施实体；
- 设施拥有容量、岗位、所有者、库存和账本。

### 第三阶段：最小生产贸易闭环

```text
具体农田生产粮食
→ 家庭消费与市场出售
→ 商人收购和运输
→ 战区市场与军队消费
→ 价格、利润、税收与库存变化
```

### 第四阶段：科研应用、税收与组织财政

- 首批科技卡只影响明确的设施、产业或组织；
- 县级征收、地方留成、官仓和地方金库；
- 州郡上缴以及个人、家族、设施、政府和国库分账；
- 官府建设使用真实财政、物资、人员和时间。

M22-P0已经完成这一阶段的县级最小守恒账：家庭现金税进入县政府金库，村庄税粮按留成率
进入县仓，县政府俸给回到具体管理者家庭，县仓救济回到具体村庄。豪族税收遵从、粮价压力、
粮食安全和行政效率会改变实际征收、救济与治安结果。州郡上缴、设施财政和国库仍未实现，
不得把本底座描述为完整三级财政。

### 第五阶段：NPC自主建设与一县治理

- 农户、工匠、商人、豪族和官府依据真实需求提出建设；
- 支持合资、借贷、许可和所有权；
- 扩展市场、豪族、治安、税役和基层执行链。

M22-P0已先完成县级治理中的财政、豪族、市场、救济和治安反馈；自主建设、土地兼并、
基层执行人员与案件链仍属于本阶段后续。

### 第六阶段：兵员来源与地方军事接触

- 征兵从永久人物和家户建立真实服役关系；
- 聚合缓存保留人物、原籍、家庭和职业引用；
- 伤亡回写家庭、生产、财政和关系；
- 军队征购、征发、抢掠、乡镇防御和设施破坏共享同一世界结果。

### 第七阶段：州郡经济与完整城市圈

- 加入林矿、纺织、畜牧、医药和造船产业链；
- 加入港口、水运、商会和跨区财政；
- 扩展迁徙、军需、战争和多年代持续模拟；
- 按总纲完成更高人口规模的压力验收。

M23-P0已经完成本阶段第一条跨系统军需切片：六种军械作为数据驱动产品进入商号组织库存，
有军队权限的人物从所属组织金库付款，永久承运人沿既有道路运输；目标军队尚未到达时货物
保持等待，双方会合后才写入军械库和采购账。该实现只证明成品采购、付款、运输和入库守恒，
尚不代表冶铁、木作、制弓、制甲、多段寻路、押运战斗或完整州郡后勤已经完成。

M23-P1进一步完成组织工坊切片：真实管理者在静态工坊仓上使用通用加工订单，铁料、木料、
皮革和角料经过六种守恒配方形成军械批次；承运人可从同组织、同地点的静态仓装货。损坏
军械则预留军械库数量和产品耗材，按世界日维修后回到可用库存。四类原料仍是原型期初量，
尚未连接林矿、冶炼、制革、品质、工匠成长、押运风险和多段州郡物流。

## 30. 总验收标准

目标世界架构完成后，应满足：

1. 城市不直接凭空产生商品；
2. 设施没有人员、原料或运输时不能正常生产；
3. 人口、物资、兵员和财政能够通过自动测试守恒；
4. 战争死亡真实减少人口和未来产出；
5. 征兵来源可以追溯到县镇、身份和职业；
6. 军队抢夺的物资来自真实库存；
7. 战术地图的破坏永久回写世界；
8. 玩家观察地点不会创造或重随机人口；
9. 普通人物以永久基础档案存在并由汇总缓存低频结算，重要人物能够独立行动；
10. 地理决定资源潜力，历史决定初始传统，人物和市场决定实际发展；
11. 农户、工匠、商人、豪族、官府和军队在同一经济世界中互相影响；
12. 玩家可以通过身份、家族、产业、政策、财政和战争改变世界，但不能绕过真实成本。
13. 同一世界实体在不同比例尺和专题视图中保持稳定身份；
14. 所有专题视图只显示当前人物及获授权组织已经掌握的信息；
15. 信息复制、建设和勘察由具体人物消耗材料与时间完成；
16. 资源创世配置、来源等级和世界种子可以存档、审计并确定性复现；
17. NPC自主建设只能依据自身认知、权限和真实资源选址；
18. 每个领域明确最小有意义实体，聚合缓存不得删除会独立改变世界结果的事实。

## 31. 最终总结

```text
土地和历史资料给出生产潜力
→ 家庭、组织和人物取得土地与设施
→ 真实人口提供劳动力与技能
→ 设施消耗原料并生产商品
→ 商人和运输网络完成流通
→ 居民、政府和军队形成需求
→ 税收和利润支持建设与战争
→ 战争、灾害和政策改变人口与设施
→ 家族和后代继承真实结果
```

项目的独特性不在于单独拥有城市建设、跑商、家族、人物扮演或战争，而在于这些玩法共享同一套人口、土地、设施、库存、财政和历史账本。
