# 《群雄志：仕途》世界模拟、人口经济与地方战争总设计

## 1. 文档定位

本文统一归纳项目关于以下系统的长期设计：

- 多层世界地图与城市圈；
- 全地图可开发土地与建筑位；
- 城市、县镇、乡村和产业设施；
- 统计人口、代表性AI与持久人物AI；
- 延迟实例化与人物回归统计；
- 城市圈资源、设施生产和商路流通；
- 身份、数量、税基与三级财政；
- 家族、豪族、官府、商人和工匠的自发建设；
- 人物追随、投靠、起义与相性；
- 征兵来源、兵员批次、战争伤亡与人口守恒；
- 军团、乡镇、农庄、坞堡和设施层战斗；
- 战争破坏对人口、生产、税收和声誉的永久影响；
- 控制算力与保持世界真实性的方法。

本文描述的是目标架构，不表示所有内容已经完成。

当前M1至M9原型已经验证人物开局、地图、旅行、市场、军队、医疗、地点地理、身份视角、个人建设项目、第一版人口批次、人口事务与守恒审计、人物多属性与五维派生，以及消耗真实时间和财富的教育实践循环；存档可由V1连续迁移至V4。独立设施实体、完整产业链、组织财政、NPC自主建设、兵员批次、地方战争破坏和延迟人物实例化仍属于后续开发。

人物的多属性、词条、家族教育和代际培养详见
`Docs/CHARACTER_ATTRIBUTES_TRAITS_AND_GROWTH.md`。

## 2. 核心愿景

游戏世界不依靠“城市等级自动产生粮食”“占领城市自动获得全部税收”或“战争结束后人口自动恢复”等抽象结果运行。

世界中的资源变化应当能够追溯：

```text
谁拥有土地
谁建立设施
谁提供资金
谁在那里工作
使用了什么原料
生产了什么商品
商品存放在哪里
由谁运输和购买
谁征收了税款
哪支军队消耗或抢走了物资
哪些人在战争、疾病或灾害中死亡
```

核心原则是：

> 所有人口在世界账目中都是真实数量，但只有需要独立关系、财产、家庭、记忆、任务或关键决策的人，才持续作为完整AI运行。

## 3. 不可违反的系统原则

### 3.1 人口守恒

```text
期末人口
= 期初人口
+ 出生
+ 迁入
- 死亡
- 迁出
- 永久失踪
```

民间人口、在役军人、伤员、俘虏、流民和已实例化人物必须属于同一本人口总账，不能重复计算。

### 3.2 物资守恒

```text
期末库存
= 期初库存
+ 生产
+ 输入
- 消费
- 输出
- 损耗
- 抢夺
- 焚毁
```

军队抢到的粮食必须从农庄、市场或官仓的真实库存转移，不能凭空增加。

### 3.3 兵员守恒

```text
军队期末人数
= 期初人数
+ 征召和补充
+ 伤愈归队
- 阵亡
- 被俘
- 逃亡
- 退伍
- 永久失踪
```

征兵时人口已经从民间转入军队，阵亡时只能从军队扣除，不能再次从原籍民间人口重复扣除。

### 3.4 财政守恒

个人财产、家族财产、设施账本、地方政府财政和势力国库必须分开。

任何财政收入都应来自税收、产业、贸易、贡赋、罚没、借贷、战利品或其他明确来源；任何支出都进入另一主体账户或形成真实消耗。

### 3.5 视角一致

战略地图上的农庄、县镇、港口和坞堡，与玩家进入详细场景后看到的对象必须是同一个世界实体。

战术地图烧毁的仓库，返回战略地图后仍然损毁；战术地图死亡的人物，返回世界模拟后不能复活为原有统计人口。

### 3.6 观察不能创造世界

玩家点击一个家庭或设施，只能把已有统计人口拆分成具体人物，不能额外创造人口、财产、库存或关系。

重复进入同一地点不能重新随机获得不同家庭或商品。

### 4.3 城市、县镇和乡村地图

显示具体功能区和设施：

- 官署、民居、市场、客栈；
- 仓库、工坊、医馆、学塾；
- 农庄、牧场、林场和矿场；

### 4.4 具体场所地图

玩家进入家庭、店铺、工坊、客栈、军营或坞堡后，才实例化：

- 所有者和管理者；
- 雇工与学徒；
- 当前客人；

### 4.5 战场地图

野战、攻城、乡镇攻防、坞堡防御和设施争夺使用详细战场，但战果统一回写世界账本。

## 5. 城市圈

一个城市不是孤立节点，而是一个城市圈的行政、市场和军事中心。

```text
城市圈
├─ 中心城市或郡治
├─ 所属县城
├─ 乡镇
├─ 村落和庄园
├─ 农业与牧业分区
├─ 林场、矿山和药材产区
├─ 河流、湖泊、渡口和港口
├─ 道路、驿站和商路
└─ 军营、关隘和坞堡
```

中心城市主要承担行政、市场、仓储、高级加工、教育、城防和商品集散。

乡镇与农村主要承担土地生产、资源采集、初级加工和地方人口生活。

史料中的郡国人口不能直接视为中心城市人口。必须按照行政边界、可耕土地、水源、历史县治、道路、市场和聚落容量分配到所属县镇与乡村。

## 6. 全地图可建设土地

所有土地原则上可以被开发，但不同土地具有不同用途、成本和风险。

每个土地单元记录：

```text
地形与坡度
海拔
气候与降水
水源
土壤肥力
林木储量
草场容量
矿藏
适航条件
洪水、干旱和火灾风险
道路和市场距离
行政归属
土地所有权
当前利用方式
```

设施适宜度由地理、资源、历史传统、人口技能、交通、市场和政策共同决定。

```text
设施适宜度
= 地理条件
+ 资源条件
+ 历史传统
+ 技能人口
+ 交通条件
+ 市场需求
+ 政策支持
```

适宜度影响：

- 建设成本；
- 最大规模；
- 单位产量；
- 维护费用；
- 灾害概率；
- 所需技术和公共工程。

历史和地理决定潜力，不锁死未来。玩家可以通过治水、修路、移民、技术和投资改变地区发展，但不能无成本违背自然条件。

## 7. 建筑位与空间容量

### 7.1 战略建筑位

数量较少，在地图上明确存在：

- 官署；
- 城门和城墙；
- 大型市场与仓库；
- 港口和船坞；
- 军营和军械库；
- 官营作坊；
- 大型寺观；
- 豪族庄园与坞堡。

### 7.2 产业地块

代表成片生产区域：

- 农田；
- 牧场；
- 林场；
- 矿区；
- 药田；
- 渔场；
- 工坊区。

一个产业地块可以代表几十至数百户人口，不要求一户一格。

### 7.3 居住容量

普通民居使用容量而不是逐栋建筑：

```text
民居区
├─ 可容纳500户
├─ 当前430户
├─ 当前人口2,160
├─ 拥挤度
├─ 卫生
└─ 火灾风险
```

历史人口上限用于校准整个城市圈的承载规模，而不是要求生成对应数量的可见房屋。

## 8. 城市圈资源与产业档案

每个城市圈建立资料驱动的生产档案：

```text
历史行政范围
史料年份
中心城市与所属县镇
总人口和人口结构
地形单元
可耕土地
水利与河运
林木、草场、矿藏和盐资源
历史产业标签
技术和人才传统
当前设施与库存
道路和运输能力
主要输入需求
主要输出商品
资料来源和可信度
```

资料分级：

- A级：明确史料或考古证据；
- B级：依据地理、区域产业和周边资料合理推断；
- C级：为玩法闭环加入的设计推断，必须明确标注。

《九州》系列主要参考地方商品差异、跑商、商队、仓库、投资和供需玩法；不复制其城市商品表、价格、数值、UI、任务文本和素材。

历史资料和地理资料决定产业基础，市场和人物行为决定最终产量。

## 9. 人口三级模拟

### 9.1 统计人口群体

绝大多数普通人口以群体批次存在。

人口批次至少记录：

```text
原籍郡县乡镇
身份和职业
年龄段
性别结构
家户数
劳动力
财富
健康
技能
土地与生产资料
宗族或组织归属
满意度
税役状态
迁徙倾向
稳定生成种子
```

### 9.2 代表性AI

以下人物可以作为群体代表：

- 家主和庄主；
- 掌柜与管事；
- 主匠；
- 乡勇首领；
- 屯长和基层军官；
- 商队领队；
- 宗族与流民代表。

代表性AI负责重要选择和玩家交互，但其背后人口仍使用统计批次。

### 9.3 持久人物AI

以下人物永久独立：

- 玩家和家族成员；
- 历史人物；
- 官员、将领和豪族家主；
- 名医、名匠和豪商；
- 宗教领袖和密探；
- 与玩家形成重要关系的人；
- 任务、契约和重大事件相关人物。

## 10. 延迟实例化

未被玩家详细观察的家庭和设施，以统计数据和稳定种子存在。

玩家进入时，从统计人口中拆出人物：

```text
进入前：农户群体500人
实例化一家五口
进入后：群体495人＋独立人物5人
```

人物生成使用稳定组合：

```text
世界种子
+ 地点ID
+ 家户ID
+ 出生序号
```

离开后：

- 未产生重要关系的普通人物可以重新合并；
- 已认识、雇佣、帮助、伤害或签订契约的人永久保存；
- 历史人物和重要管理者始终独立。

合并时必须把出生、死亡、财产、健康、职业和家庭变化写回群体摘要。

## 11. 设施与生产

设施不是图标，而是有所有权、人员、库存和账本的生产组织。

```text
设施
├─ 所有者
├─ 所在土地
├─ 管理者
├─ 建筑等级和完好度
├─ 最大岗位
├─ 实际雇员
├─ 生产配方
├─ 原料库存
├─ 产品库存
├─ 资金账户
├─ 技术水平
├─ 当前订单
└─ 维护成本
```

实际产出：

```text
实际产出
= 基础产能
× 人员满足率
× 技能效率
× 原料满足率
× 地理适宜度
× 设施完好度
× 治安效率
× 健康效率
× 季节和天气
```

城市粮食、布帛、兵器和船只产量等于所属设施真实产出的汇总，不由城市等级直接产生。

## 12. 主要产业链

### 农业

```text
土地＋种子＋农户＋农具＋耕牛
→ 粮食
→ 口粮、种子、市场、军粮和酿造
```

### 畜牧

```text
草场＋牧民＋种畜＋饲料
→ 马、牛、羊、肉类、皮革和羊毛
```

### 林矿与冶铁

```text
林场→木材→木炭
矿山→矿石
矿石＋木炭＋冶炼工
→ 铁材
→ 农具、武器、甲胄、车辆和船钉
```

### 纺织

```text
桑麻或羊毛
→ 丝线、麻线、毛线
→ 布帛、绳索和帆
```

### 医药

```text
药田或山林采集
→ 药材
→ 炮制和成药
→ 医馆、居民、军队和市场
```

### 造船

```text
木材＋铁件＋麻绳＋桐油＋船匠
→ 渔船、商船、运输船和战船
```

## 13. 市场与跑商

各地地理、人口、产业和战争需求不同，形成真实价差。

```text
生产过剩地
→ 商人收购
→ 商队或船队运输
→ 短缺地出售
→ 居民、设施、军队和政府消费
```

价格取决于：

- 当前库存；
- 当地人口消费；
- 生产成本；
- 军队与建设需求；
- 战争和灾害；
- 道路安全；
- 运输容量；
- 税收和关卡；
- 商人囤积与竞争。

商人可以投资农庄、作坊、仓库、商铺、车马行、港口和船队，也可以签订预购、军需、运输与贷款契约。

## 14. 世界主体的自发建设

世界建设不只依靠玩家点击。

### 农户

根据粮价、种子、工具、地租、税收、灾害和其他职业收入决定开垦、改种、购买耕牛或弃田。

### 工匠

根据订单、售价、原料、工资、贷款和技术决定扩建、招徒、转产或关闭。

### 商人

根据价差、商路、仓储、税收、匪患和资金成本决定投资和运输。

### 豪族

根据家族资产、粮食自给、政治影响、部曲供养和地方安全决定兼并土地、建设庄园、工坊、学塾或坞堡。

### 官府

根据财政、治安、粮食安全、战争、灾害和政绩建设水利、道路、官仓、城防、港口与官营作坊。

建设必须具备土地权利、资金、劳动力、原料、实际需求、运输和政策许可。设施也会停产、破产、废弃、转让、没收或被战争摧毁。

## 15. 城市发展

城市不使用单一发展值直接产生资源。

分别记录：

- 农业；
- 工业；
- 商业；
- 行政；
- 军事；
- 交通；
- 民生和医疗；
- 文化和教育。

综合繁荣度只用于界面阅读，是人口、设施、产业、交通、治安和政策的汇总结果，不是产出的来源。

## 16. 身份、数量与税收

数量决定税基，身份决定税种、义务和减免，收入来源决定具体征收方式。

### 人口群体

普通农户、佃农、商贩、工匠、船工和军户按群体结算。

### 家户、设施和组织

玩家家族、豪族庄园、商铺、商队、农庄、牧场、工坊、船坞、寺观和商会单独记账。

### 重要人物

对俸禄、赏赐、产业分红、土地租金、贸易利润、利息和战利品单独结算。

身份财政示例：

| 身份 | 主要税基 | 主要义务 |
| --- | --- | --- |
| 自耕农 | 土地、收成、家户 | 田赋、户赋、徭役 |
| 佃农 | 收成、工资 | 地租、部分户赋、徭役 |
| 商人 | 交易、利润、货物 | 商税、关税、许可费 |
| 工匠 | 作坊销售和利润 | 作坊税、产品或官府订单 |
| 军户 | 军田和家庭 | 服役替代部分税役 |
| 豪族 | 土地、佃户和产业 | 法定税负、包税、军粮或部曲义务 |
| 宗教组织 | 寺产、捐赠和产业 | 减免或特别贡赋 |

多身份人物分别按照不同收入来源结算，不能选择一个最低税率覆盖全部资产。

## 17. 三级财政

```text
县城或城市财政
→ 州郡或地区财政
→ 中央政府或玩家势力财政
```

基层负责实际征收，按留成和上缴比例分配，不能对同一税基重复征收三次完整税率。

税收形式包括：

- 钱币；
- 粮食、布帛、马匹、木材和药材等实物；
- 徭役；
- 兵役；
- 战时军需征发。

实际税收：

```text
实际税收
= 理论税基
× 法定税率
× 户籍覆盖率
× 行政效率
× 实际控制力
× 纳税意愿
- 减免
- 隐瞒
- 贪污
- 截留
- 运输损耗
```

每个地点区分：

- 法理归属；
- 行政管理；
- 军事控制；
- 税收控制。

占领城市不等于立即获得全部财政，必须控制官府、豪族、户籍、仓库、税吏和运输。

## 18. 人物追随、投靠与起义

关系值只是私人信任的一部分。

人物是否追随需要比较追随、留任、投靠他人或自立的预期结果。

主要因素：

- 私人信任；
- 家世与政治合法性；
- 分类名声；
- 人品和道德；
- 志向与价值观；
- 相性；
- 能力与治理成绩；
- 财富和供养能力；
- 军力和未来胜算；
- 可提供的职位；
- 家族、宗族、朋友和同僚态度；
- 当前忠诚；
- 背叛成本；
- 失败后的个人与家族风险；
- 人物对信息的认知可信度。

相性拆为价值观向量，而不是单一循环数字：

- 名分与实力；
- 仁德与刑法；
- 家族与个人；
- 保守与求变；
- 地方与天下；
- 虔诚与世俗；
- 冒险与谨慎。

追随具有多级承诺：

```text
有好感
→ 同情
→ 暗中帮助
→ 公开合作
→ 成为门客或属官
→ 带家族、部曲和资产投靠
→ 成为核心集团
→ 共同起兵并承担灭族风险
```

## 19. 征兵与兵员批次

大规模军队不生成同等数量的完整AI。

征兵时从真实人口批次转移：

```text
民间人口－征兵人数
在役人口＋征兵人数
```

每个兵员批次记录：

```text
原籍郡县乡镇
来源身份和职业
人数
年龄结构
兵种
训练
装备
士气
家庭依赖程度
征召日期
所属部队
```

一个批次代表约100至1,000人。二十万军队可由数百个批次、数十个部队、数百名代表军官和少量重要人物构成。

## 20. 战争伤亡分配

总伤亡按以下层级分配：

```text
总伤亡
→ 军团
→ 部队
→ 阵列和兵种
→ 兵员批次
→ 批次内已实例化人物
```

权重考虑：

- 参战人数；
- 接敌时间；
- 战场位置；
- 兵种暴露度；
- 装备和训练；
- 士气；
- 是否被包围；
- 撤退路线；
- 将领指挥。

分配必须使用整数守恒方法，保证所有批次伤亡之和严格等于战斗总伤亡。

战损分为：

- 阵亡；
- 重伤；
- 轻伤；
- 被俘；
- 失踪；
- 逃亡；
- 溃散待归队。

历史人物和持久人物单独判定，但必须包含在批次总伤亡中，不能额外叠加。

## 21. 伤亡对原籍的影响

兵员批次保留原籍和原职业，使伤亡能够回写：

- 遗属和孤儿；
- 主要劳动力家庭；
- 农业和工坊岗位缺口；
- 抚恤债权；
- 地方民怨；
- 未来征兵能力；
- 返乡伤兵和残疾人口。

生产下降不按“死亡比例”直接硬减，而是根据损失的具体职业、家庭补位、流民雇佣、工具牲畜和土地撂荒重新计算。

## 22. 军队的地方行动

军队进入乡镇后可以：

- 通过；
- 驻扎；
- 有偿征购；
- 强制征粮；
- 搜捕敌人；
- 占领官署；
- 攻击坞堡；
- 抢掠农庄；
- 焚毁仓库；
- 破坏水利；
- 强征民夫和工匠；
- 保护产业和居民。

统治者可以制定军纪政策，但实际执行还受将领忠诚、军队纪律、补给、军饷、敌意和督战能力影响。

## 23. 农庄、乡镇与坞堡防御

地方生产单位拥有真实防御：

```text
围墙和木栅
壕沟
箭楼
大门
警戒
常备私兵
临时乡勇
武器库存
粮食和水
避难容量
可坚持时间
```

私兵和乡勇来自真实地方人口，动员会减少生产劳动力；伤亡会永久减少原籍人口。

小型坞堡可以击退侦察队、劫掠队、溃军和缺少攻城能力的小部队。面对正规大军时，主要作用是拖延、保护人口、造成损失和等待援军，不应无条件阻挡主力军团。

攻击、征粮和破坏都需要时间。军队停留越久，补给消耗、疫病和遭遇援军的风险越高。

## 24. 地方战斗与真实破坏

地方接触生成统一战斗对象：

```text
进攻者
防守者
地点
军事目标
军令
居民和防御人口
设施
库存
持续时间
伤亡
破坏
物资转移
责任人物
```

战斗结果回写：

- 居民、私兵和军队死亡；
- 伤员、俘虏和逃亡人口；
- 民居、仓库、工坊和水利损坏；
- 粮食、牲畜、工具和商品被抢；
- 土地弃耕；
- 火灾、尸体和疫病风险；
- 地方仇恨与势力声誉。

农庄被攻破不等于所有居民必然死亡。人口应分为死亡、逃亡、被俘和幸存，除非确实发生屠杀或无法逃生的灾难。

## 25. 后台结算与玩家进入战场

玩家远离时，按部队批次、设施和防御数据自动结算。

玩家在附近或担任指挥官时，可以进入乡镇、农庄、坞堡或攻城战场，直接决定进攻、防守、撤离、灭火、护送和投降。

两种模式共享同一战斗状态和结果结构：

- 进入战术地图不会重新生成一场战斗；
- 已经在后台结算的伤亡不能再次计算；
- 战术选择只改变尚未决定的过程；
- 结束后统一汇总到人口、设施和库存账本。

## 26. 战争的长期影响

地区记录：

```text
战争破坏度
流民
弃耕面积
设施损坏
道路安全
尸体与疫病风险
豪族武装化
居民仇恨
粮食短缺
重建需求
```

同一地区不能被军队无限征粮。第一次征粮减少库存，第二次抢掠导致逃亡和停产，第三次经过时可能已无粮可取。

战争行为形成分类声誉：

- 保护百姓；
- 有偿购粮；
- 约束军纪；
- 抢掠和屠杀；
- 焚毁农田；
- 释放俘虏；
- 强征工匠；
- 战后赈济。

农民、商人、豪族、士人、军人和宗教组织对同一行为会有不同评价，并影响投降、补给、招募、贸易和叛乱。

## 27. 算力控制

### 27.1 分层结算频率

| 内容 | 建议频率 |
| --- | --- |
| 玩家和重要人物 | 每日或每时段 |
| 军队行军与战斗 | 每日 |
| 玩家附近市场 | 每日或每旬 |
| 普通市场 | 每月 |
| 职业与迁徙 | 每月或每季 |
| 农业 | 按农时和季节 |
| 出生、成长和继承 | 每月或每年 |
| 远方地区 | 批量低频结算 |

### 27.2 动态拆分和合并

人口批次在征兵、迁徙、疾病、转职、叛乱和人物实例化时拆分。

同原籍、同身份、相近年龄、同职业、同政治状态，且没有重要人物或特殊事件绑定的批次可以合并。

### 27.3 计算复杂度

世界模拟以地点、设施、人口批次、军队批次和重要人物数量为主要复杂度，而不是以总人口为复杂度。

例如二十万军队可以由：

- 5个军团；
- 30至60个部队；
- 200至1,000个兵员批次；
- 100至500名代表军官；
- 数十名完整重要人物。

## 29. 推荐开发顺序

### 第一阶段：人口与设施账本

- 地点人口拆为家户、劳动力和职业群体；
- 建立人口事务和守恒验证；
- 把现有设施标记升级为独立设施实体；
- 设施拥有容量、岗位、所有者和库存。

### 第二阶段：最小生产贸易闭环

```text
农田生产粮食
→ 农户自用与出售
→ 商人收购和运输
→ 战区市场与军队消费
→ 价格、利润和税收变化
```

### 第三阶段：税收与组织财政

- 县级征收和地方留成；
- 官仓与地方金库；
- 州郡上缴；
- 玩家个人、家族、地方政府和势力国库分账；
- 官府建设使用真实财政和物资。

### 第四阶段：NPC自主建设

- 农户、工匠、商人、豪族和官府提出建设；
- 根据利润、生存、声望、战略和政策决定；
- 支持合资、借贷、许可和所有权。

### 第五阶段：兵员来源与战争损失

- 征兵从真实人口批次抽取；
- 建立兵员批次与原籍；
- 伤亡回写家庭、职业、生产和税收；
- 伤兵、俘虏、逃亡和退伍闭环。

### 第六阶段：地方军事接触

- 军队征购、征发、抢掠和驻扎；
- 农庄、乡镇与坞堡防御；
- 真实库存转移和设施破坏；
- 后台结算与战术地图共享结果。

### 第七阶段：延迟人物实例化

- 从群体中拆出家庭和代表人物；
- 稳定种子恢复；
- 人物晋升、持久化与重新合并；
- 玩家关系、契约和事件阻止人物被遗忘。

### 第八阶段：更完整城市圈

- 根据地理和历史资料制作多个城市圈档案；
- 加入林矿、纺织、畜牧、医药和造船产业链；
- 加入港口、水运、商会和跨区财政；
- 扩大至135年以后多年代持续模拟。

## 30. 总验收标准

目标世界架构完成后，应满足：

1. 城市不直接凭空产生商品；
2. 设施没有人员、原料或运输时不能正常生产；
3. 人口、物资、兵员和财政能够通过自动测试守恒；
4. 战争死亡真实减少人口和未来产出；
5. 征兵来源可以追溯到县镇、身份和职业；
6. 军队抢夺的物资来自真实库存；
7. 战术地图的破坏永久回写世界；
8. 玩家观察地点不会创造或重随机人口；
9. 普通人口能够以统计批次运行，重要人物能够独立行动；
10. 地理决定资源潜力，历史决定初始传统，人物和市场决定实际发展；
11. 农户、工匠、商人、豪族、官府和军队在同一经济世界中互相影响；
12. 玩家可以通过身份、家族、产业、政策、财政和战争改变世界，但不能绕过真实成本。

## 31. 最终总结

```text
土地和历史资料给出生产潜力
→ 家庭、组织和人物取得土地与设施
→ 真实人口提供劳动力与技能
→ 设施消耗原料并生产商品
→ 商人和运输网络完成流通
→ 居民、政府和军队形成需求
→ 税收和利润支持建设与战争
→ 战争、灾害和政策改变人口与设施
→ 家族和后代继承真实结果
```

项目的独特性不在于单独拥有城市建设、跑商、家族、人物扮演或战争，而在于这些玩法共享同一套人口、土地、设施、库存、财政和历史账本。
