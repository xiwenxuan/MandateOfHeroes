# M14 任务书：200—500人真实村庄与家庭生活闭环

## 一、阶段目标

建立一个可脱离场景、连续确定性运行至少一年的基层村庄切片。村庄人口必须落实为
200—500名永久人物、数十个真实家户和可审计的基层设施；关注等级只能改变报告精度，
不能创建、删除、合并或重随机人物。

本阶段承接：

- `TASK_M12_PERMANENT_POPULATION_AND_ATTENTION.md` 的首个基层验收切片；
- `WORLD_SIMULATION_FOUNDATION.md` 的第二阶段“基层家庭与设施账本”；
- `GAME_SYSTEMS_MASTER_AND_STATUS.md` 当前推荐建设顺序第2项。

## 二、本阶段范围

### 2.1 永久人口与家户

- 支持按稳定种子生成200—500名具体人物，默认300人；
- 每人具有永久ID、出生地、当前地点、家户、职业、劳动能力和下一独立事件摘要；
- 家户保存成员、家主、粮食、种粮、土地、农具、财富、债务和税役状态；
- 出生、婚姻、死亡、继承和迁徙不丢失原人物身份。

### 2.2 村庄与基层设施

- 村庄保存家户目录、公共粮仓、税粮、劳役和人口汇总缓存；
- 首批设施包括农地、水利、粮仓、铁匠作业点、医护点和里社；
- 设施具有地点、管理者、容量、完好度和库存，不是单纯地图图标；
- 铁匠、医者和里正缺位必须影响农具、照护或税役执行。

### 2.3 一年生活闭环

按月结算以下事实：

```text
家庭劳动力与农具、水利
→ 播种与收获
→ 家庭粮食消费和公共粮仓救济
→ 税粮、劳役和临时征发
→ 健康、疾病与照护
→ 出生、婚姻、死亡、继承与迁徙
→ 回写永久人物、家户、村庄缓存和可审计账本
```

本阶段农业只承担村庄生活闭环的基础粮食核算，不替代下一阶段的具体作物、仓储、
市场和完整生产链。

### 2.4 关注报告

- 无关注只返回村庄摘要；
- 普通关注返回异常家户和关键变化；
- 深度关注返回具体家户、人物和近期账本；
- 构建报告必须是只读操作，前后世界快照完全一致。

## 三、存档与兼容

- 世界快照升级至V6；
- 提供V5→V6顺序迁移，旧人物和家户不得丢失；
- 迁移时从既有家户成员表补全人物的家户ID；
- 旧人口批次仅作兼容数据，新村庄全部由永久人物构成；
- 新增集合在旧存档迁移时显式初始化。

## 四、验收条件

1. 同一种子和人口规模两次生成的永久人物、家户和初始资源完全一致。
2. 默认村庄拥有300名永久人物，允许的输入范围为200—500人，且不存在抽象人口批次。
3. 每名村民恰好属于一个家户，人物家户ID与家户成员表双向一致。
4. 连续运行一年后，全部初始人物ID仍存在；死者只退出生活调度，不删除记录。
5. 播种、收获、消费、救济、税粮、劳役、征发、婚姻和迁徙写入具体人物或家户账本。
6. 人口、家庭粮食、公共粮仓和税粮汇总无负数，人口地点汇总通过审计。
7. 医者或铁匠离开会产生可重复验证的健康或农具连锁影响。
8. 无关注、普通关注和深度关注得到同一世界事实，报告构建不修改存档。
9. V6快照往返保留人物、血缘、家户、设施和村庄账本；V5能够顺序迁移。
10. 全工程编译、核心回归、受控Unity测试和`git diff --check`分别具有明确结果。

## 五、明确不包含

- 县、郡、州和天下人口的正式分区存储；
- 水稻、小麦、粟黍等完整具体作物与市场产业链；
- 完整军队编制中的长期服役，只实现可追溯的基层临时征发义务；
- 玩家逐日操作播种、除草或每个村民的完整AI；
- 村庄场景中的逐人寻路、动画和住宅美术。
