# M25-P31 创伤手术、永久伤残与医疗退役任务书

## 一、阶段目标

承接 M25-P30 的永久伤情与冻结诊疗计划，为需要外科处置的具体伤员建立第一条正式闭环：

```text
数据定义伤型与手术方案
→ 接诊时冻结是否需要手术
→ 具体医者投入更高医术门槛、真实药材和工时
→ 手术治疗、库存事务、健康变化逐项留痕
→ 由接诊时已冻结的严重度确定永久伤残
→ 伤残写回具体人物劳动能力并保留开闭值
→ 完成后患者在诊疗地医疗退役，原救护队独立返队
```

本阶段不通过人物关注、读档顺序或临时随机重新决定结局，也不删除、合并或替换人物。

## 二、数据驱动手术合同

1. 手术方案使用开放稳定命名空间 ID 和世界持久数据定义，不使用固定手术类型枚举。
2. 首个核心方案是创伤清创复位，定义适用伤型、最低严重度、最低医术、240分钟工时、3单位
   真实草药、目标健康和永久伤残阈值；新增普通方案或 MOD 方案不要求升级存档结构。
3. 伤型定义可以引用手术方案。新住院在接诊时把具体方案 ID 冻结到伤情记录，并把手术协议插入
   住院计划；以后修改内容定义不得改变已经接诊的疗程。
4. 野战医院顺序为“稳定伤情→手术→感染控制（若需要）→恢复”；既有医馆为
   “手术→感染控制（若需要）→恢复”。

## 三、永久伤残与人物影响

1. 首个永久结局使用稳定 ID `military_injury_outcome.permanent_mobility_impairment`。
2. 当接诊严重度达到冻结方案阈值时，完成手术后永久降低人物劳动能力3,000基点；伤情记录保存
   劳动能力开值、闭值、惩罚量和具体手术治疗引用，禁止重复扣减。
3. 该结局不修改人物先天禀赋、不伪造通用词条，也不删除其技能、家庭、关系或永久身份。
4. 伤残者不再恢复现役。完整疗程结束后使用医疗退役出院策略，人物留在诊疗地点；原救护队沿
   真实道路独立返回来源军队，全部到达后患者军役转为 `Retired`、救护队恢复 `Active`。
5. 非伤残患者继续沿 M25-P28 的患者与救护队共同返队合同。

## 四、现实尺度与后续扩展

- 本阶段的真实消耗只覆盖药材、医者工时、床位、健康和人物劳动能力；诊疗点被视为已具备基础
  可复用器具能力。
- 可复用手术器具、布帛缝合物、器具耐久、助手、麻醉和术后护理必须在后续生产/医疗任务中作为
  正式产品、设施能力和工时扩展，不能在本阶段凭空伪造一次性库存。
- 伤后死亡涉及人物死亡、军役、家庭继承与人口账；跨院转运涉及床位、患者旅行、药库和责任
  迁移。二者分别保留为后续任务，不在本阶段静默实现。
