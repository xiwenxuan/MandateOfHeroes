# M24-P2任务书：百万家庭库存、县级市场、官仓赈济与跨县运输

## 一、阶段目标

在M24-P1“人口—家庭—土地—粮食—压力死亡”闭环上拆分粮食所有权与交换过程：

```text
具体农业劳力形成县级收获
→ 税粮进入县仓，余粮进入具体农业家庭
→ 家庭先消费自有粮食
→ 同县余粮家庭与缺粮家庭进行真实粮食和现金交换
→ 县仓向仍缺粮家庭赈济
→ 同郡余粮县向缺粮县进行有限运输
→ 到货、自然损耗和途中口粮分别记账
→ 最终家庭满足度影响生育和具体人物压力死亡
```

本阶段继续使用独立百万世界压力工具，不修改正式V28存档，也不声称已运行百万份完整NPC AI。

## 二、必须实现的合同

1. 每户保存自有粮食、现金、累计购入、售出、税粮、县内赈济、运输赈济、未满足口粮和最近满足度。
2. 新婚家庭的启动资产只能从双方原家庭按参数转移；绝户资产进入所在县官仓与公共现金账户。
3. 县内市场买量等于卖量，买方现金减少等于卖方现金增加，交易不得超过库存、缺口或支付能力。
4. 税粮从实际净收获中扣除并进入县仓；赈济只能从现有县仓发放。
5. 跨县赈济只匹配M13相同郡国父级下的县，受到承运劳力、容量、储备和年度路线数约束。
6. 每笔运输满足：`发运量 = 到货量 + 自然损耗 + 承运途中口粮`。
7. 市场、税粮、赈济、婚姻资产和绝户归公均为内部转移，不得改变全局粮食或现金。
8. 同一输入、参数版本、主种子、稳定ID与年度必须产生相同结果。

## 三、全局守恒式

```text
期末家庭粮食 + 期末县仓粮食
= 开局粮食 + 毛收获
 - 田间与留种损耗 - 仓储腐败 - 地方冲突征夺
 - 家庭实际消费 - 运输自然损耗 - 承运途中口粮
```

```text
期末家庭现金 + 期末县级公共现金 = 开局家庭现金
```

## 四、验收条件

1. M24-P2小规模双跑通过人口、家庭经济、市场、官仓和运输确定性检查。
2. 100万开局连续运行50年，候选进程不超过285秒。
3. 每户粮食和现金非负；消费、销售和购买不超过真实约束。
4. 每县年度粮食账、全局粮食账、全局现金账和逐笔运输账全部守恒。
5. 形成年度县账、家庭经济二进制文件、运输流水、SHA-256摘要、内存与耗时证据。
6. 全工程编译、核心测试、受控Unity EditMode测试、`git diff --check`与范围审阅分别通过。
