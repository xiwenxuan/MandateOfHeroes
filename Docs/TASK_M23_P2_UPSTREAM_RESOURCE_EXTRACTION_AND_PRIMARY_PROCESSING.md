# M23-P2 上游资源采集与初级加工任务书

## 1. 阶段目标

在 M23-P1 的组织工坊、军械制造与维修底座上，建立第一条不依赖新增开局物资的真实上游补给链：

```text
既有矿体/林地资源事实
→ 真实人物在同地采掘场或林场执行耗时采集工单
→ 矿石、木料进入组织静态仓并保留来源
→ 木料经炭窑形成木炭与灰
→ 矿石和木炭经冶炼形成铁料与炉渣
→ 既有组织工坊继续制造、运输、入库和维修军械
```

本阶段是林矿与冶铁的首个可审计切片，不把资源创世、多矿脉勘探、运输工作面、事故、品质成长或完整州郡产业网宣称为完成。

## 2. 必须完成

1. 增加数据驱动的铁矿石、木炭、草木灰和炉渣产品，以及烧炭、块炼铁配方与对应生产方法；所有输入、主产物和副产物质量守恒。
2. 增加持久 `ResourceBodyState`：稳定资源种类 ID、输出产品 ID、地点、来源等级、生成规则版本、初始/剩余/预留数量、品位、开采难度和设施要求。
3. 增加持久采集工单和资源账：工单保存组织、场地、仓库、管理者、具体工人、控制模式、时间、数量和输出批次；创建时预留资源，完成时原子扣减资源并生成可追溯批次。
4. 采集必须校验真实人物存活、同地、组织成员、劳动能力、设施和资源兼容；非法命令不得部分写入。
5. 中山原型增加一处铁矿体、一处林地，以及矿场、林场、炭窑和冶炼场；沿用组织静态仓，但资源体与设施保持不同稳定身份。
6. 把采集到期结算接入统一世界日推进；同种子、同世界和同命令产生相同工单、账目、批次与快照。
7. 世界存档顺序升级到 V16；V15 迁移仅建立空资源/采集集合并刷新内容清单，不倒推或伪造历史开采。
8. 更新开发观察台、系统总纲、生产设计、世界模拟、确定性存档、README 与 Skill 任务路由，使实现状态和限制一致。

## 3. 不在本阶段

- 地质创世、多矿区—矿床—矿脉层级生成、勘探与角色认知；
- 选矿、搬运工作面、排水、支护、事故、工具磨损、燃料热值和炉温；
- 林木逐年生长、林权、季节采伐和生态退化；
- 养殖、屠宰、皮革、角料和胶的真实上游链；
- 材料多维品质、工匠技能成长、设施升级和科研改良；
- 自动排产、多段货运、押运风险、动态价格和军需委任。

## 4. 验收用例

- 原型世界包含稳定、非负且来源明确的铁矿体和林地；观察或切换界面不生成资源。
- 合法采集立即预留正确资源量，到期前无产出；到期后剩余量、预留量、输出批次、库存事务和资源账严格平衡。
- 超量采集、错误地点/组织/设施、死亡或不在场人员、重复工人均被拒绝且世界快照不变。
- 采得木料可经烧炭配方产生木炭和草木灰；采得矿石与木炭可经冶炼产生铁料和炉渣。
- 新产铁料和木料可继续进入 M23-P1 军械制造配方，证明上游与工坊共用同一产品批次事实。
- 活跃采集工单与完成工单经 V16 快照往返保持人员、预留、资源和批次引用。
- V15 迁移后资源体、采集工单和资源账为空，不制造过去的开采记录。
- 相同命令序列得到相同快照。
