## 三、来源与异文处理

原始户口事实采用公共领域古籍《后汉书》卷三十·郡国二。维基文库《四库全书》本
用于原文定位，现代公开校录表只用于数值交叉核对，不复制其完整表格、公式或注释。

### 3.1 河间“郡/国”

- 维基文库《四库全书》本网页转录作“河间郡”；
- 其他公开古籍转录、现代校录表和当时诸侯王沿革作“河间国”；
- 本批行政类型采用`kingdom`、显示名采用“河间国”，置信度记为`medium`；
- 原始户口数93,754户、634,421口在各转录中一致；
- 后续获得可靠影印页或版本校勘时，只更新证据和显示判断，不修改稳定行政ID。

现代校录表把“清河国”转录为“清川国”，但户口数字与《后汉书》清河国条目一致。
本项目采用原典名称“清河国”，不继承该转录标签。
