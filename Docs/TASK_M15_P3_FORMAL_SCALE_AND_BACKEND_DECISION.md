# M15-P3 任务书：正式规模压力与后端决策

## 一、任务定位

本任务承接M15-P0至P2，以10万和100万永久人物分别运行SQLite、紧凑分区二进制和混合
候选，形成正式容量证据与后端建议。P3允许得出“当前证据不足，需要优化”的结论；不得
为了宣称通过而延长300秒硬超时、缩减永久人物字段、跳过检查点或把失败候选写成成功。

P3不替换V6存档、不把候选依赖接入Unity、不承诺1000万以上人口，也不直接进入正式迁移。

## 二、运行矩阵

每个矩阵单元使用独立进程、独立工作目录和独立300秒看门狗：

| 人口档 | SQLite | 分区二进制 | 混合 |
|---|---|---|---|
| 100,000 | 独立运行 | 独立运行 | 独立运行 |
| 1,000,000 | 独立运行 | 独立运行 | 独立运行 |

候选不得在同一压力进程中串行叠加。运行顺序不进入摘要；每个单元均读取相同M13输入、
种子、P2确定性迁徙样本和时间窗。

## 三、每个单元的操作合同

1. 审计105项人口来源、1182项县级目录和稳定地理；
2. 生成指定数量的永久人物、家户、父母、组织、地点和到期事件；
3. 写入一个候选后端并建立索引；
4. 执行人物、家户、父母/子女、组织和劳动力组合查询；
5. 推进绝对日1、30和365，只处理到期节点并批量回写；
6. 验证出生、死亡、迁徙和地点人口守恒；
7. 生成增量保存和完整检查点，执行恢复；
8. 展开并释放少量关注人物；
9. 输出确定性摘要、体积、耗时、托管堆和峰值工作集。

## 四、成功与失败证据

单元状态只能是：

- `passed`：完整操作合同结束、结果JSON存在、守恒和摘要通过；
- `failed`：进程主动报告异常并保留阶段、日志、退出码和资源采样；
- `timed_out`：300秒到期后只终止该单元PID树，并保留阶段、峰值工作集和日志尾部；
- `blocked`：缺失依赖、磁盘空间或外部环境阻止启动，必须附具体原因。

失败、超时和阻塞是有效决策证据，但不能计为候选通过。100万档即使失败也必须生成外层
机器可读结果文件，不能只留下口头说明。

## 五、指标

每个矩阵单元至少记录：

- 数据生成、初写、日/月/年推进、查询、增量、检查点和恢复耗时；
- 初始与期末人物、家户、事件、出生、死亡、迁徙和写回数量；
- 物理存储、增量和检查点字节数；
- 托管堆起点、期末值及进程峰值工作集；
- 人物、家户、子女、组织和劳动力查询结果与延迟；
- 到期扫描数、分区加载数和守恒结果；
- 检查点前后核心与事件摘要；
- 进程PID、起止时间、退出码、超时状态、日志和结果路径。

## 六、决策规则

1. 优先排除不能在100万档完成核心操作合同的方案，但保留其可优化原因。
2. 速度、体积、查询、恢复、依赖、迁移复杂度和跨平台风险必须共同评价，不能只看单项。
3. 若没有候选完整通过100万档，结论必须是“证据不足，需要优化或新增实验”，不得正式
   选择后端。
4. 若至少一个候选通过，可给出推荐顺序，但正式接入、V6迁移和发布依赖仍需新任务书及
   用户确认。
5. 100万结果只能用于M15范围内容量判断，不能外推已经支持1000万或累计5000万永久
   人物；157年前后约5650万只作为史料参考，不是技术压力档位。

## 七、验收条件

1. 六个矩阵单元均有机器可读外层结果；通过单元另有完整候选结果JSON。
2. 每个外部进程具有PID、日志、退出码、峰值工作集和不超过300秒的硬超时。
3. 10万与100万人物ID保持唯一，关注、分区和恢复不删除、合并或重随机人物。
4. 通过单元完成P2全部守恒、查询、调度、增量和检查点合同。
5. 同一人口档的通过候选使用相同输入，确定性窗口计数一致；摘要差异必须能够解释为
   候选事实错误，否则该单元失败。
6. 决策报告逐项列出通过、失败、超时或阻塞，不隐藏不利结果。
7. 报告明确是否具备进入正式存储任务的证据，并给出下一步而非直接修改V6。
8. P0、P1、P2回归、全工程编译、核心测试、受控Unity测试、`git diff --check`和差异
   审阅分别具有明确结果。

## 八、明确不包含

- 正式存储适配器、V7存档、V6迁移和发布包依赖；
- 1000万和累计5000万永久人物压力；
- 为通过压力而删除人物、家户、父母、事件或查询字段；
- 超过300秒继续等待同一个外部进程；
- 把容量实验等同于完整NPC AI、生产、战争或场景表现已经支持该人口规模。

## 九、完成定义

六个矩阵单元、汇总报告和项目级验证均有明确证据后，M15-P3可以完成。若100万档没有
候选完整通过，P3仍可作为“证据不足”的决策阶段完成，但M15不得进入正式后端迁移。
