# M26-P0A 可玩 Demo 缺陷修复任务书

## 一、任务定位

本任务是 M26-P0 可玩 Demo 主循环的纠错阶段，不扩大玩法范围、不升级存档版本，
也不继续扩展 M25 医疗后台。目标是修复首次代码审阅确认的开局、人物接管、有限认知、
交易可用性和随军治疗五类合同偏差。

## 二、缺陷与修复合同

1. 军人开局不得先接受任意地点、再静默移动到军队；界面只显示真实军队集结地，
   模拟服务同时拒绝非法地点请求。
2. 接管现有人物只设置玩家控制引用，不得根据人物 ID 文本推断职业，也不得补造村庄、
   土地、粮仓或改写全家成员职业与所在地。
3. 太平道历史传闻只在第十日后、人物位于广宗或下曲阳且停止旅行时出现；这表示人物
   在相关地区亲历或直接获知，不能向远方人物泄露全图历史信息。
4. 随军治疗必须检查同地军医和军队停止行军；治疗命令必须以玩家本人为目标。底层治疗
   失败时不得返回成功，也不得消耗一天时间。
5. 商人买入行动必须按当前地点的实时价格、市场库存和人物载重计算，不能使用固定资金门槛。

## 三、实现范围

- `NewGameSetupService`：合法落点查询、现有人物原位接管、情境行动条件与反馈；
- `SimulationDashboard`：按身份展示合法开局地点；
- `MedicalSystem`：新增指定伤员的军队治疗入口，复用原有正式药材、军医、权限和病案账；
- `WorldKernelTests`：为五类缺陷增加回归覆盖；
- 原 M26-P0 任务书：补充纠错记录和当前证据。

本任务不新增持久字段、不改变永久人物 ID、不删除或合并人物，不建立 Demo 专用医疗、
贸易或知识账。

## 四、验收标准

- 非法军人落点被拒绝，合法军人落点与军队位置一致；
- 接管现有农户前后人口、家庭、村庄、设施和成员关系不被改写；
- 远离广宗战区的人物看不到太平道选择，相关地区人物可以看到；
- 没有同地军医时随军治疗不可用、执行失败且时间不推进；
- 多名伤员同时存在时，玩家治疗明确写入玩家病案并恢复玩家服役状态；
- 买入按钮的可用性与实际成交使用同一动态价格、库存和载重条件；
- 全工程编译、M26 定向核心测试、完整核心分组回归、受控 Unity 测试与
  `git diff --check` 分别取得明确结果。
