# M24-P1验收报告：百万家户粮食、土地承载与人口压力闭环

## 一、结论

M24-P1通过。

在M24-P0的同一人口参数、主种子`14000024`和140年开局上，本阶段继续生成恰好
1,000,000名具体永久人物，并加入家户口粮需求、县级固定可耕地、具体农业劳力、收获与
损耗、疾病和地方冲突压力，从140年连续运行50年至190年。

50年后在世人口为1,275,407人，累计永久人物2,694,097人。相对不受粮食约束的M24-P0
基线，在世人口减少188,527人；粮食满足度同时降低生育并把饥荒、疾病、地方冲突死亡落实
到171,276名具体人物。死亡人物仍保留永久身份和死亡原因，未来原定自然死亡到期不会重复
扣减人口。

本结果证明第一层“人口—家户—粮食—土地—压力死亡”能够在百万规模持续闭环。它不是
逐块农田、市场价格、完整瘟疫传播、历史战争或百万完整NPC AI验收。

石制、作物结构或真实产量的历史断言。
