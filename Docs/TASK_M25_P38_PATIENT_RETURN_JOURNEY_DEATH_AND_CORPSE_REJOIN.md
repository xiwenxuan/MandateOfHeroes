# M25-P38 患者返军途中死亡、遗体随队返军与归队结案任务书

## 一、阶段目标

承接 M25-P28 的患者与救护队返军、M25-P33—P37 的永久人物死亡闭环，处理已经完成后方治疗、
释放床位并开始真实返军旅程后，患者在尚未与来源军队会合前伤情复发死亡的情形：

```text
患者与救护队已沿明确道路返军
→ 数据政策冻结返程复发、健康开闭值和死亡时剩余里程
→ 永久人物、人口、军籍、家庭继承和组织抚恤原子闭合
→ 最后诊疗设施与主治医者保留医疗责任快照
→ 患者原返程旅程继续表示遗体随队返军
→ 来源军队保持冻结，直至遗体和全部救护队员会合
→ 遗体归抵军队、救护队恢复现役、住院与后送记录结案
```

## 二、本阶段范围

1. 存档升级至 V60，新增数据驱动返军途中恶化政策、返军死亡情境、遗体随队策略、返军死亡结案、交叉引用和次日启用边界。
2. 只处理已经完成治疗、住院处于 `Discharged`、后送处于 `ReturningToArmy`，且患者本人仍有非零剩余里程返程旅程的情形。
3. 结案冻结伤情、住院、后送、来源军队、最后诊疗设施、最后主治医者、返程路线、起终点、返程开始日、患者旅程、死亡时剩余里程和健康开闭值。
4. 死亡复用既有永久人物、人口、军籍、家庭继承、家主继任和原军队组织抚恤闭环；最后照护组织与抚恤组织可以不同，不得强行合并两种责任。
5. 患者死亡后不删除、不重建返程旅程；该旅程继续表示原救护队护送遗体，死者不再消耗个人行粮。
6. 遗体和全部救护队员抵达前来源军队不得行军；全部抵达后患者军籍保持死亡、救护队恢复现役，住院和后送记录一次结案。
7. V59→V60 只补核心未来政策、空结案集合、空引用和次日启用边界，不根据旧返程、人物健康或既有死亡倒推历史。

## 三、验收条件

- 返军途中死亡冻结非零剩余里程、最后照护责任和健康开闭值，患者永久死亡但原返程旅程继续存在。
- 死亡后军队仍被返军任务冻结，死者不消耗行粮；遗体和救护队抵达后军队解冻、救护队恢复现役、住院与后送结案。
- 等待期不足、患者旅程缺失、错误阶段、权限不足、家庭或财政不完整时不得产生部分死亡事实。
- 篡改路线、剩余里程、健康开闭值、最后设施/医者、住院/后送引用或遗体策略时世界校验失败。
- V60 往返保存完整闭环；V59 迁移不制造返军死亡。
- 全工程编译、聚焦核心、完整核心、受控 Unity、`git diff --check` 和范围审阅分别完成。

## 四、明确不包含

- 救护队员在返军途中死亡、受伤、逃亡或被俘；
- 患者返程旅程已经结束、但仍等待其他队员时发生的死亡；
- 遗体改道、棺木、家属接回、安葬、讣告传播和关系反馈；
- 医疗事故过失比例、司法追责、额外赔偿或抚恤欠款；
- 自动每日死亡调度、动态追赶移动军队、多段返程和玩家医疗界面。
