## 三、来源与缺项处理

原始行政和户口事实采用公共领域古籍《后汉书》卷三十三·郡国五。维基文库
《四库全书》本用于原文定位，现代公开校录表只用于数值交叉核对与显式补正，
不复制其完整表格、公式或注释。

### 3.1 辽东郡人口

- 原文为64,158户、81,714口；
- 户口比约1.27，且口数与前一条辽西郡完全相同；
- 现代校录据辽西郡、乐浪郡户口比推定人口脱二十万位，采用281,714口；
- 数据保留原文81,714口，并把281,714口单独写入修正字段。

### 3.2 玄菟郡户数

- 原文为1,594户、43,163口；
- 户口比约27.08，明显异常；
- 现代校录比较乐浪郡并在11,594与9,594候选中采用9,594户；
- 数据保留原文1,594户，并把9,594户单独写入修正字段。

### 3.3 辽东属国缺项

- 原文列出六城但独缺户数和口数，《四库全书》本考证也明确指出缺项；
- 原始户数、口数均保存为空，不得写0；
- 现代校录按辽东郡、辽西郡每城平均值估算22,986户、116,592口；
- 估算值标为`M`，只作为后续空间权重候选，不冒充史籍原值。
