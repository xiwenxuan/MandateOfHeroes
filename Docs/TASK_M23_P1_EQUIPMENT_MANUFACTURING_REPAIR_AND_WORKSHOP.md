# M23-P1 军械制造、维修与组织工坊任务书

## 1. 阶段目标

在 M19 产品批次库存与加工订单、M11 军械库以及 M23-P0 采购运输闭环上，建立第一条可审计的军械制造与维修链：

```text
组织原料批次
→ 真实人物在组织工坊下达并执行制造订单
→ 耗时结算为成品军械批次
→ 商队从工坊库存装运并交付军械库
→ 损坏军械预留维修名额与材料
→ 工坊耗时维修后恢复军械库可用数量
```

制造必须复用通用加工订单，不建立一套只供军事使用的生产规则；维修因操作对象是军械库资产而使用独立订单，但材料仍来自同一产品批次账。

## 2. 必须完成

1. 核心生产内容包增加铁料、木料、皮革和角料四类稳定产品 ID，以及环首刀、木盾、长矛、角弓、箭束和札甲六种守恒制造配方。
2. 增加组织工坊状态：稳定类型 ID、地点、所属组织、真实管理者、库存容器、容量、完好度和设施标签。
3. 将现有 `ProcessingWorkOrderState` 扩展为家庭或组织二选一的通用订单；两类订单共享批次预留、时间、控制模式、结算和库存流水。
4. 组织制造订单只能使用同组织、同地点、标签兼容的工坊与库存；管理者必须存活、在场并属于该组织。
5. 中山商号原型增加静态工坊仓和可追溯原料期初批次；制造成品保留来源订单和来源交易。
6. 采购允许真实承运人从同组织、同地点的静态工坊仓装货；运输容量、付款、旅程和军械库入库合同继续成立。
7. 军械定义以稳定产品 ID 配置维修材料、单位耗材、耗时和设施标签，不以固定类别枚举写死维修表。
8. 增加永久维修订单与损坏数量预留；创建时预留材料和损坏军械，完成时原子消耗材料、减少损坏数量、增加可用数量，并写入两套账。
9. 世界存档顺序升级到 V15；V14 迁移只建立空工坊/维修集合、补齐新字段和刷新内容清单，不伪造历史制造或维修。
10. 更新演示入口、总纲、生产、战争、世界模拟、存档说明、README 与 Skill 路由。

## 3. 不在本阶段

- 矿山开采、冶炼、伐木、制革和养殖的上游完整生产链。
- 炉温、燃料、边角料、材料品位、工匠技能成长和逐件品质差异。
- 独立铁匠铺、木工作坊、弓坊和甲坊的建筑施工过程；本阶段使用带多标签的综合工坊原型。
- 多段自动寻路、押运战斗、劫掠、保险、动态竞价和税关。
- 军械翻新等级、维修失败、报废、拆解回收和替换零件。
- 完整玩家 UI 美术与所有 NPC 的自动排产策略。

## 4. 验收用例

- 内建内容与核心 JSON 的版本、哈希和数量一致；新增六种配方均满足质量守恒。
- 合法组织订单立即预留正确原料，未到期不产出，到期后消耗原料并生成可追溯成品批次。
- 原料不足、错误组织、错误地点、错误设施标签或管理者不在场时拒绝且无部分写入。
- 家庭加工旧用例继续通过；不同控制模式不改变相同订单的世界事实。
- 新制造军械能够从静态工坊仓装入真实商队，抵达后只入库一次。
- 合法维修立即预留损坏数量和材料，到期前不改变可用量，到期后材料、损坏量、可用量和账本精确平衡。
- 超量维修、材料不足、军队不在工坊地点或管理者不合格时拒绝且无部分写入。
- V15 快照往返保留活动/完成制造及维修事实；V14 迁移不制造历史订单。
- 相同种子和相同命令得到相同订单、批次、流水和快照。
