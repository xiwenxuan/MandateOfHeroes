# 家族组织中心与历史家族参考 V1

本目录是`FAMILY-ORGANIZATION-CENTER-AND-HISTORICAL-FAMILY-REFERENCE-V1`的正式成果集。

建议阅读顺序：

1. `01_...关系规范`：先区分Clan、Branch、Household、FamilyOrganization和FamilyCenter；
2. `02_FamilyCenter设计规则`：读取中心成立条件、状态、范围和20项冻结决策；
3. `03_...Action_Matrix`：确认个人与组织动作权限；
4. `04`—`07`：读取历史宗族、剧本、初始化候选与资产证据；
5. `08`—`10`：读取184洛阳人物、7组织审计和中心候选；
6. `11_...开发参考报告`：查看结论、限制和后续开发阶段。

这些成果是开发参考，不会自动生成FamilyOrganization、Household、庄园或FamilyCenter。
