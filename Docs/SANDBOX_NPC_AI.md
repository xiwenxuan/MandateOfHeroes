# 人物志沙盒AI方案

## 1. 定位

本系统借鉴《鬼谷八荒》以性格、关系和定期自主行动塑造NPC生活的优点，但服务于本项目的
历史世界、职业身份和数代家族模拟。

这里的“AI”首先是可离线、可解释、可复现的游戏决策系统，不是让大语言模型直接控制NPC。

## 2. 决策结构

每个完整人物保存：

```text
PersonMind
  personality        // 稳定倾向
  needs              // 当前需要
  goals              // 中长期目标
  memories[]         // 亲历或获知的重要事实
  beliefs[]          // 人物认为真实的信息
  relationships[]    // 多维关系
  commitments[]      // 官职、契约、誓言和债务
```

首版人格维度：

- 野心：追求职位、名望和支配力。
- 顾家：愿意为亲属投入时间与资源。
- 社交：主动交友、拜访和经营关系。
- 冒险：面对旅行、战争和投资风险的接受度。
- 仁厚：救济、宽恕和避免伤害他人的倾向。

首版需要维度：

- 生计
- 家庭
- 身份
- 财富
- 关系
- 战争压力

全部采用`0—10000`整数值，避免浮点差异。

## 3. 月度重点与具体行动

AI分为两步：

1. **月度重点**：决定这个月最在意什么。
2. **具体行动**：根据地点、身份、资源和情报选择可执行行为。

首批月度重点：

| 重点 | 后续具体行动示例 |
|---|---|
| 维持生计 | 务农、做工、求职、借粮、迁徙 |
| 照顾家庭 | 赡养、治病、婚配、教育、分家 |
| 提升身份 | 投仕、应募、考试/察举、拜师、求荐 |
| 积累财富 | 贸易、置地、开工坊、放贷、储粮 |
| 维护关系 | 拜访、赠礼、调解、结义、谢恩 |
| 应对战争 | 参军、避难、囤粮、护送、投靠 |

首版已经实现月度重点选择，并接入务工、交易、拜访、求仕、参军、避难六类行为意图。
行为意图先经过`NpcActionValidator`验证，再交给对应领域系统结算。

当前实现进度：

- 务工：已结算确定性收入、口粮与生计需要。
- 交易：已结算基于所在地粮价波动的确定性盈亏。
- 避难：已连接直达道路并创建真实旅程。
- 拜访：已接入有方向的好感、信任与敬重变化。
- 求仕：已接入所在地官署、入门职位和容量验证。
- 参军：已接入所在地军事组织、士卒职位和成员记录。

## 4. 评分

```text
重点分数 =
当前需要
+ 人格倾向
+ 身份与处境
+ 关系与承诺
+ 情报判断
+ 小幅确定性扰动
```

确定性扰动来自命名随机流：

```text
npc_ai / person_id / month_index / monthly_focus / action_id
```

增加其他系统的随机抽签不会改变NPC原有决定。

## 5. 有限认知

AI读取的是`Belief`，不是无条件读取全局事实。

```text
Belief
  subject_id
  claim
  perceived_value
  confidence
  source_id
  learned_day
  expires_day
```

同一场战争可以同时存在事实、官报、商旅传闻和敌方宣传。密探、商人和官吏的价值，
来自他们能够更早获得或验证消息。

## 6. 多维关系

```text
Relationship
  affection
  trust
  fear
  respect
  obligation
  shared_interest
  political_alignment
  intimacy
```

亲属、夫妻、师徒、主从、同僚、债权和仇敌是关系类型，不等于单一好感值。

## 7. 家族继承

人物死亡后可以继承：

- 财产与债务；
- 恩义与血仇；
- 门生、故吏和商业关系；
- 家传技能、秘密和政治立场；
- 未完成的家族目标。

继承强度由关系、遗嘱、共同经历与继承人的人格决定，不能机械复制父辈全部关系。

## 8. 更新频率

| 人物层级 | 更新频率 |
|---|---|
| 玩家、同行者、现场对手 | 每时段 |
| 家庭、好友、关键历史人物 | 每日或每旬 |
| 完整远方NPC | 每月 |
| 普通人口群体 | 每季聚合 |

与玩家建立永久关系、签订契约或参与重要事件的生成NPC，从聚合人口升级为永久人物。

## 9. 行为安全边界

- AI只能提交`Command`，不能直接修改世界结果。
- 行动必须经过权限、地点、资源和规则验证。
- 婚姻、死亡、继承、叛乱等重大结果由领域系统解决。
- AI不得读取角色未知的秘密。
- 决策必须能输出评分明细，方便调试玩家质疑的行为。
- 生成式语言模型未来只能表达结果，不能成为唯一规则来源。

## 10. 第一阶段验收

使用50名人物模拟10年，检查：

- 同种子结果完全一致；
- 不同性格产生显著不同的月度重点；
- 饥饿或战争压力能压过平时野心；
- 顾家人物在家庭危机时优先照顾家人；
- NPC不会选择无权限、无路径或无资源的行动；
- 每次决定都能显示前三名候选及评分原因。
