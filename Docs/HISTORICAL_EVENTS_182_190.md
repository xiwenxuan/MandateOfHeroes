# 182—190年历史事件索引（第一版）

## 1. 文档目的

本索引为首个可玩年代建立历史骨架。它不是完整剧本，也不预设玩家必须“照历史演出”，
而是为事件系统提供时间、地点、人物、世界状态和不同身份的参与入口。

设计原则：

- 正史事实构成“历史压力”，具体结果允许被玩家和模拟世界改变。
- 未被玩家改变时，世界尽量向史实结果收束；重大改变需要足够代价。
- 正史、后世文学和原创玩法必须分层标注。
- 事件不仅属于君主与武将，也要改变人口、粮价、治安、疾病、徭役、商路和家庭命运。
- 公元260年不是游戏终点；本索引只是135年以后长时间模拟中的首个高密度事件段。

## 2. 史料与标记

### 2.1 可靠度

- **A**：纪、传、编年史可以互证的核心事实。
- **B**：见于正史，但月份、地点、人物关系或过程仍需专题校核。
- **C**：文学传统、民间叙事或为玩法所作的合理虚构，不能写成史实。

### 2.2 主要来源

- **S01**：《后汉书·孝灵帝纪》
- **S02**：《后汉书·孝献帝纪》
- **S03**：《资治通鉴》卷五十七
- **S04**：《资治通鉴》卷五十八
- **S05**：《资治通鉴》卷五十九
- **S06**：《三国志·先主传》
- **S07**：《三国志·武帝纪》及裴松之注
- **S08**：《三国志·孙破虏讨逆传》

## 4. 文学名场面处理

| 名场面 | 历史层结论 | 游戏处理 |
|---|---|---|
| 桃园结义 | 正史记刘备与关羽、张飞关系亲密，“恩若兄弟”，无桃园结义记载 | 可作为低概率传奇事件或玩家自建结义仪式，不标为正史 |
| 三英战吕布 | 不见于正史 | 可作为“传奇模式”战场事件；史实模式不强制发生 |
| 温酒斩华雄 | 正史中斩华雄者为孙坚军 | 可保留传闻、说书版本，不覆盖世界事实记录 |
| 十常侍整体同日被尽诛 | 189年宫变真实，但人物、次序和死亡经过比文学叙事复杂 | 采用事件链和派系成员表，避免单一演义过场 |
| 曹操献刀 | 文学情节 | 可改造成泛化的刺董密谋任务，不强制指定执行者 |

游戏应允许“传奇叙事”成为世界中的传闻：同一事件可以同时保存事实记录、官方文书、
民间传闻三种文本，让玩家通过身份和情报能力接触不同版本。

## 5. 普通人生活事件包

历史大事不直接等于玩法。每个锚点会向周边地点释放可重复、可组合的生活事件：

| 事件包 | 触发条件 | 典型任务 | 长期后果 |
|---|---|---|---|
| 征发与避役 | 战区、募兵或迁都 | 应募、代役、逃亡、查验户籍 | 家庭劳力、声望、犯罪记录 |
| 难民与宗族迁徙 | 城破、饥荒、强迁 | 护送、安置、收养、夺田纠纷 | 人口迁移、新家族分支、地方冲突 |
| 战时粮价 | 大军集结、道路中断 | 运粮、囤积、平粜、查禁 | 财富与民望此消彼长 |
| 伤病与疫病 | 战斗、饥荒、密集迁徙 | 救治、制药、隔离、掩埋 | 医术传承、人口与军队恢复 |
| 军需制造 | 战争或宫城武装 | 锻造、修车、制甲、验收 | 工坊升级、军方关系、偷工减料风险 |
| 文书与情报 | 政变、州牧更替、联盟 | 送檄、伪造、截获、辨谣 | 势力关系、通缉、情报可信度 |
| 土地与债务 | 青壮死亡、流民增加 | 赎地、兼并、佃作、调解 | 世家扩张或小农复兴 |
| 宗教互助与镇压 | 太平道传播、地方恐慌 | 治病、布施、潜伏、审讯 | 信众网络、官府戒备、地方民心 |

## 6. 历史事件的可改写等级

- **一级：个人改写**——救下一户人、改变一次婚姻、一次交易或一名士卒的生死。
- **二级：地方改写**——保住县城、缩短饥荒、打开商路、改变地方官去留。
- **三级：战役改写**——改变一支部队的胜负或一名关键人物的生死，需要组织资源。
- **四级：时代改写**——阻止黄巾全面爆发、改变189年帝位或迁都结果，需要长期经营的
  家族、势力、情报与军事优势；世界必须产生可解释的新时间线。

无论是否改写，人物都会衰老、成家、死亡和继承。玩家本人没有赶上某一事件时，
可以由门客、子女、族人或组织代理参与，这正是数代经营玩法的核心。

## 7. 首版原型建议

首个可玩切片暂取 **184年涿郡—广宗走廊**，不立即制作整个天下：

- 主要地点：涿县、蓟县、广宗、下曲阳、邺、洛阳（远程政治节点）。
- 三条身份开局：乡勇/军人、行商、县吏。
- 共享危机：黄巾起事、募兵、道路封锁、粮价上涨与家庭抉择。
- 交汇人物：刘备小集团、邹靖、地方官、商人资助者及生成的村民家族。
- 结局不是“打赢黄巾”即结束，而是计算玩家家庭、财富、关系、官职、伤亡和迁徙结果，
  然后继续进入185年。

## 8. 下一步数据化

下一轮应把本表拆为可导入的数据：

1. `historical_events`：事件ID、时间窗、地点、参与者、前置条件、史实默认结果。
2. `event_effects`：人口、粮价、治安、兵力、民心、道路和关系变化。
3. `participation_hooks`：身份、职位、技能、组织资源对应的任务入口。
4. `narrative_layers`：事实、官方记载、民间传闻、传奇模式文本。
5. `source_refs`：书名、卷篇、原文定位、译注和可靠度。
