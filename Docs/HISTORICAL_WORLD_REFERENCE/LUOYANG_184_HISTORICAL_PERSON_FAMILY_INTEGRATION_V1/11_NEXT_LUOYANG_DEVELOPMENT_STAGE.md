# 下一洛阳开发阶段建议

## 推荐阶段

`LUOYANG-184-LIVING-WORLD-CLOSED-LOOP-V1`：40万永久人物、2,084项Facility与地方经济生活闭环。

## 优先顺序

1. 建立受保护初始化包之上的可写派生检查点/覆盖层，支持Person状态、迁居、就业、库存和资产变化，仍保持同一永久PersonId。
2. 以分区调度接通`Residence → Work → Production → Consumption → Market → Supply`，每笔人口、物资和货币变化可追溯并守恒。
3. 让25名历史人物和普通人物都消费同一世界规则；关注/热存只改变演出与计算精度，不改变事实。
4. 增加家庭成员日常、组织管理和地方治理的低频调度；FamilyCenter只有真实条件满足后才由命令显式指定。
5. 在不创建40万GameObject的前提下提供抽样可视化、审计面板和50年运行证据。

## 进入条件

- 本阶段V69全量回归最终通过。
- 明确派生检查点格式、分区事务和V70迁移策略。
- 对32条都市圈Facility未决主张保持隔离；它们不阻塞生活闭环，但不得被自动转成资产。

## 继续延期

虎牢、函谷、70万供给区物化、190历史事件玩法、全国Clan/FamilyOrganization生成和全面美术场景继续Deferred，除非用户另行授权。
