# 洛阳 T4 之后的全国扩展计划

1. 先把洛阳 v6 适配合同提炼成不含城市专名的 `SettlementLivingWorldAdapter`，保持永久人物、家户、设施和库存唯一事实。
2. 以 72 地点 Full Development Reference Pack 分三波扩展：虎牢—长安走廊；河北/中原主城市；荆益扬州核心节点。
3. 将目前 Deferred 的马匹等远方商品逐步升格为 Compact 或 FullPhysical 供应商，升格前禁止直接发货。
4. 将城门关闭、路况、战事与 Shipment 路由接通；继续使用统一 Cell 世界，不建第二张战斗地图。
5. 深化实物税、家族继承、仕途晋升和犯罪治安，但不得破坏 v6 存档兼容、v5顺序迁移与40万人物性能基线。
6. 每新增地点都必须复用相同验收矩阵：历史开局、AI、地产、供应、市场、家族、个人、政府、军需、事件、玩家、存档和性能。
