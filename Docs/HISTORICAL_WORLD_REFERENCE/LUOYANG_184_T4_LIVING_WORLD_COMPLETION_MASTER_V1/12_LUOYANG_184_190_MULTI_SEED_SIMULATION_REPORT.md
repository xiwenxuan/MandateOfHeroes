# 洛阳 184—190 多种子模拟报告

## 一年 20 种子

- 每个分支从相同的正式184初始化创建；初始化阶段固定使用同一 Seed，然后只替换运行分支 WorldSeed，不改变历史人物、家户、设施和地产开局。
- 为遵守 Unity 300秒硬边界，Seed 1—20 拆成 1—5、6—10、11—15、16—20 四组；没有减少 Seed 数。
- 20 个分支全部推进365天；各组均保持相同开局并产生至少两类不同结果，整体形成多类贸易收入、运输风险、家族投资、政府策略、设施扩建与执行动作组合。
