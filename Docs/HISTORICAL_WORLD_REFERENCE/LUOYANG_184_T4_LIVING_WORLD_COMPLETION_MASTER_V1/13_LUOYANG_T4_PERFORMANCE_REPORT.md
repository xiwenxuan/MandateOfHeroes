# 洛阳 T4 性能报告

- 规模：400,000 永久人物、80,899 家户、2,084 开局设施。
- 禁止模式：没有每帧全人物 AI、每人每日寻路或每户遍历全市场。
- 人物与家庭高频事实使用紧凑数组；学习/职位/事件等细节使用稀疏记录；跨系统结算使用 30 天批次。
- 修复的关键瓶颈：充分就业后设施经理重复扫描全部 400,000 人；智能体创建曾线性查重形成 O(n²)。增加 O(1) 无失业者门禁和 HashSet 去重索引后，一年模拟从约 107 秒降到约 2.85 秒。
- 最终核心性能 Suite 中初始化约 0.69 秒、一年模拟约 5.15 秒、峰值托管内存约 247.26 MiB；不同测试进程与GC时点会波动。
- 连续六年最后一段追加运行约 13.29 秒；v6 gzip 检查点往返通过。
- Unity T4 EditMode 拆为18项功能、5项长期/性能/迁移，以及4×5 Seed测试并全部取得通过XML；两条洛阳PlayMode Smoke均约16秒通过。
