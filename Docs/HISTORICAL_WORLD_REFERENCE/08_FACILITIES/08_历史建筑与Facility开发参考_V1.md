# 历史建筑与Facility开发参考 V1

设施是统一世界中的持久实体，不是地图图标。历史存在、合理复原与玩法补全必须分层。

## 统一数据合同

- 稳定definition_id与facility_id
- 位置/占地/容量/耐久
- 所有权与使用权
- 岗位与排班
- 库存/配方/能耗/损耗
- 建设、扩建、损毁与废弃时间线

## 证据规则

每个实例同时记录`evidence_type`、`source_ids`、`valid_from/to`、`confidence`和`notes`。增加普通Facility、产品、道路或行政设施采用数据定义，不新增枚举，不要求升级存档结构。

## 运行边界

本参考文档不直接创建全国实例；运行时建设、拆除、生产、运输、战争和治理可以改变设施状态，变化必须进入统一世界账并可追溯。
