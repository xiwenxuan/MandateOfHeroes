# 成都 Sources and Unknowns

## Unknowns

- major_city_timeline中成都错指admin.han140.jingzhou.nanyang.chengdu，禁止使用（MODELED_GAP）
- 城门与宫廷逐Cell位置（MODELED_GAP）
- 蜀锦官营设施的数量和边界（MODELED_GAP）

这些UNKNOWN不等于NONE；非阻塞的普通细节可由MODELED运行需求补全，但精确历史Cell、人物住宅、Estate和FamilyCenter不得臆造。
