# 135—260 全国县域生产、资源、产业与供应参考母版

## 结论

本目录已经形成覆盖 1182 县、13 个历史切片的县域经济参考层。184 年基准使用全国人口母版的 5350 万实际模型人口，建立土地、水利、作物、畜牧、林业、渔猎、矿产、盐业、加工、仓储、市场、运输、地方需求、商品平衡和供应关系。

它不是运行时世界本身。正式运行仍须把参考能力物质化为 Cell 上的资源、设施、劳动者、配方、库存和运输活动；玩家进入世界后，历史初始化可以立即被真实行动改变。

## 证据和地理边界

当前 HanWorldV1 仅有 68 个可解析县治点；其余 1114 县没有可靠坐标。为让全国统计和图层可计算，本包只为未解析县生成显式标记的分析点，状态为 `MODELED_UNRESOLVED_COUNTY_REFERENCE`，不得解释为历史县治定位。所有县界和绝大多数县面积仍未知，面积仅为人口密度反推的低/推荐/高参考。

40 份工作簿中的所有产量、需求与供应关系都携带证据等级或方法 ID。`RECONSTRUCTED` 表示现有区域/开发地点资料可支持方向性重建；`MODELED` 表示为玩法和开发校准建立的确定性模型，不是史实宣称。

## 关键结果如何理解

- 全国谷物生产覆盖率约为 0.767，其他食物折算约为 1.773；二者不能直接相加，单位与损耗必须分别审计。
- 铁矿石潜力充足不等于铁料充足。冶炼设施、燃料、劳动和运输能力造成明显加工瓶颈。
- 木材潜力充足不等于县内存在车船制造；需要对应加工设施和熟练劳动。
- 只有存在剩余、运输容量和路径时才形成供应关系。没有关系不代表世界“没有贸易”，而是当前 V1 参考模型没有证明可形成可交付余量。
- 贸易损耗从发出量扣除，目的地只获得送达量；差额不会凭空消失或被重复计入。
- 负库存被禁止。不能满足的消费、工业、政府或军事需求进入 `unmet_demand`，由后续世界系统产生饥荒、停工、军需缺口或替代行为。

## 目录

- `HISTORICAL_UNIT_CONVERSION.md`：规范单位和历史单位处理。

- `MASTER_WORKBOOKS`：40 份人读/审计工作簿。
- `REGIONAL_STUDIES`：区域与产业专题。
- `MAP_OUTPUTS`：GeoJSON 点层和模型走廊。
- `SOURCES`：来源与许可证边界。
- `VALIDATION`：数据、公式和渲染证据。

## 后续物质化门槛

任何县进入实际开发前，必须完成县治/关键 Place 定位复核、Cell 资源分布、Facility 类型与容量、Worker 岗位、Recipe 输入输出、Inventory 初值和 Transport 路径的独立就绪审查。V1 母版不能直接批量生成全国人物或设施。
