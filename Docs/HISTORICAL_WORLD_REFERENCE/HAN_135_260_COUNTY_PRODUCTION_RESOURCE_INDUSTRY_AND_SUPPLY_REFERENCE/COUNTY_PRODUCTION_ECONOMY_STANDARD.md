# 县域生产经济统一标准 V1

## 世界事实层级

`县域参考 → Cell 资源 → Facility → Worker → Recipe/生产任务 → Inventory → Transport → 市场/官府/军队/家户消耗`。

县域表只回答“开局和 AI 应在什么范围内寻找、配置和校准”，不直接回答“此刻哪个仓库有多少粮”。

## 县级最小合同

每县必须具备稳定县 ID、所属州与郡国、县治/分析点状态、184 人口和劳动力、土地与水风险、主要作物、畜牧、林业、渔猎、矿盐潜力、加工能力、仓储、市场、运输、19 类商品需求和平衡、证据等级、未知项及运行时映射状态。

## 守恒

县—商品平衡采用：

`期末库存 = 期初库存 + 生产 + 送达进口 - 家户消费 - 工业投入 - 政府需求 - 军事需求 - 本地损耗 - 发出出口 + 未满足需求`

其中未满足需求只用于把实际库存下限保持为零，不能被解释为补给。运输关系采用：

`发出量 = 送达量 + 运输损耗`

全国内部出口和进口的差额必须等于运输损耗。

## 潜力、能力和实际

- 土地、矿产、盐、森林为潜力层；必须另列实际开发状态。
- 加工能力是可用设施/劳动/技术的参考上限；不是实际产出。
- 市场、仓储和运输服务容量不是实物库存。
- 理论剩余先受库存目标、路径、运力、风险和政治控制限制，之后才成为可出口量。

## 证据等级

`HISTORICAL`、`ARCHAEOLOGICAL`、`RECONSTRUCTED`、`MODELED`、`UNKNOWN`、`NO_EVIDENCE`、`NOT_APPLICABLE`。郡级证据下推县级时必须写 `REGIONAL_INFERENCE`；未知县界和县治不能用模型坐标冒充史实。

## 确定性

所有县内变异使用稳定县 ID 和固定频道生成；相同输入产生相同输出。新增普通商品、作物、设施、配方和资源必须使用稳定命名空间 ID，不扩展固定枚举或要求存档升级。
