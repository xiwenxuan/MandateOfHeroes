# 区域生产研究入口 V1

V1 建立以下区域研究路由：河南—黄淮、关中、河北平原、兖豫徐青、江汉、南阳、成都平原、汉中、江淮、吴会稽、凉州河西、交州。每个区域均应从气候、地形、水系、人口密度、主要作物、畜牧、森林、矿盐、加工、市场、运输、军需和灾害风险进行交叉审计。

当前定量底座按 13 州级区域参数下推到县，并以县稳定 ID 产生确定性变异。它可用于发现研究重点，不能代替县/郡考古和历史地理证据。区域边界不是现代行政区，也不表示游戏运行时经济共同体。

优先深化：河南—黄淮粮食与都城消费、关中粮运与关隘、河北粮马、兖豫徐青粮盐市场、江汉/江淮水运、成都平原水利盐铁丝织、凉州河西马匹与走廊运输、吴会稽稻作木材船舶、交州稻作海运与热带资源。
