# 产业专题研究入口 V1

专题包括粮食、盐、铁冶金、马匹畜牧、丝织、木材燃料、造船、建筑材料和军事生产。

每项专题必须区分资源潜力、历史开发、原料产出、初级加工、深加工、设施容量、熟练劳动、燃料/工具、库存、地方需求和可运输剩余。不得因存在铁矿潜力就生成铁器，也不得因临水就生成船厂。

后续深化的最小链条示例：

- 铁：矿点 → 采矿设施 → 矿石库存 → 冶炼设施 + 木炭 → 铁料 → 铁匠/军工作坊 → 工具或兵器。
- 丝织：桑地/蚕桑 → 生丝 → 丝织设施 + 熟练劳动 → 织物 → 商号/官府/家户需求。
- 粮食：田地 + 种子 + 劳动 → 收获 → 加工 → 分层仓储 → 家户/军队/市场 → 运输损耗与短缺后果。
- 船舶：适用水体 + 木材/铁件/麻纤维 → 船场 + 技工 → 舟船资产 → 水运能力；水体和产船不是同一事实。
