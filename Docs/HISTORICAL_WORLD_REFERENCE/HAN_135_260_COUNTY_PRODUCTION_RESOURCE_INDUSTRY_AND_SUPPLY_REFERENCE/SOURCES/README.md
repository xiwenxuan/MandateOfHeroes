# 来源、许可与使用边界

- 项目内 HanWorldV1：提供统一网格、已解析县治点和现代物理地理参考；具体来源见其 `source_manifest.json`。
- 项目内全国人口母版：提供 184 年县人口与 13 个切片。
- 项目内 72 个 Development Place 参考包：仅提供区域/地点方向性重建提示。
- 《后汉书·郡国志》：行政与人口史料锚点；本包不复制现代注释文本。
- Natural Earth：公共领域物理图层，已经由 HanWorldV1 引用。
- Mapzen terrain/SRTM/GMTED：只沿用 HanWorldV1 已登记的物理高程来源边界。
- CHGIS V3：其公开许可包含学术研究、非商业和禁止再分发限制，因此本任务没有导入，仅保留为人工研究定位线索。

任何新增外部数据必须先记录来源 URL、版本、许可、是否允许商业使用、是否允许再分发和派生作品，再决定是否进入仓库。
