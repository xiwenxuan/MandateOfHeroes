## 证据与世界生成

- 城市存在/名称：`HISTORICAL`或现有资料等级，具体见来源ID。
- 精确城界与内部街区：`UNKNOWN`，不得由点坐标推导。
- 当前坐标：用于地图定位；近似坐标不等于遗址范围。
- 默认产业、设施和资源：只能作为`MODELED`初始候选，运行后由统一世界系统变化。
