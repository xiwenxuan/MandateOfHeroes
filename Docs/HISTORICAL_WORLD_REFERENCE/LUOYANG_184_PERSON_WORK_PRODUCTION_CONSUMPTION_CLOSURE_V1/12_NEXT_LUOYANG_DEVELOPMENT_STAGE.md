# 下一洛阳开发阶段建议

## 推荐：先物化洛阳外围供应区与农业腹地

建议下一正式任务为：

`LUOYANG-184-SUPPLY-REGION-AND-AGRICULTURAL-HINTERLAND-MATERIALIZATION-V1`

原因来自本轮真实结果，而非预先选择：全年可食来源462,860,000毫单位，而累计未满足需求达134,208,932,550毫单位，80,899户全部经历短缺。此时直接扩展价格、商号和金融，只会对接近零的真实粮源做更复杂分配。

## 下一任务应完成

1. 在同一HanWorld Cell网格上确定洛阳供应腹地、道路、水运和仓储节点，不建立第二张世界地图。
2. 使用既有永久人物原则物化必要的农村家户和劳动力；不得把计划人口叠加进当前40万都市基线。
3. 建立耕地、种子、畜力、农具、土地权属、收获、地租/税前接口和季节性运输。
4. 将本轮5条`TRANSITIONAL_REFERENCE_SUPPLY`逐条替换为真实生产批次、承运人、损耗、仓储和交付。
5. 重跑1/7/30/365日，比较粮食安全、仓储瓶颈和运输能力。

## 后续顺序

外围物理供给达到可审计规模后，再进入`LUOYANG-184-MARKET-COMMERCE-LOGISTICS-ECONOMY-V1`，补商号、订单、议价、信用、货币支付、运输合同、官府征购和军需竞争。两个阶段都必须复用本轮Person、Facility、Inventory和Household合同。
