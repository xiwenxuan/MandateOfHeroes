# 洛阳184人物—工作—生产—消费闭环 V1 正式报告

## 结论

本阶段已经在同一受保护洛阳世界中跑通第一版生活经济闭环。400,000个PermanentPerson、80,899个Household和2,084个Facility均保持原身份与数量，新增、删除、合并和重新随机均为0。运行时明细写入独立gzip派生检查点，初始化包没有被写回。

这是一套可运行、可保存、可审计的原型底座，不等于成熟商业经济系统。它已经能够诚实地产生缺工、缺原料、缺粮和依赖外围供应的结果，不会用城市总量数字或魔法进口掩盖问题。

## 守恒与来源

粮食审计恒等式：

`参考输入 970,000 + 本地可食收储 461,890,000 = 消费 462,515,000 + 年末库存 0 + 加工损耗 345,000`

两侧均为462,860,000毫单位。非粮加工、运输和种子账另有独立流转记录；主摘要中的总Loss包含粮食、非粮加工和参考供应损耗，不能误读为仅粮损耗。

外围供应没有物化额外30万人，也没有每日补粮。5条既有供应链的已交付物资进入其真实目的仓或供应链所列仓库；其中金市自身仓储容量为0，所以非粮货物落入供应链明确给出的真实仓库，而不是被静默丢弃或凭空增加容量。

## 修复的历史数据解释问题

1. 初始化数据中官职、军职和Force的“无引用”索引为0。原型初版按`ushort.MaxValue`判断会把全员误判为军役；现已同时兼容0和MaxValue空值，只把有效目录引用视为占用。
2. 金市是交易设施但没有仓储容量。供应链已交付货物现在使用其显式`warehouse_facility_id`，仍受真实仓容约束。

## 尚未宣称成熟的部分

- 市场已能读取真实库存、需求、失败需求和价格压力，但尚未完成商号竞价、货币结算、订单与运输合同。
- 家户分配已从真实库存扣减并记录来源，但产权许可、购买能力和救济资格仍是下一经济阶段内容。
- 506个农业类设施中只有既有135条正式农业记录具备完整作物周期，其余设施不会被虚构作物填充。
- 本任务只提供饥饿/迁移/救济行动接口，不在本阶段扩展死亡、税收、战争、190事件或完整健康后果。
