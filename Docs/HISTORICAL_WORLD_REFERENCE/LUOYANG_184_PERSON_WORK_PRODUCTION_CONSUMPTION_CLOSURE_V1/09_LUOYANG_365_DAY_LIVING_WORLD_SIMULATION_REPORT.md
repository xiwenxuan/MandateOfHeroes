# 洛阳184生活世界365日模拟报告

## 运行方式

- 固定Seed：184。
- 初始日：0；终止日：365。
- 观察点：1、7、30、90、180、365日。
- 权威人口：受保护的400,000个PermanentPerson；家户80,899；设施2,084。
- 运行粒度：人物和家户保持永久记录，日常消费按家户与来源库存合并记账，表现层不创建逐人GameObject。

## 观察

1. 第1日参考粮食970,000毫单位即被真实家户消费，库存不会负数。
2. 早期缺粮立即触发`SUPPLY_REGION_DEPENDENCY`和家户寻求市场/救济响应，没有生成兜底粮食。
3. 农作物在各自90—150日成熟期完成收获，留出真实种子；30日休整后由真实种子启动下一周期。
4. 年内317次收获、295次再播种；110块地处于第3周期，25个畜牧单元处于第4周期。
5. 生产设施在人员、原料或仓容任一条件不满足时停产并留下StopReason；年末69个设施缺输入、353个低于最低用工。
6. 全年没有负库存、无限产出或循环创建人物/设施。

## 解释

全年每日总粮食需求约368,962,870毫单位，而现有135个农业单元和5条参考供应链远不能承担40万都市需求。累计短缺134,208,932,550毫单位并非模拟失控，而是当前地图尚未物化洛阳外围农业腹地和真实持续物流的直接结果。

因此365日证据支持下一阶段优先选择供应区域物化；在完成外围生产、仓储、运输与所有权前，不应先用更复杂价格系统掩盖物理供给缺口。
