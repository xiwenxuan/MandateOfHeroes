## 性能边界

当前实现每次日推进仍扫描家户并对有限库存来源进行分配，适合作为40万洛阳闭环原型。全国和5,000万累计人物规模不能简单复制该热循环；后续仍需分区调度、冷热层、脏分区检查点和批量供需结算，但不得以聚合结果删除永久人物。
