# 下一世界模拟阶段

## 阶段判定

本阶段达成了可运行 Policy、稳定 Seed、离线 Neural Scorer、安全回退和条件历史事件多种子分布，但没有完成全国 HOT/WARM/COLD，也没有证明 400K 洛阳混合热度性能。按照任务门禁，下一阶段应为：

`WORLD-HOT-WARM-COLD-PERMANENT-PERSON-SIMULATION-V1`

## 下一阶段范围

1. 以 400K 洛阳受保护初始化为性能基线，建立 HOT/WARM/COLD Agent 调度、批量信号缓存和分级决策节奏。
2. 覆盖 100、1,000、1,182 县 Agent、1,000 Merchant 与极端全 HOT 对照，记录 CPU、GC、Memory、Peak Memory 和存档增长。
3. 将当前合同 Fixture 中尚未改变的 Facility、农业/产业、贸易网络、Family 与 Government 指标接到既有正式 Command/Order/Shipment/Facility/Organization 账。
4. 继续使用同一 `WorldState`、稳定 ID、Validator、市场和事件引擎；禁止另建第二套简化世界或魔法 Supply。
5. 保持 Rule/Utility 为生产默认，Merchant Neural 仅做版本化 A/B；禁止 Runtime Online Training。

## 前置缺口

- 400K 洛阳完整回归与全国混合热度性能尚未在本次 Arena 证据中执行。
- 10 年 Fixture 的 Facility、TradeVolume 和 GovernmentReserve 没有形成策略差异。
- 189/190 原型已证明 25/25/25/25 的多分支合同，但不等于正式历史内容包。

这些缺口是下一阶段验收对象，不应通过扩大历史资料研究或硬写年份脚本规避。
