## 三、来源与校录判断

原始行政和户口事实采用公共领域古籍《后汉书》卷三十三·郡国五。维基文库
《四库全书》网页转录是原值依据；另一公开校勘转录和现代人口校录网页只用于
异文、疑值及数值交叉检查，不复制其完整表格、校勘文字或现代注释。

永昌郡原文为231,897户、1,897,344口，户均人口明显偏高。公开校勘记录指出
该口数可能有讹，但没有给出可采用的替代值；现代人口校录也明确没有修正。
因此项目保存原值和疑点，修正字段保持为空。广汉属国旧注作“属蜀郡”，公开
校勘依据其阴平、甸氐、刚氐三道改作“属广汉郡”；该异文只写入行政备注。
