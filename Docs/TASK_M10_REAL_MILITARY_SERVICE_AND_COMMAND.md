# M10 任务书：真实服役、军队编制与军令权限

## 一、任务目标

依据《统一战斗、军团与战争权限系统设计》的 P1 开发顺序，将现有抽象兵力升级为能够追溯到真实人物的服役与编制账。

本任务建立：

```text
真实人物
→ 服役关系
→ 队与部
→ 军团
→ 指挥链
→ 军令权限
→ 行军、战斗、逃亡和医疗
→ 人物与军队状态同步回写
```

## 二、原型规模

- 三支原型军队；
- 总计约240名真实服役人物；
- 每军约80人；
- 每军包含军团根编制与两个基层队；
- 已有人物担任主将；
- 生成士卒与基层军官从所在地人口总账实例化，不创造额外人口。

这是用于验证事实链的缩尺原型，不代表历史战役的最终兵力。

## 三、领域对象

### MilitaryServiceState

- 人物；
- 军队；
- 所属编制；
- 职责；
- 军衔；
- 服役状态；
- 纪律；
- 忠诚；
- 服役经验；
- 入伍与状态变更日期。

### MilitaryFormationState

- 所属军队；
- 上级编制；
- 编制层级；
- 指挥官；
- 额定人数；
- 显示顺序。

### MilitaryOrderState

- 发布者；
- 目标军队与编制；
- 军令类型；
- 要求权限；
- 实际权限；
- 发布日期；
- 目标地点或目标军队；
- 是否获准；
- 摘要。

## 四、服役状态

- 集结；
- 在役；
- 伤病；
- 掉队；
- 逃亡；
- 被俘；
- 退役；
- 死亡。

军队查询缓存规则：

```text
ArmyState.Troops
= 集结人数 + 在役人数

ArmyState.WoundedTroops
= 伤病人数
```

当真实服役系统启用后，缓存必须与服役账严格一致。

## 五、指挥链与权限

权限分为：

- 无军事权限；
- 自身行动；
- 基层编制指挥；
- 军团指挥。

规则：

1. 军团主将可以发布整军行军和主动交战命令。
2. 基层军官只能指挥自己的编制，不能调动整个军团。
3. 普通士卒只能执行自身和所属队伍允许的行动。
4. 非服役人物不能发布军令。
5. 伤病、逃亡、被俘、退役或死亡人物不能行使现场指挥权。
6. 每次军令都必须写入审计记录，拒绝的军令也保留原因。
7. 历史事件直接动员军队属于世界事件权限，不伪装成人物军令。

## 六、系统接入

### 原型世界

- 从所在地行政或农业人口批次实例化士卒；
- 使用稳定世界种子生成人物禀赋；
- 主将、基层军官与士卒进入真实服役账；
- 生成军团根编制和基层队。

### 行军

- `ArmySystem.StartMarch` 必须提供发布军令的人物；
- 只有拥有军团权限且现场可用的主将能够下达行军令；
- 行军命令进入军令记录。

### 战斗

- 主动方必须由合法主将发布交战命令；
- 军团结算产生的伤亡分配到具体服役人物；
- 死者进入人口死亡账；
- 伤者进入伤病服役状态；
- 军队兵力缓存由服役状态重新聚合。

### 缺粮与逃亡

- 缺粮造成的逃亡落实到具体在役人物；
- 人物保持存活，但服役状态变为逃亡；
- 军队有效兵力同步下降。

### 医疗

- 恢复战斗力的人必须来自真实伤病服役成员；
- 康复者回到在役状态；
- 个人健康与军队伤兵缓存同步变化。

## 七、存档兼容

- 世界存档升级至 V5；
- V4旧存档保留原有抽象军队并标记为“尚未转换真实服役”；
- 新建原型世界默认启用真实服役；
- 旧存档不伪造历史上不存在的具体士卒。

## 八、界面交付

开发观察台增加：

- 真实服役总人数；
- 各军在役、伤病、逃亡、被俘、退役和死亡人数；
- 编制树与指挥官；
- 当前玩家对军队的权限；
- 最近军令及授权结果。

## 九、验收标准

1. 新建原型世界具有约240名真实服役人物。
2. 新增士卒全部来自人口批次，世界人口总数不增加。
3. 每名在役人物只属于一支军队和一个有效编制。
4. 军队兵力与伤兵缓存能够由服役状态严格重算。
5. 主将可以发布行军与交战命令。
6. 普通士卒、外部人物和失去现场能力的主将不能发布整军命令。
7. 军令无论成功或拒绝都写入记录。
8. 战斗死亡和伤病落实到具体人物，且不会重复计入抽象伤亡。
9. 缺粮逃亡落实到具体人物。
10. 医疗只让真实伤员恢复在役。
11. 同一世界种子与命令产生相同服役人员和伤亡分配。
12. 存档往返保持编制、服役、军令和伤亡一致。
13. V4存档可以迁移至V5兼容状态。
14. 非法编制、重复服役和兵力缓存篡改会被校验拒绝。
15. 现有测试不得回归。

## 十、不在本任务范围

- 兵种派生；
- 阵型完整度；
- 局部交战阶段；
- 个人战斗；
- 传令延迟和副将委托；
- 战役与战争目标；
- 军械生产和采购。
