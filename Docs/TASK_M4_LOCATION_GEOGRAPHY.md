# M4任务书：地点层级、地貌与设施数据

## 目标

将地图上的城池节点升级为可以支持多视角、多身份和多种玩法的正式地点数据。

同一地点必须能够在天下战略图、州郡舆图、县乡近览和未来战场中保持身份一致，而不是由每个界面分别猜测它是什么。

## 本次范围

- 增加地点类型：州郡治所、县城、关隘、港口、市镇、村庄和营地；
- 增加地貌类型：平原、丘陵、山地、河网、森林和湿地；
- 增加一至五星战略重要度；
- 增加地点设施标记：官署、市场、驻军、农田、工坊、医馆、寺观、驿站、港口和城防；
- 为当前六地点原型补齐地图元数据；
- 在县乡近览中按照真实设施数据绘制农田、市场、驿站等标记；
- 城池封泥图标根据地点类型改变；
- 地点详情展示层级、地貌、战略重要度与设施；
- 新字段进入世界验证与存档往返测试。

## 非本次范围

- 不宣称当前六地点坐标已达到历史GIS精度；
- 不增加洛阳区域；
- 不增加设施建设、损坏和升级；
- 不增加港口航行；
- 不增加关隘攻防；
- 不改变现有旅行距离和黄巾事件流程。

## 验收标准

1. 每个原型地点都有明确类型、地貌、重要度和设施；
2. 非法枚举、非法设施位和非法重要度会被世界验证拒绝；
3. 存档读写保留全部地图元数据；
4. 近景装饰由设施数据决定；
5. 地点封泥字样能够区分治所、县城、关隘等类型；
6. 当前52项核心测试继续通过；
7. 新增地图数据测试通过；
8. 运行时程序集编译通过。

## 后续接口

- 军人：地貌、驻军、城防、战略重要度；
- 官吏：地点层级、官署、人口、治安；
- 商人：市场、工坊、驿站、港池；
- 医者：医馆、人口、战斗与疫病状态；

- 工匠：工坊、市场和建设需求；
