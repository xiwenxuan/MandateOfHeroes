# M6任务书：身份相关地方建设

## 目标

让地点设施从静态地图标签变为玩家能够发起、投入并完成的世界状态。

建设项目必须进入存档；完工后直接改变地点设施，并立即影响身份地图视角。

## 核心流程

1. 玩家在自己所在地点发起建设项目；
2. 项目记录发起人、地点、目标设施、所需进度和开始日期；
3. 玩家投入个人资金和劳力；
4. 进度达到要求后完工；
5. 目标设施加入地点数据；
6. 县乡近览和身份视角立即显示新设施。

## 身份建议

- 军务：城防、驻军设施；
- 政务：官署、驿站、农田；
- 商旅：市场、工坊、驿站、港池；
- 医药：医馆；
- 通用：根据地点缺失设施提供基础建议。

第一版允许玩家手动切换身份视角后提出对应建设，未来再加入职务权限、组织审批和公共财政。

## 数据规则

- 一个项目只能建设一种设施；
- 已存在的设施不能重复建设；
- 同一地点不能重复发起相同项目；
- 人物必须身处项目地点且不在旅途中；
- 投入不能超过人物财富；
- 资金和劳力共同转化为建设进度；
- 项目完工状态必须和地点设施一致；
- 项目、进度、投资和完工日期必须可以存档。

## 验收标准

1. 建设项目具有正式世界状态；
2. 世界验证拒绝无效项目；
3. 玩家可以从地点详情发起身份建议项目；
4. 玩家可以投入资金与劳力；
5. 完工后地点获得对应设施；
6. 地图近景立即反映新设施；
7. 存档往返保留建设进度；
8. 已有设施和重复项目被拒绝；
9. 原有测试无回归；
10. 运行时程序集编译通过。
