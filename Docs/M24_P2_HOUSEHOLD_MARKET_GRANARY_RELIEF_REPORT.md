## 四、同郡跨县运输

共形成6,772笔运输：

```text
38,220,172,462 发运
= 36,309,167,904 到货
 + 1,146,603,124 自然损耗
 +   764,401,434 承运途中口粮
```

到货比实际发到家庭的赈济多2,925毫口粮，这是按整数比例计算运输时留下的极小尾差，保留在目的县官仓，没有消失。来源县只能在保留县仓目标储备后发运；当年仍有缺粮的县不得再作为转运来源，避免同一批到货被重复承诺。
