# M5任务书：身份地图视角

## 目标

让同一个世界地点根据玩家身份显示不同的重点信息，同时保留玩家手动切换视角的自由。

身份视角与颜色图层相互独立：

- 身份视角决定地点标签、设施标记和情报摘要；
- 地形、治安、粮价、战争图层决定地图着色。

## 本次视角

### 通用

- 地貌；
- 地点层级；
- 战略重要度；
- 已知的全部基础设施。

### 军务

- 驻地兵力；
- 伤兵；
- 城防、驻军、驿站和港池；
- 地点战略重要度。

### 政务

- 人口；
- 治安；
- 官署；
- 农田、市场和驿站。

### 商旅

- 粮价；
- 市场库存；
- 市场、工坊、驿站和港池。

### 医药

- 当地低健康人物；
- 驻地军队伤兵；
- 药材价格；
- 医馆、市场、驿站和寺观。

## 自动推荐

- 军事组织成员默认军务视角；
- 县吏等政府成员默认政务视角；
- 行商默认商旅视角；
- 医者默认医药视角；
- 无组织身份默认通用视角；
- 玩家进入世界后仍可自由切换。

## 验收标准

1. 进入世界时根据玩家身份选择推荐视角；
2. 地图提供五种视角切换；
3. 四种颜色图层仍可独立切换；
4. 地点标签随视角变化；
5. 县乡设施标记随视角过滤；
6. 军团标记随军务和医药视角显示不同信息；
7. 地点详情显示当前视角情报；
8. 推荐逻辑和视角摘要具有自动化测试；
9. 原有测试无回归。

## 当前限制

- 视角当前代表“信息组织方式”，尚未加入情报等级和战争迷雾；
- 玩家可以自由切换全部视角，未来可根据身份、职务、声望和情报网限制精度；
- 低健康人物目前只统计健康低于90%的在世人物；
- 市场库存为地点全部商品的合计，后续商旅界面将提供分商品明细；
- 医药视角尚未模拟疫病传播，后续接入人口健康系统。
