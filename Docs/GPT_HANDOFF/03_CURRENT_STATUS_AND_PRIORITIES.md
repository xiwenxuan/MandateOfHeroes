## 4. 当前主线

系统总纲当前仍把可玩Demo与M26商旅—家族/商号成熟切片作为优先方向：

1. M26-P0可玩主循环底座已经贯通；
2. M26-P1/P2商旅—家庭路线已有自动验证候选，但仍需要独立20—30分钟人工盲玩；
3. M26-P5A/P5B已经建立中山城镇与建筑路线，但仍需要人工点击、可读性与视觉验收；
4. 用户最新地图决策是：继续扩大空间地图代码前，先确认各级地图的原创视觉样式；
5. 已归并的Facility、权力、皇室与政治AI设计是后续规则基础，但归并文档没有自动改变全局排期。

## 5. 近期适合和GPT讨论的问题

- 世界图、州郡图、城镇图、村庄图和建筑功能界面应如何形成统一视觉语言；
- 中山商旅切片怎样从“能点击”提升到20—30分钟有目标、有反馈、有长期后果的成熟体验；
- Facility Catalog中哪些应该合并为Profile，哪些确实需要独立BaseType；
- 设施五种成长怎样转成玩家可理解的操作，而不造成微操压力；
- 官职、军职、爵位和组织委任怎样同时支持细致经营与高层托管；
- 皇室、王国、自立、奉汉自治和政治AI怎样进入真实世界而不是事件按钮；
- 军队一军一格、阵型朝向、局部战斗和战略地图如何衔接；
- 哪些系统先进入下一个可玩纵向切片，哪些只保留接口。
