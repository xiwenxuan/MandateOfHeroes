# ChatGPT 对接资料包

> 项目：《群雄志：仕途》（Mandate of Heroes）
> 资料包版本：2026-08-09
> 目录：`<repo-root>/Docs/GPT_HANDOFF`

## 1. 这套资料怎么用

这是一套给网页版 ChatGPT 或其他无法直接读取本地仓库的 AI 使用的轻量对接包。
它帮助 AI 快速理解项目、遵守已有规则、区分设计与实现，并把讨论结果整理成可交回 Codex
执行的结构化方案。

建议首次对话上传本目录全部六份文档；之后只需补充本次问题对应的领域设计和任务书。

## 2. 文件说明

1. [项目概览](01_PROJECT_BRIEF_FOR_GPT.md)：游戏是什么、玩家体验和系统如何连成一个世界；
2. [不可破坏规则](02_NON_NEGOTIABLE_RULES.md)：GPT 提方案时必须遵守的核心边界；
3. [当前状态与近期方向](03_CURRENT_STATUS_AND_PRIORITIES.md)：哪些已有原型、哪些只是底座或方案；
4. [文档权威与上传组合](04_DOCUMENT_AUTHORITY_AND_UPLOAD_PACKS.md)：不同问题还要上传哪些项目文档；
5. [可复制提示词](05_GPT_STARTER_PROMPTS.md)：开始讨论、审查方案和建立任务书的提示词；
6. [决策回传模板](06_DECISION_AND_CHANGE_RETURN_TEMPLATE.md)：让 GPT 用统一格式输出，便于交给 Codex。

## 3. 最小使用流程

```text
上传本目录六份文件
→ 复制05中的“通用启动提示词”
→ 描述这次要讨论的问题
→ 让GPT按06的格式输出结论
→ 把GPT输出交给Codex
→ Codex重新核对仓库最新状态、冲突、代码和测试后执行
```

## 4. 重要边界

- 本资料包是沟通摘要，不替代仓库根目录 `AGENTS.md`、项目 Skill、系统总纲或领域设计；
- 网页版 GPT 看不到工作区最新代码和未提交修改，不得依据本包声称代码已经完成；
- 本包标注的“当前状态”会随开发变化，重要讨论前查看日期；
- GPT 给出的建议只有在用户明确接受并写入权威项目文档后，才成为正式设计；
- GPT 生成的任务书不等于已经执行，自动测试通过也不等于人工试玩通过。

## 5. 维护方式

以下情况发生时应同步更新本目录：

- 游戏愿景或不可破坏规则改变；
- 系统总纲的当前优先级改变；
- 地图、人口、Facility、战争或政治架构发生方向变化；
- 可玩 Demo 达到新的人工验收阶段；
- 新的文档替代旧权威入口。

历史任务书、长测试报告和完整源码不复制进本目录，避免对接包失控；需要时按
`04_DOCUMENT_AUTHORITY_AND_UPLOAD_PACKS.md`追加上传。
