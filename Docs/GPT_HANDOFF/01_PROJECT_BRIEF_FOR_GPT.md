# 《群雄志：仕途》项目概览（给 GPT）

> 摘要日期：2026-08-09
> 本文是沟通摘要，不是项目最高权威。

## 1. 一句话定义

《群雄志：仕途》是一款以东汉末年至三国为主要舞台的开源单机家族人生模拟、角色扮演与
战略沙盒游戏。玩家可以自建任意人物或选择世界中的人物，以多种身份生活数代，并通过家庭、
职业、组织、经济、建设、政治和战争持续改变同一个真实运行的世界。

主要开局年份为135—260年，但260年不是终局，世界可以继续演化。

## 2. 玩家体验

玩家不是只能扮演君主，可以成为：

- 军人或武将；
- 士人或官吏；
- 商人；
- 侠士；
- 医者；
- 家主或世家成员；
- 农户、工匠；
- 宗教人士、密探等。

玩家可以亲自进行细致经营，也可以下达目标、政策或委任，由家庭、商号、太守、军团和其他
组织代理执行。两种操作方式必须使用同一本世界账，接管或交还控制不能重置既有进度。

人物会成长、受伤、结婚、生育、衰老和死亡；后代继承家庭、产业、关系、知识、债务、声望与
历史后果。一局可以经营许多代，不要求统一天下才算成功。

## 3. 世界不是多个小游戏

```text
具体人物与家庭
→ 提供劳力、技能、消费、关系和继承
→ 加入或建立家族、官府、军队、商号、师门等组织
→ 在具体土地、资源和设施上建设与生产
→ 形成库存、市场、运输、税收、财政和军需
→ 通过治理、情报、任务、政治与战争影响天下
→ 后果回写人物、家庭、设施、组织、地理和历史
```

战略地图、州郡图、县域图、城镇图、建筑功能界面和战场只是同一个世界的不同比例尺与专题视图，
不能各自建立一套人口、建筑、库存或军队数据。

## 4. 地图方向

地图层级为：

```text
天下战略图
→ 州/郡区域图
→ 县域与乡野图
→ 城镇空间图
→ 村庄/庄园图
→ 建筑功能和必要室内表现
→ 局部战术战场
```

世界地图视觉目标是原创的“东汉军府舆图＋绢本设色＋山水战略图”，追求山河间分布城池、
关隘、道路、产业和军队的感觉，但不得临摹《三国志11》等商业游戏的地图、笔触、UI或素材。

当前正式地图数据使用 `HanWorldV1` 的2000米 Cell。它是战略交互尺度，不是单体建筑实测尺寸。
一个Cell只有一个Owner、一个基础Facility槽和一个独立Force槽；Facility与Force是不同占用槽。

## 5. 核心系统

- 永久人物、家庭、家族和多代传承；
- 人物属性、技能、知识、教育、实践与词条；
- 数据驱动作物、产品、配方、工艺、设施和科技；
- 生产、建设、仓储、市场、商旅、运输、税收和财政；
- 官职、军职、爵位、皇室、王国、政权与政治AI；
- 任务、历史事件、消息、有限认知和情报；
- 真实服役、装备、兵种、军粮、行军、阵型、局部战斗和战争回写；
- NPC家庭、组织、市场、建设、迁徙和战争的持续自主运行；
- MOD和数据包扩展。

## 6. Facility 的统一含义

设施不按宫廷、家族、官府和民间复制多套代码，而使用：

```text
FacilityDefinition（基础机制）
→ Profile / Variant（具体配置）
→ FacilityState（世界实例）
```

设施成长通过参数升级、设备/内部模块、配方或服务扩展、改造转型和新增Cell空间扩张实现，
不是一个简单等级自动增加全城百分比。

## 7. 权力的统一含义

以下关系彼此分离：

```text
土地所有权
设施控制与运营权
行政管辖权
官职权限
军职和实际兵权
爵位与封邑收益
个人、家族、皇室和国家资产
```

县令不拥有全县土地；家主管理族产但族产不属于家主个人；将军指挥官军但官军不是私人财产；
诸侯王拥有封国身份和收益，但不拥有封国内所有Cell。

## 8. 参考作品的使用方式

项目会研究《三国志》系列、《九州：商旅/立志》、《吾今有世家》、《了不起的修仙模拟器》、
《鬼谷八荒》、《中华三国志》等作品的系统优点，但只吸收抽象玩法思想和问题解决方式。
代码、文本、地图、美术、音乐、数值、任务和UI必须原创或来自许可证兼容的开源资源。

## 9. GPT 的合适职责

GPT适合：

- 帮助讨论系统应该怎样交互；
- 对比参考游戏的优缺点并进行原创转化；
- 发现规则冲突、遗漏和玩家操作压力；
- 整理历史资料、设计方案、任务书和验收标准；
- 将用户想法转成可供Codex核对和实施的结构化提案。

GPT不应：

- 在看不到仓库时声称功能已经实现或测试通过；
- 擅自改变存档、永久人口、Cell尺度和世界守恒规则；
- 把商业游戏内容直接复制进项目；
- 把建议、已接受设计、任务书、代码完成和玩家验收混为一谈。
