# 可复制给GPT的启动提示词

## 1. 通用启动提示词

```text
这是开源Unity游戏《群雄志：仕途》（Mandate of Heroes）的项目资料。

请先完整阅读我上传的GPT_HANDOFF资料。你必须遵守：
1. 区分“已有原型、已有底座、已定方案、待研究”；
2. 不把建议、用户接受、任务书、代码完成、测试通过和人工试玩混为一谈；
3. 维持一个世界、永久人物、人口/物资/兵员/财政守恒、有限认知、稳定ID和存档兼容；
4. 不复制商业游戏代码、地图、美术、UI、文本或数值；
5. 如果资料冲突，先列出冲突，不要静默选择；
6. 明确区分“项目已有规则”“你的推断”“你的新增建议”“需要我确认的决定”。

本次问题：<填写>
希望你输出：<讨论方案/对比/任务书候选/文档修订建议>

最后请按照06_DECISION_AND_CHANGE_RETURN_TEMPLATE.md整理结论，便于我交给Codex核对和执行。
```

## 2. 讨论一个新系统

```text
请在不改变项目不可破坏规则的前提下，讨论以下系统：
<系统名称和我的想法>

请依次给出：
1. 该系统解决的玩家问题；
2. 玩家亲自操作、部分委任、完全委任三种体验；
3. 需要新增或复用的世界事实；
4. 与人物、家庭、Facility、组织、经济、知识、政治、战争的交互；
5. NPC如何在有限认知下使用同一规则；
6. 存档、确定性和大规模人口性能影响；
7. 参考游戏中可借鉴的抽象思想和必须原创的部分；
8. 与现有文档可能冲突的地方；
9. 需要我确认的决策；
10. 如果接受，建议修改哪些项目文档。

不要直接假设已经进入开发排期。
```

## 3. 对比参考游戏并原创转化

```text
我们想研究以下参考游戏：<游戏列表>。
目标系统：<系统>。

请不要复制原作内容。请用表格区分：
- 原作解决的设计问题；
- 值得吸收的抽象机制；
- 不适合本项目的部分；
- 如何改造成东汉统一世界、永久人物和真实经济下的原创机制；
- 对玩家亲自操作和组织委任分别有什么意义；
- 需要的数据对象与世界后果；
- 许可证或知识产权风险。

最后给出一个原创整合方案，而不是把多个游戏玩法机械拼接。
```

## 4. 审查现有方案

```text
请审查我上传的方案，不要默认同意。

重点检查：
1. 是否制造第二套世界账；
2. 是否删除、合并或重随机永久人物；
3. 是否凭空产生人口、物资、兵员、财政或情报；
4. 是否把开放内容写死为枚举；
5. 是否绕过人物时间、权限、土地、设施、材料或运输；
6. 是否会让玩家操作过于赶或过于复杂，委任是否真正可用；
7. 是否与存档、确定性和大规模运行冲突；
8. 是否误报当前实现状态；
9. 是否存在商业游戏内容复制风险。

请按严重度列出问题，并给出最小修改方案和需要用户裁决的问题。
```

## 5. 建立下一阶段任务书候选

```text
请根据已上传的系统总纲、领域设计、当前任务和验证证据，建立下一阶段任务书候选。

任务书必须包含：
- 背景与真实当前状态；
- 本阶段唯一主要目标；
- 纳入与明确不纳入范围；
- 需要修改的数据合同、代码层、内容和界面；
- 存档迁移与兼容要求；
- 确定性、守恒和有限认知要求；
- 玩家亲自操作与委任操作；
- 实施步骤；
- 全工程编译、核心测试、Unity测试和人工试玩分别如何验收；
- 停止条件、300秒外部工具超时和失败证据要求；
- 预计修改的文档和文件类型。

不要宣称任务已经执行，不要自行决定提交或推送，不要用任务编号推断优先级。
```

## 6. 合并新的外部设计资料

```text
请将新资料与项目现有权威文档进行冲突审计。输出时分成：
1. 完全重复、无需新增的内容；
2. 可以补强现有规则的内容；
3. 与项目规则实质冲突的内容；
4. 候选数值或待研究内容；
5. 应进入哪个正式领域文档；
6. 只应保留为来源记录的内容；
7. 需要用户明确裁决的冲突。

不要因为新资料更新就自动覆盖Cell尺度、永久人物、存档、稳定ID、守恒或当前开发顺序。
```

## 7. 把GPT结果交给Codex时附加的话

```text
下面是我与GPT讨论形成的候选结论。

请不要直接假设它与仓库兼容。先读取AGENTS.md、项目Skill、task-routing、系统总纲和相关领域设计，
检查工作区、现有代码、测试和存档事实；列出冲突和需要我确认的改变。

已经由我明确接受的决定：<列出>
仍只是GPT建议的部分：<列出>
我要求Codex执行的范围：<分析/修改文档/建立任务书/实现代码/测试/提交推送>

外部工具遵守300秒硬超时，保留无关工作区修改，未经授权不要提交、推送、删除文件或关闭Unity。
```
