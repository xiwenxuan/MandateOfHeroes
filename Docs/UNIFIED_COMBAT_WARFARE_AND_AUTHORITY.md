## 1. 文档定位

本文归纳个人战斗、人物属性、装备生产、兵种编成、阵法战法、计谋情报、军团战争、职业参与、身份权限和战争后果的统一设计。

本文建立在以下既有原则之上：

- 人物是世界中真实存在的主体；
- 八项基础禀赋、十类专业能力和五维摘要沿用 `CHARACTER_ATTRIBUTES_TRAITS_AND_GROWTH.md`；
- 玩家与 AI 使用同一套规则；
- 军队、装备、财政、人口和物资必须遵守世界守恒；
- 个人战不是脱离世界的小游戏；
- 高职位扩大权限和影响范围，但不剥夺人物亲自行动的能力。

## 2. 核心愿景

战争系统的核心不是让玩家在战略地图、军团战和个人战之间选择三个互不相干的玩法，而是：

```text
同一个真实世界
+ 同一批真实人物
+ 同一批真实装备
+ 同一条生产和运输链
+ 同一场持续推进的战争

根据人物当前身份、职位、地点、信息和责任，
向玩家开放不同尺度的观察与操作。
```

普通士卒生活在眼前的阵列与搏杀中；伍长同时关心自己和身边数人；军官指挥局部队伍；主将规划行军、补给与会战；都督协调多个军团；君主决定战争目标、财政和任命。

高层人物仍可进入低层战斗，但其注意力、身体和时间不能同时存在于所有尺度。主将亲自冲阵时，远处军队必须由副将、预设军令和 AI 继续运行。

## 3. 统一层级

```text
战争 War
└─ 战役 Campaign
   └─ 战斗 Battle
      └─ 局部交战 Engagement
         └─ 个人遭遇 Encounter
```

### 3.1 战争

回答“为何而战、打到何时”：

- 交战势力；
- 战争理由；
- 战争目标；
- 盟友与附属方；
- 战争支持与厌战；
- 和谈条件；
- 战争结果及合法性变化。

### 3.2 战役

回答“如何实现战争目标”：

- 目标地点；
- 参战军团；
- 集结地；
- 主攻与牵制方向；
- 行军路线；
- 补给基地和运输线；
- 战役阶段；
- 主动权与战役进度。

### 3.3 战斗

回答“某一战场如何部署和决胜”：

- 地形和天气；
- 双方部署；
- 左翼、中军、右翼与预备队；
- 阵法；
- 战术意图；
- 战场通信；
- 撤退和追击路线；
- 总体胜负与战后控制权。

### 3.4 局部交战

由几十至数百人的战术单位在具体位置发生：

- 盾阵推进；
- 骑兵侧击；
- 弓弩压制；
- 寨门争夺；
- 桥梁防守；
- 阵线突破；
- 局部溃败和追击。

局部交战是军团层最小的常规结算单位。

### 3.5 个人遭遇

从某个局部交战中展开少量真实人物：

- 士卒短兵相接；
- 队长维持阵线；
- 保护军旗；
- 救援军官；
- 夺桥、破门和纵火；
- 突袭主将；
- 战场单挑；
- 掩护撤退。

个人遭遇必须有对应的局部交战、参与者、地点、目标和时间，不能凭空生成不属于任何军队的敌人。

## 4. 五条统一规则

### 4.1 一本人物账

军队人数来自真实服役人物。阵亡、受伤、失踪、被俘和逃亡都必须落实到具体人物或明确的人口批次。

### 4.2 一本装备账

军队装备率来自成员实际领取的装备。个人战损坏一面盾，所属队伍下一阶段的盾牌齐整度就会下降，不能再从抽象军械数值中重复扣除。

### 4.3 一份伤亡预算

个人遭遇产生的明确伤亡属于所在局部交战的总伤亡，不能在军团结算中再次叠加。

### 4.4 一个持续战场

玩家进入个人战时，其他战线不会暂停。远处命令、增援、溃败、补给和副将决策继续推进。

### 4.5 一套行动规则

玩家和 AI 使用相同的属性、装备、权限、信息和行动条件。AI 可以误判、迟疑、违令和投降，但不能读取未知伏兵、隐藏属性或玩家输入。

## 5. 人物属性如何进入战斗

人物战斗表现采用：

```text
基础禀赋
+ 专业能力、知识和技能
+ 实战经历
+ 当前健康和心理状态
+ 实际装备
+ 性格、志向和关系
+ 身份、职位与权限
+ 所属组织和同伴
+ 战场环境与信息
```

不设置能够覆盖所有规则的单一“武力值”。五维中的武勇、统率和智略用于快速阅读和 AI 初筛，具体结算仍读取底层数据。

### 5.1 八项基础禀赋

沿用既有人物设计：

| 禀赋 | 个人战斗作用 | 军团作用 |
| --- | --- | --- |
| 体质 | 健康、恢复、失血与疾病抵抗 | 持续行军和伤病恢复 |
| 力量 | 负重、重兵器、冲击和破架 | 重装适应、工事和近战冲击 |
| 灵巧 | 兵器操作、反应、骑射和精细动作 | 复杂战法和器械操作 |
| 感知 | 察觉攻击、伏兵和环境异常 | 侦察、警戒和情报发现 |
| 记忆 | 招式、军令、路线和知识保持 | 训练、条令和复杂命令记忆 |
| 思辨 | 判断、预判、战术理解 | 战法、计谋和战场分析 |
| 意志 | 恐惧、疼痛、压力和坚持 | 士气稳定、纪律和逆境执行 |
| 亲和 | 沟通、鼓舞、建立信任 | 部下认同、协调和劝降 |

禀赋代表条件，不代表已经掌握技能。力量高不等于精通枪术，思辨高不等于会指挥军队。

### 5.2 专业能力与后续子技能

基础实现先复用军事、武艺、医药、工艺、商业、情报等专业总能力以形成验证证据；
完整目标包含下列必要子技能及其继续扩展，不把基础实现当作设计上限：

- 刀、剑、枪矛、弓弩、盾、徒手；
- 骑术、骑战；
- 阵列训练；
- 小队指挥、战场指挥；
- 侦察、攻城、守城、后勤；
- 战地医疗；
- 军械制造和维修。

技能主要负责：

- 解锁动作；
- 降低动作成本；
- 提高执行稳定性；
- 减少灾难性失败；
- 改善训练和传授效率。

### 5.3 武艺、临阵与谋断

- **武艺**：兵器控制、动作精度、发力、应招和变招；
- **临阵**：体力分配、带伤行动、多人混战、保持队列和撤退判断；
- **谋断**：察势、识破、制造破绽、欺骗和时机选择。

演武可以提高武艺，真实战场才是临阵经验的重要来源。谋断不能让人物获得全知，只改善其处理已有信息的能力。

### 5.4 即时状态

战斗读取：

- 健康；
- 劲力和疲劳；
- 架势；
- 先机；
- 疼痛和失血；
- 恐惧；
- 饥饿和睡眠；
- 疾病；
- 身体部位伤势。

右臂伤影响持械，左臂伤可能影响盾牌，腿伤影响移动和撤退，头部伤影响感知与专注。重甲能降低部分致命伤，却增加疲劳、炎热和落水风险。

### 5.5 性格和志向

性格决定 AI 如何使用能力：

| 属性 | 典型战斗行为 |
| --- | --- |
| 野心 | 请战、争功、挑战强敌 |
| 家庭责任 | 保命、救亲属、避免无意义冒险 |
| 风险偏好 | 冲锋、追击和撤退阈值 |
| 仁慈 | 留俘、救伤、避免补刀和屠掠 |
| 社交倾向 | 协作、呼救、鼓舞和说服 |
| 财富欲望 | 战利品、抢掠和受贿倾向 |
| 地位需求 | 维护名誉、争夺功劳和指挥权 |
| 人生志向 | 决定人物为何参战和愿承担何种代价 |

性格不直接增加伤害，而是改变候选行动的权重。

### 5.6 关系和认同

人物是否服从和坚持还取决于：

- 对上级的信任；
- 对组织和战争目标的认同；
- 同乡、亲属、师徒和旧部是否在场；
- 军饷是否拖欠；
- 上级是否曾抛弃伤兵；
- 派系和私人仇恨；
- 军令是否合法；
- 逃跑和投降的现实后果。

## 6. 职业、身份、职位和职责

以下概念必须分开：

- **职业**：人物靠什么生活、拥有什么专业；
- **社会身份**：社会如何识别和评价人物；
- **组织职位**：人物能够合法命令谁；
- **临时职责**：某次任务被授予的范围；
- **现场状态**：人物此刻能否实际行使权力。

### 6.1 职业参与

| 职业 | 战争中的主要入口 |
| --- | --- |
| 士卒 | 列阵、个人战、军令与求生 |
| 军官 | 小队指挥、阵法、纪律和传令 |
| 将领 | 行军、部署、战法和预备队 |
| 医者 | 伤员分类、救治、后送和疫病 |
| 商人 | 采购、承运、仓储、信用和风险 |
| 工匠 | 制造、维护军械、车辆和器械 |
| 官吏 | 征兵、征粮、财政、订单和问责 |
| 侠士 | 护卫、侦察、突袭和局部战斗 |
| 密探 | 情报、破坏、策反和伪令 |
| 农户 | 兵员、乡勇、粮食、劳力和战争承受 |

职业不是战斗职业模板。医者也能从军，商人也能担任军需官，武将也可能兼任地方官。

### 6.2 影响范围

```text
人物有效贡献
= 能力
× 权限
× 信息掌握
× 执行组织
× 可用资源
÷ 管理复杂度
```

能力决定质量，职位、组织和资源决定规模。

## 7. 玩家视角与权限

身份决定人物拥有的最高权限层级；地点、通信和注意力决定此刻能否使用。

| 身份或职位 | 主要视角 | 主要时间尺度 | 核心操作 |
| --- | --- | --- | --- |
| 普通士卒 | 自身与周围数十米 | 回合、分钟 | 出招、列阵、救援、逃跑 |
| 伍长、什长 | 个人与小队 | 回合、分钟 | 前后排、目标、传令和撤退 |
| 队率、基层军官 | 局部战场 | 战斗阶段 | 阵法、战法、增援和轮换 |
| 主将 | 战场与战役地图 | 时辰、日 | 行军、补给、部署和预备队 |
| 都督 | 多军团战区 | 日、月 | 战役目标、军团调配和后勤网络 |
| 君主 | 势力全局 | 月、季度 | 开战、议和、财政、任命和战略 |

### 7.1 信息权限

普通士卒看到的是：

```text
前方出现敌兵
左侧友军似乎后退
队长命令举盾
远处传来鸣金声
同乡受伤
自己的盾已经破损
```

主将看到的是延迟军报，而不是全知状态：

```text
左翼半个时辰前开始交战
右翼请求骑兵增援
敌军中军疑似减弱
林中可能存在伏兵
粮队预计明日抵达但尚未确认
```

战争视角只筛选当前人物亲历、军队共享和职位授权的认知记录。切换到建设、资源、商业或
情报视角也不能读取未知的敌方营寨、仓库、道路障碍和布防。侦察、军报、地图、俘虏口供、
密探和地方向导形成各自带来源、时间、精度与可信度的信息副本，详见
`WORLD_SIMULATION_FOUNDATION.md` 第4.7至4.8节。

### 7.2 权限不是绝对禁止

行动区分为：

- 有权执行；
- 可以建议；
- 可以请求；
- 可以越权；
- 现场条件下无法实施。

普通士卒可以发现伏兵并逐级上报，也可以越权奔向主将营帐，但要面对距离、警卫、可信度和军法。

### 7.3 高职位可以向下行动

主将拥有战略、战役、战术和个人行动能力，但不能同时全力投入所有层级。

主将状态分为：

1. 帐中指挥；
2. 临阵指挥；
3. 亲自参战。

主将亲战时：

- 局部鼓舞和突破能力可能提高；
- 失去部分全局观察；
- 新军报暂时积压；
- 原有命令继续执行；
- 副将或预设军令接管；
- 主将受伤、被俘或死亡会冲击指挥链。

## 8. 指挥链、委托与注意力

```text
主将发布意图
→ 传令系统送达
→ 下级军官理解
→ 基层军官组织
→ 士卒执行
```

每层都可能产生：

- 延迟；
- 部分执行；
- 理解偏差；
- 拒绝执行；
- 擅自扩大；
- 因现场变化主动调整。

### 8.1 指挥委托

主将亲战或失联前可以设置：

- 指挥代理人；
- 左右翼自治范围；
- 预备队投入条件；
- 撤退条件；
- 粮营保护原则；
- 追击限制；
- 通信失败时的预案。

副将依据自己的能力、性格、忠诚、关系和认知执行，而不是成为玩家的完美自动脚本。

君主、都督和主将还可以建立跨层级战争委任，指定战区、目标、预算、军团、补给权限、
交战规则、政策红线、必须上报事项和通信中断预案。下级可以继续拆解军团、部队和后勤任务；
玩家接管一场关键战斗后可以把尚未结束的战区事务交还，不得重置已经发生的行军、补给、
命令、伤亡和工事进度。

### 8.2 指挥空窗

```text
指挥空窗
= 主将离开时间
× 战场通信难度
× 副将能力不足
× 预案缺失
```

可能造成：

- 增援请求无人批准；
- 预备队停留或过早投入；
- 左右翼各自为战；
- 旧命令继续执行；
- 谣言称主将阵亡；
- 多名军官争夺接管权。

## 9. 军队由真实人物组成

建议新增服役关系：

```text
MilitaryServiceState
├─ PersonId
├─ ArmyId
├─ UnitId
├─ Role
├─ Rank
├─ Status
├─ Discipline
├─ Loyalty
└─ ServiceExperience
```

服役状态至少包括：

- 集结；
- 服役；
- 伤病；
- 掉队；
- 逃亡；
- 被俘；
- 退役；
- 死亡。

军队编制建议：

```text
军团 Army
└─ 营或部 Formation
   └─ 队 CombatUnit，约 30～100 人
      └─ 真实服役人物
```

`ArmyState.Troops` 可以保留为查询缓存，但事实来源应是有效服役成员。

普通成员不需要每秒运行完整 AI。军团层按队批量推进疲劳、补给、士气和阵列状态，在关键决策点或被展开为个人遭遇时读取完整人物数据。

## 10. 装备、训练与兵种

兵种不是征兵菜单中的资源，而是派生资格：

```text
人员
+ 实际装备
+ 制式训练
+ 军官组织
+ 当前健康
= 可用兵种和实际战备水平
```

### 10.1 示例：刀盾兵

需要：

- 单手刀；
- 盾；
- 刀术基础；
- 盾术基础；
- 阵列训练；
- 合格基层军官。

一支百人队可能拥有：

```text
刀具配备率：95%
盾牌配备率：72%
护甲配备率：31%
训练合格率：68%
健康可战率：86%
```

系统可以将其识别为“不齐装刀盾队”，允许使用简化盾阵，但效果和稳定性下降。

### 10.2 装备作用

装备优先改变规则：

- 长枪提供控制距离和截击；
- 盾牌提供要害保护和同伴掩护；
- 重甲改变致命伤概率和疲劳；
- 弓弩提供远程攻击并消耗弹药；
- 战马提供机动、冲击和追击；
- 军旗维持识别、通信和士气；
- 工具允许破障、纵火、救治和维修。

### 10.3 装备聚合

部队装备状态从人物实际装备聚合：

```text
EquipmentReadiness
├─ 武器配备率
├─ 盾牌配备率
├─ 护甲配备率
├─ 弹药充足度
├─ 战马可用率
├─ 平均质量
└─ 平均耐久
```

普通制式装备可以按批次记录，名器和传承装备使用独立物品 ID。

## 11. 装备生产和军需供应链

```text
矿场、林场、牧场等原料
→ 冶炼、制革、木料处理
→ 铁匠、木匠、弓匠、甲匠作坊
→ 官府或军队采购订单
→ 商人组织货源与融资
→ 商队真实运输
→ 军械库验收和储存
→ 发放到具体人物
→ 训练形成兵种
→ 战斗损坏、遗失和缴获
→ 维修、回收和再次采购
```

### 11.1 城市和工匠

城市设施决定生产可能，真实工匠、工具、原料和工时决定产能与质量。政府有钱不等于能够立即得到数千套军械。

军需生产具有机会成本：

- 铁匠生产兵器时减少农具产量；
- 木匠生产盾牌和车辆时减少民用工程；
- 军队购买战马时提高商旅运输成本；
- 大量采购粮食时抬高民间粮价；
- 征用工匠可能迫使私人订单延期。

### 11.2 政府采购

采购订单至少包括：

- 采购方；
- 交付地点；
- 商品和数量；
- 最低质量；
- 价格上限；
- 预付款；
- 交付期限；
- 验收和违约规则。

订单可以交给官营作坊、民间作坊、商人、豪族或多个承包方。

### 11.3 商旅作用

商人负责：

- 寻找原料和现货；
- 垫付资金；
- 拆分和组合订单；
- 组织车辆、牲畜和护卫；
- 跨地区运输；
- 承担劫掠、延期和价格风险；
- 处理信用、保证金和违约。

军需货物必须在地图上真实移动，才能被保护、征用、劫掠或转卖。

## 12. 战场结构

基础战场表现可以先用下列结构验证统一结算；完整地图仍按地形、设施、视野与实际部队展开：

```text
              敌军后阵
敌军左翼    敌军中军    敌军右翼
            交战前线
我军左翼    我军中军    我军右翼
              我军后阵
```

同时记录：

- 高地；
- 林地；
- 河流；
- 城门；
- 营寨；
- 狭道；
- 可迂回路线；
- 双方撤退路线；
- 火场和障碍。

战斗按阶段推进：

1. 侦察；
2. 布阵；
3. 接近；
4. 远射；
5. 交锋；
6. 机动和战法；
7. 士气崩溃；
8. 撤退、追击或收兵。

## 13. 兵种

兵种定义部队能够做什么，不采用固定剪刀石头布。

基础兵种验证批次包括但不限于：

- 普通步卒；
- 刀盾兵；
- 长矛兵；
- 弓弩兵；
- 轻骑兵；
- 辎重和工兵。

兵种能力包括：

- 近战；
- 远程；
- 冲击；
- 防御；
- 机动；
- 追击；
- 反骑；
- 攻城；
- 补给消耗；
- 装备和训练要求。

克制来自条件。例如骑兵能否冲击弓弩兵取决于开阔距离、地形、疲劳、是否被发现、对方掩护和反骑能力，而不是固定伤害倍率。

## 14. 阵法

阵法描述：

- 各兵种的位置；
- 正面宽度；
- 预备队比例；
- 队伍之间的保护关系；
- 受到攻击后的反应；
- 变阵条件和成本。

阵法不是“攻击加成”，而是许多人物共同执行的组织状态。

### 14.1 阵型完整度

每个战术单位记录 `FormationIntegrity`，受到以下因素影响：

- 行军后直接接战；
- 地形；
- 训练；
- 军官能力；
- 正面伤亡；
- 侧击；
- 友军溃退；
- 疲劳；
- 临时变阵。

高级阵法只有在装备、训练和阵型完整度满足要求时生效。

### 14.2 基础阵法验证批次

- 方阵；
- 盾阵；
- 锋矢阵；
- 雁行阵；
- 行军阵。

例如盾阵需要足够盾牌、阵列训练、纪律和可展开地形。军官死亡、侧击和盾牌损坏可能使其局部崩坏。

## 15. 战法

战法是战斗阶段中的明确命令：

- 坚守；
- 盾阵推进；
- 齐射；
- 冲锋；
- 集中突破；
- 迂回；
- 轮换；
- 整队；
- 佯退；
- 掩护撤退；
- 追击。

战法成功不是主将属性的单次检定：

```text
战法执行
= 主将决策质量
× 传令质量
× 下级军官理解
× 士卒训练
× 装备适配
× 阵型完整度
× 地形条件
```

每个战法具有：

- 可用阶段；
- 合法目标；
- 装备和兵种要求；
- 指挥成本；
- 疲劳和士气成本；
- 成功效果；
- 失败和误用风险。

## 16. 计谋和有限情报

计谋主要改变信息、环境、路线和敌方判断：

- 伏兵；
- 劫粮；
- 夜袭；
- 火攻；
- 破坏桥梁和道路；
- 伪造军令；
- 散布谣言；
- 策反军官；
- 佯退诱敌。

计谋需要：

```text
情报
+ 执行人员
+ 时间
+ 资源
+ 路线
+ 保密
```

### 16.1 主观战场认知

不同人物和组织拥有各自的战场认知：

- 估计兵力；
- 估计兵种；
- 补给判断；
- 已知阵法；
- 指挥官情报；
- 伏兵怀疑；
- 情报可信度和时效。

设施存在、设施状态与当前布防是不同事实。曾经发现一座关卡，不等于永久知道它当前的
城墙、箭楼、守将、驻军、粮草和外围营寨。军事观察至少记录最后确认时间、来源、估计范围、
可信度和可能欺骗；地形与大型城池变化较慢，驻军、补给、临时工事和军队位置变化很快。

准确情报通过实际计划发挥作用，例如决定攻城器械、兵力、路线、围困周期、奇袭和破坏目标；
过时或错误情报不会简单产生固定减益，而会让计划与当前世界事实发生真实偏差。防守方可以
封锁道路、隐藏仓储与兵力、制造假营火、伪造军报或放出假逃兵进行反侦察。

诱敌不是强制敌方移动，而是让敌方相信：

```text
目标正在溃退
追击收益较高
伏击风险较低
```

敌将再根据能力、性格、军令、补给和关系决定是否追击。

## 17. 个人战斗

个人战斗采用：

- 生命和具体伤势；
- 劲力；
- 架势；
- 先机；
- 针对特定对手的破绽；
- 接触距离；
- 兵器动作和响应窗口。

单回合流程：

1. 察势；
2. 蓄势；
3. 出招；
4. 应变；
5. 结算；
6. 余波。

一次行动依次处理：

```text
能否执行
→ 是否被察觉
→ 是否获得响应
→ 是否形成有效接触
→ 命中部位和装备碰撞
→ 伤势、位移、架势和心理结果
```

### 17.1 个人战如何进入军团战

个人遭遇由军团局势触发：

- 玩家所在队伍接敌；
- 阵线被突破；
- 主将率队冲锋；
- 帅帐遭夜袭；
- 争夺桥梁、寨门或军旗；
- 救援军官；
- 撤退中被追上。

军团状态决定个人战初始条件。被侧击者可能架势混乱、敌人拥有先机；伏击成功者可能隐蔽且目标尚未持械。

### 17.2 个人结果如何改变军团战

| 个人结果 | 局部战场影响 |
| --- | --- |
| 守住寨门 | 阻止敌军进入位置 |
| 击伤队长 | 降低敌队命令和纪律 |
| 夺取军旗 | 降低识别、凝聚和士气 |
| 救回军官 | 避免指挥链中断 |
| 点燃辎重 | 产生火场和补给损失 |
| 破坏障碍 | 打开移动或冲锋路线 |
| 带领结阵 | 恢复局部阵型完整度 |
| 掩护撤退 | 降低溃败伤亡 |
| 追击过深 | 本队失去军官或精锐 |

猛将影响局部结构、指挥链和士气，不能凭个人属性直接消灭成千上万人。

## 18. 局部交战与聚合

军团战按 30～100 人的战术单位结算：

```text
UnitCombatSnapshot
├─ 有效人数
├─ 单兵质量
├─ 士气均值与分布
├─ 疲劳
├─ 阵型完整度
├─ 凝聚力
├─ 装备齐整度
├─ 训练合格率
└─ 军官和特殊人物
```

不应只使用平均士气。相同均值下，全部成员稳定和一半狂热、一半濒临逃亡是不同队伍。

### 18.1 聚合公式

```text
基础能力
= 有效人数
× 单兵技能和健康
× 装备适配

组织能力
= 阵列训练
× 阵型完整度
× 军官指挥
× 凝聚力

环境修正
= 地形
× 距离
× 天气
× 情报
× 战术匹配

实际表现
= 基础能力
× 组织能力
× 环境修正
```

随机只提供小幅不确定性，不能覆盖明显的训练、装备、组织和地形差距。

### 18.2 普通人与关键人物

- 普通士卒以真实成员数据形成统计基础；
- 军官直接影响命令、纪律和阵型；
- 高武艺人物可以触发局部突破、夺旗、救援和护卫事件；
- 医者、向导、军需官、工兵等角色改变对应环节；
- 关键人物仍受装备、距离、体力和多人围攻限制。

## 19. 统一伤亡结算

局部交战先产生阶段性结果预算：

```text
死亡
受伤
失踪
被俘
溃逃
```

如果展开个人遭遇，明确人物结果先进入预算：

```text
局部预算：死亡 12、受伤 25、被俘 4

个人遭遇明确：
敌军官死亡 1
敌兵重伤 2
友军死亡 1

剩余结果：
按风险权重落实其余死亡和受伤
```

个人结果可以改变局势并触发预算重算，但不能在最终总数之外叠加。

### 19.1 个体风险权重

伤亡分配考虑：

- 所在位置；
- 承受攻击强度；
- 装备防护；
- 健康；
- 阵型是否崩溃；
- 是否溃逃或追击；
- 同伴掩护；
- 武艺和临阵；
- 撤退路线；
- 战后医疗。

结果区分：

- 当场阵亡；
- 轻伤和重伤；
- 失踪；
- 被俘；
- 掉队；
- 逃亡；
- 伤后死亡；
- 康复与残疾。

## 22. 战斗示例

玩家担任某营校尉，率领三百人：

```text
刀盾队 100 人
长矛队 80 人
弓弩队 60 人
普通步卒 40 人
军官、医者、传令和辎重人员 20 人
```

战前：

1. 官府军械库只能提供七十面盾；
2. 商人承接订单，从邻城运输三十面；
3. 商队途中遭袭，最终只送达十八面；
4. 刀盾队盾牌齐整度为八成多；
5. 部分新兵训练不足，完整盾阵稳定性有限。

战斗中：

1. 玩家命令刀盾队正面推进；
2. 传令兵将命令送达；
3. 队长正确理解，但部分新兵跟不上队列；
4. 盾阵完整度下降；
5. 敌方骑兵尝试侧击；
6. 玩家调动长矛队拦截；
7. 右翼军官受伤，命令发生延迟；
8. 玩家决定亲率亲兵支援右翼；
9. 副将暂时接管全营；
10. 玩家从局部指挥进入真实个人遭遇；
11. 玩家击退敌方军官并救回队长；
12. 右翼恢复指挥，但副将擅自投入弓弩队追击；
13. 玩家脱离接触后返回指挥视角，收到积压军报。

战后：

- 死伤落实到具体人物和家庭；
- 盾牌损坏进入维修需求；
- 医者根据伤势和身份决定救治顺序；
- 官府发布补充军械订单；
- 商人判断是否继续承担高风险运输；
- 玩家获得军中威望，也可能因擅离指挥位置被问责；
- 副将的自主决策改变关系与评价；
- 幸存者获得临阵和阵列经验；
- 阵亡教习可能造成部分技艺传承中断。

## 26. 验收原则

最终系统应满足：

1. 军队人数能够追溯到真实人物；
2. 兵种能够追溯到装备、训练和编制；
3. 装备能够追溯到生产、采购、运输和发放；
4. 阵法由实际人员和条件维持；
5. 战法通过真实指挥链执行；
6. 计谋依赖情报、人员、资源和时间；
7. 职业提供职责入口，不是简单数值职业；
8. 地位和职位决定权限与责任；
9. 高职位人物能够亲自进入低层战斗，并承担指挥空窗；
10. 普通士卒看不到全局真实数据；
11. AI 只依据自己的认知行动；
12. 个人战和军团战共用人物、装备和伤亡账；
13. 同一输入和随机种子可以稳定复现；
14. 战斗结果能够回写家庭、组织、城市、市场和政治；
15. 没有物资、人员、权限和组织时，人物属性不能凭空创造战斗力。

## 27. 总结

```text
人物禀赋和技能
→ 决定个人能够完成什么

健康、性格、志向和关系
→ 决定此刻能发挥多少、愿意如何行动

装备
→ 决定可用动作、保护方式和战斗成本

训练和编制
→ 把真实人物组织成兵种

阵法和战法
→ 把各队能力组织成战场行动

计谋和情报
→ 改变环境、认知和敌方决策

职业
→ 决定人物通过何种职责参与战争

身份、职位和军令
→ 决定能够看见什么、命令谁和承担何种责任

城市、工匠、官府和商旅
→ 提供军队赖以存在的物资与供应链

统一结算和世界回写
→ 让每场战争真正改变人物、家庭、军队、经济和历史
```

系统的最终目标不是制造一个更复杂的伤害公式，而是让战争成为整个世界运行的集中体现：每一名士卒有来历，每一件军械有来源，每一道命令有权限，每一次执行有组织过程，每一处伤亡都留下真实后果。

## 28. 城防网络与攻城通行 V0

城墙和城门都是统一世界中的真实Facility；护城壕是具有稳定ID、Cell、状态和通行限制的防御地物。防线以
`FortificationNetwork` 组织，主城墙和宫墙可建立父子关系，但分别保存状态：大城出现缺口不会自动摧毁
南宫或北宫防线。

城墙至少保存高度、厚度、材质、最大/当前耐久、具体守军Person和 `Intact / Damaged / Breached /
Destroyed` 状态。`Intact` 与 `Damaged` 阻止普通Force跨越；耐久归零形成 `Breached` 可通行交叉点。
云梯只有在有效高度不低于墙高时才能越墙。城门保存Owner、Controller、开闭、耐久、通行容量和具体守军；
只有Controller能改变正常开闭状态，摧毁后才无条件形成通路。积水护城壕阻止普通移动，须受控门路、架桥或
填壕才能跨越。

184洛阳V1已实现上述领域合同、十二座独立大城门及南北宫独立网络；完整冲车、投石机、地道、火攻、攻城
后勤与战术动画仍为待扩展，不得据此宣称完整攻城系统已经完成。
