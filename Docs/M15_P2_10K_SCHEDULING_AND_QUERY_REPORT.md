# M15-P2：1万人调度、分区与查询报告

## 一、结论边界

2026-08-01，SQLite、紧凑分区二进制和混合存储三种候选使用相同P2数据集，完成绝对日
1、30、365的连续推进，并通过具体人物回写、跨分区引用、血缘/组织/劳动力查询、关注

- 初始永久人物10,000、家户2,524、稳定分区101、初始到期事件10,000；
- 确定性跨分区迁徙样本64人；旅行中32人；已占用32人；
- 全年只扫描10,000个实际到期节点，没有扫描后续年度事件或已完成事件；
- 出生1,397人，立即获得永久ID并加入具体家户；
- 死亡1,447人，身份、家户与血缘记录继续保留；
- 迁徙1,514人，世界永久人口总量不受迁徙影响；
- 期末永久人物11,397，期末存活9,950，满足：
  `11397 = 10000 + 1397`，`9950 = 10000 + 1397 - 1447`。

| 候选 | 初写 | 日/月/年调度 | 物理体积 | 增量 | 检查点 | 恢复 |
