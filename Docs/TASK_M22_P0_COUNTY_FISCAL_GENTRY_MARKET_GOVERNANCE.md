# M22-P0 任务书：县级财政、豪族、市场与基层治理守恒账

## 一、阶段目标

承接系统总纲的首项全局建设顺序，在现有200—500人真实村庄切片上建立一个县的最小治理闭环：

```text
家户财富与秋收税粮
→ 县级征收、村庄留成与县仓上解
→ 官府俸给与县仓救济
→ 豪族遵从、粮价与粮食安全反馈
→ 县城和村庄治安变化
```

本阶段交付的是可存档、可审计、可重复验证的领域底座，不把自主建设、土地兼并、案件链、
州郡上缴或完整三级财政宣称为已实现。

## 二、权威边界

- 世界守恒、财政层级和市场规则以 `WORLD_SIMULATION_FOUNDATION.md` 为准。
- 永久人物、家户与大规模调度遵守 `TASK_M12_PERMANENT_POPULATION_AND_ATTENTION.md`；
  县级结算按村庄家户索引工作，不扫描全体人物。
- 存档与确定性遵守 `DETERMINISTIC_SIMULATION_AND_SAVE.md`；新增持久事实使用V12顺序迁移。
- 豪族、税目和财政流水类型是领域协议；未来具体税制、政策和地方内容继续使用稳定ID扩展，
  不把商业游戏数据或表现层对象写进核心世界事实。

## 三、工作包

### WP1：V12县级治理领域合同

- 增加县级治理、豪族家户、家户税账和县级财政流水。
- 保存县政府、管理者家庭、县仓、税率、留成率、登记覆盖、行政效率、市场压力和累计结果。
- 验证稳定ID、县—村—家户归属、政府组织、非负库存与双边账守恒。
- 提供V11→V12空集合顺序迁移，不反向编造旧存档财政史。

### WP2：月结与年结

- 每30日按稳定ID结算一次，同日重复执行无副作用。
- 每月官府金库向具体管理者家庭支付俸给。
- 粮食安全不足或县级粮价过高时，县仓向具体村庄拨付救济粮。
- 每年第十月从具体家庭财富征收现金税；欠税进入永久家户税账。
- 同日村庄已收税粮按地方留成率从村仓上解县仓，不能重复计算。

### WP3：豪族、市场和治安反馈

- 原型县明确三户豪族及其影响、税收遵从和累计减免。
- 县级粮食挂牌价相对均衡价形成市场压力。
- 行政效率、粮食安全、市场压力、救济和豪族影响共同形成县村治安反馈。
- 反馈不改变人物是否存在，也不以关注等级改变世界事实。

### WP4：原型、存档与验证

- 300人村庄原型加入县政府、县仓、粮食市场和豪族数据。
- `WorldSimulator` 在村庄月结及缓存刷新后执行县级结算。
- 验证现金和粮食总量在县级转移前后守恒、豪族遵从改变实际税收、救济真实转移、
  同日幂等、V11迁移、V12往返和非法不平账拒绝。

## 四、不纳入本阶段

- 州、郡、中央国库和跨级财政上缴。
- 土地兼并、依附人口、庄园、私兵和豪族政治行动AI。
- NPC自主选址建设、许可、合资、借贷和建设施工。
- 完整户籍稽核、胥吏执行、贪腐案件、诉讼、赈灾任务和玩家治理界面。
- 大规模县目录批量生成及一千万级县级治理压力测试。

## 五、验收标准

1. V12保存四类县级持久集合，V11可顺序迁移且不虚构记录。
2. 家庭现金税与官府金库、村仓与县仓的每笔转移均为双边相反增量。
3. 第十月结算产生真实现金税和税粮上解，账户与库存不为负。
4. 豪族税收遵从改变实际县税收入，并记录累计减免。
5. 低粮食安全或高粮价触发县仓到村仓的真实救济及治安反馈。
6. 同日重复结算不增加流水、不重复转账。
7. 同种子同持续时间产生相同快照；V12往返保留县级事实。
8. 非法引用、越界参数、负库存或不平衡财政流水被领域校验拒绝。
9. 全工程编译、核心测试、受控Unity EditMode、`git diff --check`和范围审阅通过。
