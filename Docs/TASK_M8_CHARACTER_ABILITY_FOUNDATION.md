# M8 任务书：人物多属性与五维能力基础

## 一、任务目标

依据《人物多属性、词条与家族培养设计》的 P1 开发顺序，建立可存档、可验证、可稳定重算的人物能力底座：

- 八项基础禀赋；
- 十类专业总能力；
- 三国志式五维综合评价；
- 人生志向；
- 普通人物稳定生成与重要人物倾向；
- 人物面板展示；
- 旧存档迁移。

本任务不提前实现 P2 教育、P3 词条和 P4 家学。后续系统必须建立在本任务的数据与派生规则之上。

## 二、设计约束

1. 禀赋、专业能力使用 0—10000 基点保存，界面显示为 0—100。
2. 五维只是摘要，必须由底层禀赋、专业能力、性格和当前健康实时派生，不单独存档。
3. 相同世界种子与人物永久 ID 必须生成完全相同的初始能力。
4. 已初始化人物不得因为重进场景、加载面板或重复调用初始化而重新随机。
5. 普通人物由稳定随机与职业背景共同生成；重要人物在同一规则上增加史实角色倾向，不复制任何商业游戏数值。
6. 新生儿能力由父母禀赋倾向、自然变异和稳定世界种子共同决定；专业能力不作生物遗传。
7. 能力不能直接创造人口、物资、财政、军队或职位。
8. 旧版医术字段暂时保留以兼容现有存档和医疗玩法，新医药能力成为统一能力来源。

## 四、实现事项

1. 新增人物能力领域模型及严格基点校验。
2. 新增稳定能力初始化器：
   - 普通背景；
   - 军人；
   - 官吏；
   - 商人；
   - 医者；
   - 农户；
   - 武人；
   - 学者；
   - 统帅；
   - 宗教领袖。
3. 为原型中的刘备、关羽、张飞、卢植、张角、商人、医者和农户匹配角色倾向。
4. 自建人物按开局身份获得对应背景，不获得玩家专属超模加成。
5. 新生儿生成时初始化禀赋和人生志向。
6. 医疗系统读取统一医药能力，并兼容旧医术字段。
7. 人物面板展示八维、十类能力和实时五维。
8. 世界存档版本升级，并迁移旧人物能力。

## 五、验收标准

1. 原型世界所有人物均完成人物能力初始化。
2. 同种子、同人物 ID 的能力完全一致；不同种子至少有一项基础禀赋不同。
3. 重复初始化不会改变人物能力。
4. 自建军人、县吏、商人、医者的优势专业符合身份。
5. 五维能够稳定重算，健康下降只影响需要身体发挥的武勇。
6. 新生儿禀赋受到父母倾向影响，专业能力从零基础开始。
7. 旧版本存档能够迁移到当前版本。
8. 存档往返后底层能力和五维结果保持一致。
9. 非法能力基点会被世界校验拒绝。
10. 现有核心测试不得回归。

## 六、明确不在本任务范围

- 月度教育计划、教师和学习费用；
- 技能成长、实践岗位和递减收益；
- 词条定义、冲突、进阶和隐藏认知；
- 家学、教材、图纸和传承退化；
- 分类声望与主观人物认知；
- 设施、军队、城市和关系词条。

这些内容依次进入 M9—M13，不能绕过本任务的底层能力结构。

- 新生儿从父母禀赋均值产生稳定变异，专业能力保持新手起点。
- 医疗系统读取统一医药能力，并保留旧医术字段兼容路径。
- 人物面板展示五维、八维、十类专业能力和人生志向。
- `WorldSnapshotMigrator` 支持 V1→V2→V3 连续迁移。

### 验证结果

- `Mandate.Domain`、`Mandate.Simulation`、`Mandate.Persistence`、`Mandate.Presentation`、`Mandate.Domain.Tests` 五个程序集编译通过。

- 本任务新增 10 项人物能力测试，覆盖任务书全部验收条件。

### 当前限制

- 专业能力第一版仍是十类总熟练度，尚未拆分子技能、知识和重大经验。
- 重要人物目前使用角色背景倾向，不是最终史料人物卡；以后由史料数据层提供权重和已知经历。
- 新生儿只有禀赋倾向与自然变异，尚未模拟孕期、营养、疾病和幼年环境。
- 五维暂未读取军中威望、地方信息、职位授权和团队信任，这些将在声望与认知里程碑接入。
- 旧 `MedicalSkillBasisPoints` 仅为兼容字段，后续存档大版本再移除。
