# M26-P6 永久家族、产业传承与公共仕途候选任务书

## 一、定位与优先级

本任务将 `REFERENCE_HOUSE_OF_LEGACY_GAMEPLAY_ANALYSIS.md` 提炼出的通用体验问题，转化为
《MandateOfHeroes》原创、可验证的永久家族纵向切片。它不复制《吾今有世家》的代码、文本、数据、数值、地图、UI 或素材。

本文件是候选任务，不因 M26-P6 编号自动获得优先级。全局顺序仍以
`GAME_SYSTEMS_MASTER_AND_STATUS.md` 和用户当轮指令为准。M26-P5/P5A 负责商号和城镇经营入口；本任务只负责让一次家庭选择跨越婚姻、后代、产业责任和仕途，形成可继承的长期结果。

### 启动条件

1. M26-P1/P5A 的商户家庭首个可玩闭环已有人工试玩结论。
2. M26-P5 的商号身份、岗位或委任边界已确定，或本任务明确不依赖尚未实现的部分。
3. M12 永久人口、家庭、关系、出生和死亡事实继续作为唯一权威来源。
4. 若新增持久状态，先确定存档版本、顺序迁移、往返测试和不变量校验。
5. 本切片不以大规模城建、全国世家 AI 或完整官场作为前置条件。

## 二、首个玩家体验

玩家以中山商户家庭的一名现有永久人物为当前角色，在完成首轮商旅经营后，可以：

1. 查看家庭成员、亲属关系、居住、健康、技能、责任和家庭目标。
2. 就一项婚姻提议与另一真实家庭协商，并明确聘财、居住和财产边界。
3. 婚姻成立后由正式人口规则产生家庭关系；在满足时间与生育条件时产生永久新生儿。
4. 为一名适龄家庭成员选择一次有成本的教育/实践方向。
5. 让一名合格成员申请或接受一个地方公共职务候选机会。
6. 由家庭会议决定谁继续经营产业、谁承担公共职务、谁照料依赖者。
7. 推进足够时间后，查看新生儿、婚姻、产业、职务、关系和家史的长期结果。
8. 当前角色死亡或失去行动能力时，从符合规则的真实亲属中接管，不复活、不复制、不重随机人物。

最小循环：

```text
家庭目标与压力
→ 婚姻/教育/职业机会
→ 家庭会议与资源承诺
→ 人物迁居、任职或继续经营
→ 时间推进产生收益、冲突、出生、成长或死亡
→ 家产、关系、责任与记忆结算
→ 下一代继续面对同一个世界
```

## 三、不可违反的世界合同

1. 每个人从出生起具有永久稳定 ID；不得将普通居民合并成家族人口数字。
2. 家谱、家庭列表、家史和继承界面都是权威人物/家庭事实的只读投影。
3. 婚姻是两个具体人物之间的关系，并引用双方家庭；不得只增加抽象“联姻值”。
4. 出生必须创建一个永久人物，记录父母、出生时间、出生地、家庭、居住和初始健康事实。
5. 玩家接管只改变控制主体，不改变人物身份、属性、寿命、财产来源或世界时间。
6. 家庭资金、产业、土地、设施、商品批次和债务不能因婚姻、继承或接管重复产生。
7. 公共职位属于真实组织，具有职位 ID、任命来源、辖区、权限、任期、职责和状态。
8. 任职不会使人物脱离健康、家庭、居住、旅行、财政和死亡规则。
9. 关注度只改变信息和表现精度，不改变出生、婚姻、职业、死亡或继承事实。
10. 随机选择使用稳定 ID、明确时间/动作坐标和项目确定性随机机制。

## 四、实施切片

### P6-A 家庭与家谱查询投影

在现有永久人口和家庭账之上提供有界查询，首版只展示当前家庭、父母、配偶、子女、兄弟姐妹和一层姻亲。至少显示：

- 人物稳定身份、年龄、健康、存活状态和当前居住地。
- 家庭归属、亲属关系和关系来源。
- 当前工作/职务、主要技能、家庭责任和是否可由玩家接管。
- 关键人生事件的来源链接。

不得为绘制家谱复制人物 DTO 或创建第二套亲属真相。大规模历史查询必须分页或按需加载。

### P6-B 婚姻提议与家庭协商

首版只实现一夫一妻、双方存活且达到项目既定适婚条件的候选流程；更复杂历史婚姻形态留待独立设计。状态至少包括：

```text
Draft → Proposed → Negotiating
→ Accepted | Rejected | Withdrawn | Expired
→ Enacted
```

提议记录稳定 ID、发起人与对象、双方家庭、提议时间、期限、聘财/嫁资承诺、婚后居住、家庭归属建议和责任摘要。

执行必须校验近亲边界、现存婚姻、人物状态、位置/可达性、双方同意或合法代理权限以及真实资金和物品。接受不等于立即凭空转移资源；成婚命令统一结算关系、财产和居住。

### P6-C 出生、成长与照料责任

复用 M12 与既有出生增量合同，不创建“玩家家族专用孩子”。首版必须：

- 新生儿从出生起进入永久人物仓储与家庭关系。
- 记录照料家庭、主要照料者和基本供养责任。
- 食物、营养、疾病和医疗继续读取正式世界事实。
- 成长按世界时间推进，不通过点击直接跳为成年人。
- 姓名及其他内容使用数据规则和稳定随机坐标，保存读取不重掷。

本任务不要求完整童年模拟，但必须保证新生儿能够在长期模拟中存活、迁居、失亲、被照料并进入后续教育资格。

### P6-D 教育/实践方向与家庭代价

为一名适龄成员选择首个有界方向：商业实践或地方文书学习。复用既有技能、知识、教育和实践合同，选择必须指定：

- 学习者、指导者或机构。
- 起止时间与地点。
- 家庭支付的真实费用、材料或减少的劳动时间。
- 预期能力、失败/中断条件和完成证据。

人物因生病、迁居、入伍、任职、死亡或家庭无力支付而中断时，保留已经发生的时间和成长，不回滚。

### P6-E 地方公共职务候选

首版只接入一个低层、非世袭、非军事指挥的地方文书候选职位，避免提前建设完整官场。职位必须属于现有地方组织并具有真实空缺。

候选流程至少包含：

```text
Vacant → CandidateProposed → Reviewed
→ Appointed | Rejected | Withdrawn
→ Active → Ended | Removed | VacatedByDeath
```

评审只读取可见且合法的信息：年龄/状态、相关技能、知识、声望、关系、居住和推荐来源。任命不得直接增加虚构能力；任职后人物获得明确权限、职责、时间占用、报酬来源和问责对象。

### P6-F 家庭会议与责任冲突

当同一成员同时被家庭产业、教育、照料或公共职务需要时，生成家庭会议。玩家可以提出方案，但其他成年成员根据关系、利益、健康、责任和信息作出响应，不保证服从。

首版会议至少支持：

- 谁继续管理家庭商号/产业。
- 谁接受公共职位。
- 谁承担新生儿或病弱成员的主要照料。
- 是否支付婚姻与教育成本。

决定必须形成正式责任分配和人物记忆；冲突不能通过 UI 同时把同一人分配到两个互斥地点或时段。

### P6-G 死亡、继承与玩家接管

当当前角色死亡或永久失去行动能力时：

1. 先完成死亡、遗体、债务、未结命令和责任关闭。
2. 按已有家庭与财产规则生成继承候选及争议摘要。
3. 玩家只能从仍存活、具有真实关系且满足接管规则的人物中选择。
4. 无合格直系亲属时，按已设计的旁系、收养、门客转入或家族终止规则处理；本任务首版可以明确阻塞未支持分支，不能生成替身。
5. 接管后世界时间、市场、组织、战争、债务和所有 NPC 状态保持连续。

财产分配必须逐项引用真实所有权；未完成的婚姻、教育、职务和经营责任必须结束、转交或进入争议，不能静默消失。

### P6-H 家史与跨代反馈

建立只读家史投影，首版记录：

- 出生、婚姻、迁居、教育开始/完成/中断。
- 商旅、产业责任、公共任命、免职和报酬。
- 伤病、死亡、继承、债务和家庭会议结果。

每条记录链接稳定人物、家庭、组织、地点、时间和来源事件。家史文本由项目原创模板生成；缺失内容 ID 必须报告，不得改指或重新随机。

## 五、首个验收故事

1. 玩家控制中山商户家庭的成年永久人物甲。
2. 甲完成一次正式商旅，家庭获得可追溯收益并承担现有债务。
3. 另一真实家庭的成年人物乙成为婚姻候选；系统显示已知关系、居住与家庭条件，不显示玩家未获得的信息。
4. 双方就聘财、婚后居住和家庭责任形成提议；拒绝不删除关系或资源，接受后按实转移承诺财产。
5. 婚姻关系、家庭和居住写入权威账并通过保存读取。
6. 在确定性条件满足时出生人物丙；丙立即拥有永久 ID、父母、出生地、家庭、健康和照料责任。
7. 家庭会议决定甲接受地方文书职位，另一真实成员接管部分经营，乙或另一成员承担主要照料。
8. 甲的职务占用时间并提供真实组织支付的报酬；履职与失职产生可追溯结果。
9. 推进多年后，丙达到首个教育资格并开始商业实践或文书学习，家庭支付实际成本。
10. 甲死亡后先关闭职责、债务和未结事务，再由符合规则的家庭成员接管；世界和家史连续。

## 六、自动化验收

至少覆盖：

1. 家谱查询不创建、复制或修改人物。
2. 近亲、已有配偶、未达条件、死亡、失踪或无合法代理的人物不能完成婚姻。
3. 重复执行婚姻命令保持幂等，关系和财产不重复写入。
4. 婚姻财产转移前后资金与具体物品守恒。
5. 同一确定性条件只产生一个新生儿；保存读取不改变姓名、父母或身份。
6. 新生儿被永久人口仓储、家庭、居住和增量存档查询共同找到。
7. 教育消耗真实时间与资源，中断保留已发生结果。
8. 没有真实空缺、授权或合格候选时不能任命职位。
9. 任职、家庭劳动、教育、旅行和照料的互斥时间/位置得到校验。
10. 职位报酬由真实组织财政支付；资金不足形成欠付或失败事实，不凭空发放。
11. 死亡后职位、责任、债务、财产和未结命令按规则关闭或转交。
12. 玩家接管不改变世界时间，不复活、不克隆、不重随机人物。
13. 家史每条记录可追溯至权威事件，删除 UI 缓存后能够重建。
14. 冷区/低关注度与热区执行产生相同婚姻、出生、死亡和继承事实。
15. 存档迁移和往返保持新增事实，旧档迁移不补造婚姻、后代、官职或财产。
16. M12 永久人口、M26 商旅、市场、家庭、组织和世界执行核心回归保持通过。

## 七、人工试玩验收

安排未阅读任务书和实现代码的试玩者完成一个压缩但使用正式世界规则的家庭阶段。试玩者应能：

1. 说清当前家庭为什么考虑婚姻、教育或任职。
2. 看懂每项选择涉及哪些真实人物、财产、时间和责任。
3. 理解家庭成员可以反对或无法执行命令。
4. 在出生、任职或死亡后找到对应世界变化和家史记录。
5. 当前角色死亡后独立完成合法接管，并理解哪些财产或责任没有继承。
6. 用自己的话描述“这一代留下了什么，下一代接手了什么问题”。

## 八、明确不包含

- 复制《吾今有世家》的府邸、城池、人物面板、家谱、提亲界面、文本、数值或素材。
- 一次完成全国世家、完整宗族政治、宗祠、爵位、后宫、皇室、派系和官员 AI。
- 将十万人口聚合成匿名数字或仅为玩家家族保留永久身份。
- 通过婚姻、生育、继承或接管凭空生成资金、土地、产业、技能和关系。
- 完整古代婚姻制度、多配偶、纳妾、离婚、收养和复杂礼法；这些必须另行研究历史与伦理表现。
- 完整官场、科举、军功封爵、领地统治和大规模战争。
- 自由城市建造编辑器或 200 类建筑内容。
- 以固定剧情强迫玩家家族成功，或为恢复“正史”复活人物、重置关系和补发资源。
- 未经许可下载、导入或重制商业游戏图片、图标、字体、音频、地图和数据。

## 九、停止条件

- 若现有家庭、关系、出生、死亡或继承事实之间存在冲突，停止实现并报告具体冲突，不建立玩家专用旁路。
- 若人物存储或大规模家谱查询绕过 M12/M21 永久人口仓储边界，先修正访问方案。
- 若婚姻或继承需要改变存档结构，先提交顺序迁移、旧档兼容和往返测试设计。
- 若官职无法绑定真实组织、职位空缺、权限和财政，不得用“官职加成”冒充完成。
- 若 UI 所需事实只存在于场景对象或临时缓存，不进入表现实现。
- 若首个 M26 商户家庭闭环仍无法被独立试玩者理解，不同时扩展全国世家、完整官场和大型城建。

## 十、完成定义

只有同时满足以下条件，本候选任务才可标记完成：

- 首个验收故事从正式 Demo 入口可以重复完成，且不依赖开发者口头指导。
- 婚姻、新生儿、教育、职位、家庭会议、死亡、继承和接管使用权威永久事实。
- 玩家角色死亡后，同一世界由合法永久人物继续，没有重置或复制。
- 人物、财产、资金、库存、职位和责任在完整路径及失败路径中保持可追溯与守恒。
- 确定性、存档迁移、往返、热冷区一致性和核心回归分别取得自动化证据。
- 全工程编译、核心测试、受控 Unity 测试、`git diff --check` 和差异审阅分别取得结果。
- 至少一次符合第七节的独立人工试玩已有记录，问题已修复或明确登记。
- 所有代码、文本、数据和表现资源原创或具有已登记的兼容许可证。
- 总纲、任务路由、Demo 说明和实际状态同步，且未把候选或原型能力误写成已完成能力。
