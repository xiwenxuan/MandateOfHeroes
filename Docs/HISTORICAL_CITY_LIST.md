# 东汉末至三国时期必要城市清单

## 使用范围

本清单服务于约 190—280 年的战略角色扮演游戏。它不是照搬任何商业游戏的城市表，
而是综合都城地位、州郡治理、战争频率、交通位置及区域覆盖得到的游戏化选点。

历史上的“州”“郡”“县”“城”“关”不是同一层级。游戏中应分别保存：

- `display_name`：玩家看到的常用地名，例如“汉中”。
- `historical_settlement`：具体治所，例如“南郑”。
- `administrative_area`：所属郡国，例如“汉中郡”。
- `site_type`：都城、郡治、县城、军事据点、港口或关隘。
- `modern_location_note`：约今址；古城址与现代同名城市通常并不重合。

## 首个大地图版本建议

为了兼顾开发成本和区域完整性，第一张可玩大地图采用 **24 城 + 10 个关隘/据点**。

### 24 城

洛阳、长安、许昌、邺、蓟、晋阳、陈留、濮阳、宛、汝南、下邳、寿春、合肥、
襄阳、江陵、长沙、柴桑、建业、吴郡、汉中、梓潼、成都、江州、永安。

### 10 个关隘/据点

虎牢、函谷关、陈仓、阳平关、剑阁、樊城、夏口、夷陵、濡须口、赤壁。

这套配置能形成以下主要战略轴：

- 河北—中原：蓟 → 邺 → 濮阳/陈留 → 许昌
- 关中—中原：长安 → 函谷关 → 洛阳
- 中原—荆州：许昌/宛 → 襄阳 → 江陵
- 淮南—江东：寿春/合肥 → 濡须口 → 建业
- 荆州—江东：江陵 → 夏口/柴桑 → 建业
- 汉中—巴蜀：汉中 → 阳平关/剑阁 → 梓潼 → 成都
- 巴蜀—荆州：江州 → 永安 → 夷陵 → 江陵

## 时间变化规则

地名和行政地位需要按剧本年份变化，不能用一张静态表覆盖整个 190—280 年：

- 许县在建安时期具有汉廷政治中心地位，后作为魏五都之一。
- 秣陵在孙氏统治下改称建业；游戏应按年份显示名称。
- 鄂县在孙权时期改称武昌，并一度成为都城。
- 鱼复在蜀汉时期改称永安。
- 部分郡治因战争迁移；“江夏”等区域尤其不宜固定成唯一永久坐标。
- 三国政权正式建立于 220 年以后，但游戏前期仍沿用东汉州郡体系。

## 资料基线

后续坐标核对优先使用：

1. 《三国志》及裴松之注、《后汉书》《晋书》等历史文献。
2. 谭其骧主编《中国历史地图集》第三册（三国、西晋）。
3. 中国历史地理信息系统 CHGIS 的历史地名与行政单位数据库。
4. 地方考古报告和地方志，仅用于校验具体古城址。

所有坐标都要保留“约址”和不确定性说明。地图服务于历史策略模拟，不宣称提供现代测绘精度。
