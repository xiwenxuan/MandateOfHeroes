## 二、整体玩法结构

### 2.1 核心幻想

**官方说明**：玩家管理一个从战乱和破败祖宅中重新起步的古代家族，通过一代代人物养成、产业经营、府邸与城池建设、世家交往、科举入仕、从军和政治活动扩大影响。

其核心并非“单个角色无限成长”，而是：

```text
个人获得机会与承担风险
→ 家庭积累人口、关系、产业与声望
→ 家族成员分流到经商、仕途、婚姻和军事道路
→ 成员的成功与失败改变家族位置
→ 死亡和代际更替后，家族继续存在
```

### 2.2 三种同时推进的规模

1. **人物规模**：少量重点族人拥有属性、关系、身份和可选择行为。
2. **家族规模**：家产、府邸、家规、婚姻、门客、仆役、声望与传承形成长期账户。
3. **地方/天下规模**：城池、郡县、官职、其他世家、叛乱和战争提供外部机会与压力。

**启发**：本项目可让玩家在同一永久人物系统中改变操作层级，而不是在个人 RPG、家族菜单和战略地图之间维护三套互不相干的世界。

## 三、本地截图能够确认的玩法

### 3.1 城池与府邸建设

**本地观察**：等距地图中可见城墙、道路、桥梁、河道、住宅、商业街、庭院、大型公共建筑、农田、果园、林地与装饰。建造菜单至少区分居住、生产和装饰，并存在未解锁建筑。

**本地观察**：城市中出现大面积同类住宅和生产地块，说明后期支持批量扩张。特色建筑具有独立管理面板及升级、批量处理或人员管理入口。

**推断**：建筑共同影响人口容量、资源、环境、安全、便利或繁荣等汇总指标；截图不足以证明每栋建筑是否对应真实土地所有者、住户和工人。

### 3.2 人口、资源与生产

**本地观察**：界面显示接近十万的城市人口、多项城市指标、等级/进度以及多类别资源库存。农林地块显示作物或产出图标，存在可收获状态。

**推断**：参考作品大概率将大量普通人口和资源汇总为城市数值，同时对少量核心家族人物做详细模拟。截图不能证明种子、工作者、批次、运输、消费与资源守恒如何处理。

### 3.3 家族重点人物

**本地观察**：“本族人员列表”显示独立人物形象和分类页，人物数量远小于城市总人口。

**公开截图观察**：人物面板可见年龄、健康、心情、魅力、文才、武才等信息，并提供提亲、聊天、吟诗作赋、比武等互动。

**启发**：重点人物信息必须来自永久人物事实；列表是查询投影，不能因为人物离开玩家关注范围就合并、删除或重新生成。

## 四、公开资料补足的关键循环

### 4.1 婚姻与代际延续

**公开截图观察**：提亲会考虑人物、家族地位和聘礼，成功后两人结为婚姻关系。

**官方说明**：游戏强调一代代家族养成和世家联姻。

**推断**：婚姻既连接具体人物，也连接两个家族的地位、资源和关系；当前证据不足以确认生育概率、居住安排、财产归属和继承算法。

**启发**：本项目的婚姻必须是两个永久人物的关系事实，并明确家庭归属、居住、抚养、财产、亲属网络和政治后果；不能只给家族增加一个“联姻加成”。

### 4.2 教育、科举与仕途

**官方说明**：族人可以参加科举、入仕、从军，通过官职、军功和封爵提升家族地位。

**公开截图观察**：存在人物自荐担任郡守、接受或拒绝任命等情境。

**推断**：人物能力、关系、家族地位和政治机会共同决定仕途；截图不能证明官职空缺、考核、俸禄和行政权是否全部进入同一模拟。

**启发**：本项目应让官职成为具体组织中的正式职位，具有任命来源、任期、辖区、权限、职责、预算和问责；任职人物仍然需要生活、迁居并承担风险。

### 4.3 产业、门客与仆役

**官方说明**：玩家可以经营家族产业。公开资料与截图还显示门客、仆役、农场或商铺等经营对象。

**推断**：家族通过配置成员与劳动力获得持续收益，并逐步从亲力亲为转向委派管理。

**启发**：本项目不能把门客、仆役或农户变成没有身份的产能数字。每个劳动者都是永久人物；产业必须引用土地、设施、工作者、投入批次、产出批次、所有权和分配规则。

### 4.4 世家关系、政治与战争

**官方说明**：游戏包含与其他世家的联姻、竞争和冲突，也允许人物从军、参与叛乱平定并进入更高政治层级。Steam 社区公告进一步提到私兵、皇室互动和更大规模战争等扩展方向。

**推断**：家族经营最终会转化为政治资本、军事能力和地方权力。静态资料不足以证明所有世家都使用相同资源和战争规则。

**启发**：本项目的家族不能凭“声望等级”直接获得军队、官位或领地；必须经过真实人物、军役、装备、财政、任命、组织权限与战争结果。

### 4.5 家史与长期反馈

**官方说明/社区公告**：游戏围绕世代传承，并存在族人死亡、家史和安葬相关状态。

**启发**：家史应是出生、婚姻、迁居、教育、职业、任命、产业、战争、伤病、死亡与继承等正式事实的只读投影。它不能拥有第二套人物历史，也不能为了形成漂亮故事而篡改世界结果。

## 五、参考作品的可见主循环

```text
从破败家庭与府邸起步
→ 建设住房和基本产业
→ 获得粮食、资金、人口与生活保障
→ 招募帮手并培养永久族人
→ 通过婚姻扩大亲属与世家关系
→ 让不同成员经商、求学、入仕或从军
→ 将个人成败转化为产业、官职、关系和家族记忆
→ 在死亡、继承和新生儿成长后进入下一代
```

## 六、与《九州：商旅》的互补关系

| 问题 | 《九州：商旅》参考重点 | 《吾今有世家》参考重点 |
| --- | --- | --- |
| 玩家起点 | 具体商人与商队 | 破败家族与祖宅 |
| 中期组织 | 商号岗位和分会 | 家族成员、门客、产业和府邸 |
| 地理行为 | 跨城采购、运输和交付 | 地方建设、仕途和世家关系 |
| 长期成长 | 商号规模与自动经营 | 婚姻、生育、官职和多代传承 |
| 适合本项目的问题 | 如何亲自参与经济 | 人物如何把成果留给后代 |

二者只能提供体验问题，不能拼接成可复制的功能清单或界面方案。

## 七、适合本项目独立解决的问题

1. 玩家角色死亡后，怎样自然接管一个真实亲属，而不是重新开局或克隆能力。
2. 婚姻如何同时影响两个人、两个家庭、居住、财产和社会关系。
3. 子女怎样从出生开始拥有永久身份，并通过真实照料、教育和实践成长。
4. 家庭产业怎样由真实土地、设施、库存和人物劳动组成。
5. 家族成员怎样选择经商、务农、从军、求学、入仕或离开家庭。
6. 官职怎样授予具体权限和责任，而不是成为抽象加成。
7. 玩家怎样委托族人经营，同时保留预算、期限、报告、失败与问责。
8. 家谱和家史怎样从权威事实生成，并在五十年模拟中保持可查询。
9. UI 怎样汇总十万乃至百万人，而不删除、合并或重新随机永久人物。

## 九、仍需试玩或更多证据确认的问题

1. 普通人口是否具有个人身份，还是只有重点家族成员被实例化。
2. 婚姻后的居住、财产、姓氏、子女归属和离婚/丧偶规则。
3. 生育、成长、教育、疾病和死亡的时间尺度。
4. 官职是否对应真实空缺、辖区、俸禄、职责和政治派系。
5. 产业是否消耗真实劳动力、原料、运输和市场需求。
6. 世家 AI 是否与玩家遵循相同资源、婚姻、仕途和战争规则。
7. 玩家死亡后接管、分家、绝嗣和旁支继承的具体流程。
8. 家史是否完全由世界事实生成，或包含脚本化补写。

这些未知项不得在本项目文档中写成参考作品的确定事实。
