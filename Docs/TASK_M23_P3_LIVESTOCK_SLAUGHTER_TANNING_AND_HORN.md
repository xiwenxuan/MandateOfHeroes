# M23-P3 畜牧、屠宰、制革与角料副产物闭环任务书

## 1. 阶段目标

在 M23-P2 已完成的资源采集—初级加工—军械制造—采购—运输—入库—维修链上，
补齐第一条可审计的畜牧材料链：

```text
既有草料资源与开局种羊
→ 组织牧场执行耗时繁育
→ 屠宰场将活羊守恒拆分为肉、皮、角、骨与下水
→ 鞣坊把生皮和鞣料加工为皮革及废料
→ 角作坊把生角加工为角料及边角料
→ 既有木盾、角弓制造继续消耗真实皮革和角料批次
```

普通牲畜采用数据驱动产品批次保存，不建立封闭的 `LivestockKind` 枚举；牲畜种类、
地方品种和后续 MOD 牲畜以稳定 ID 扩展。批次表示同所有者、同地点、同来源和同质量的
普通牲畜群，不删除、合并或重新随机任何永久人物。

## 2. 必须完成

1. 核心生产内容包升级到 7.0.0，加入草料、活羊、鲜肉、生皮、生角、骨、下水、
   鞣料、鞣制废料和角边料十种产品。
2. 加入牧场繁育、羊只屠宰、植物鞣革和角料整理四种质量守恒配方与对应生产方法；
   配方、产品和方法必须同时存在于内建定义与核心 JSON。
3. 中山原型增加草场草料与鞣料树皮资源体、采集设施，以及牧场、屠宰场、鞣坊、
   角作坊；设施、仓库、管理者和组织均引用真实世界事实。
4. 开局种羊通过带来源的组织库存期初事务进入静态仓；观察界面不得生成羊群或资源。
5. 复用通用组织加工订单完成批次预留、耗时结算、质量传递和库存流水；屠宰产物总重量
   必须等于活羊输入，制革与角料加工也必须守恒。
6. 新产皮革与角料能够继续进入既有木盾和角弓制造配方；下游消耗不能抹除上游订单、
   资源与库存事务来源。
7. 存档顺序升级到 V17；V16→V17 只刷新生产内容清单，不倒推羊群、资源体或历史生产。
8. 更新系统总纲、生产设计、世界模拟、确定性存档、战争设计、README 与 Skill 路由，
   使当前实现状态、限制和下一顺序一致。

## 3. 不在本阶段

- 马、牛、羊逐只永久身份，以及年龄、性别、血统、繁殖季、疾病和伤残；
- 多年牧草生长、草场退化、轮牧、灾害和兽医；
- 活体牲畜运输、市场价格、盗抢和押运战斗；
- 羊毛、乳制品、胶、肥料和更长副产品链；
- 品质多维度、工匠成长、科研改良、自动排产和军需委任。

## 4. 验收用例

- 内建内容与核心 JSON 均为 29 种产品、15 种配方、13 种方法，解析结果及哈希一致。
- 原型世界具有两处新增资源体、六处新增采集/加工设施和 30 只可追溯开局种羊。
- 采集草料后繁育一批羊，输入 1 只羊和 10 单位草料，输出 2 只羊；到期前无产出。
- 屠宰 2 只羊得到 10 肉、4 生皮、2 生角、2 骨和 2 下水，输入输出总重量一致。
- 采集鞣料后，4 生皮与 2 鞣料形成 4 皮革和 2 废料；2 生角形成 1 角料和 1 边角料。
- 新产皮革可制造木盾，新产角料可制造角弓，且全链库存事务严格平衡。
- 非法设施、管理者或原料不足的命令被拒绝且世界快照不变。
- V16 快照迁移到 V17 后不伪造资源体、羊群或订单；同种子与同命令序列快照相同。
