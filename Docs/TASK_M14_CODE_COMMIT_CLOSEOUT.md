## 五、验收标准

1. 默认样本仍为 300 名永久人物，输入边界仍为 200—500 人。
2. 村庄不存在抽象人口批次；人物不会因死亡、关注变化或月度结算被删除、合并或重随机。
3. 人物家户 ID 与家户成员表保持双向一致，家庭和公共粮仓资源无负数。
4. 同一种子产生相同初始事实，关注报告不修改世界状态。
5. V6 快照往返和 V5→V6 迁移通过测试。
6. 编译、核心回归、Unity 测试和差异检查分别有明确结果。
7. 暂存区只包含本任务声明的文件，其他工作区修改保持未暂存。
8. 提交和远程推送成功，可从远程分支独立复核。

- 外部工具硬超时 300 秒；Unity 只通过 `Tools/Run-UnityTestsSafe.ps1` 受控运行。
