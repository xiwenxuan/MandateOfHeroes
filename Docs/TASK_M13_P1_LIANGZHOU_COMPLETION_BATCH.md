## 三、来源与校录判断

原始行政和户口事实采用公共领域古籍《后汉书》卷三十三·郡国五。维基文库
《四库全书》网页转录与公开校勘转录互相核对，现代人口校录网页只用于缺项、
疑值及补正交叉检查，不复制其完整表格、公式或现代注释。

北地郡的四库网页转录缺“三”字，公开校勘转录作3,122户；武威郡的四库网页
转录作10,043户，公开校勘转录及公开影印整理作10,042户。本批分别采用
3,122户和10,042户，并在行政备注中保留异文。

酒泉郡原文只载12,706户而缺口数。现代校录说明称按邻近武威、张掖和张掖属国
平均户口比3.67估算，但同一说明列出的29,170与该方法不符；3.67倍和其公布的
全国修正总计共同支持46,631口，因此修正字段采用46,631，原始口数仍为空。

敦煌郡原文为748户、29,170口，户均人口明显异常。现代校录说明同时出现
7,948与“7,748脱首位”两种表达，而其公布的全国修正总计支持7,748户。本批
保存748原值，并把7,748只写入显式修正字段。
