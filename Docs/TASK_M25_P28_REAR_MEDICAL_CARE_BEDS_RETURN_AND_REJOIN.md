# M25-P28 后方诊疗点、住院床位、返程与归队任务书

## 一、阶段目标

承接 M25-P27 的具体伤员后送与医者交接，把后方治疗和人员回归闭合为同一世界事实：

```text
已由指定医者接收的伤员
→ 进入具有真实床位与药库的既有后方诊疗点
→ 占用床位并由具体医者投入工时
→ 消耗真实草药批次、恢复具体人物健康
→ 出院后与原救护队沿真实路线返程
→ 与来源军队会合
→ 伤员和救护队恢复在役，军队兵力缓存同步
```

本阶段登记既有诊疗设施，不用“登记”替代建设、财政或施工；新建设施仍必须进入后续建设系统。

## 二、本阶段完成范围

1. 使用稳定命名空间 ID 表示后方诊疗点种类、诊疗方案和出院策略；住院、治疗和返程生命周期使用封闭枚举。
2. 诊疗点必须依附带 `Clinic` 能力的具体地点，保存所有组织、正式药库、床位容量、登记日和运行状态。
3. 场景或内容初始化可以登记已经存在的诊疗点并用正式开局库存事务建立药材；运行期不得借此免费建设新设施。
4. 已接收后送记录可以建立唯一住院记录；床位按仍住院或等待返程的具体伤员逐床占用，超容量原子拒绝。
5. 后方治疗必须由住院记录指定的具体医者完成，消耗诊疗点药库中一单位未预留草药，并与民间、随军医疗共享每日480分钟工时上限。
6. 治疗保存健康开闭值、医术开闭值、工时、药材批次和唯一库存事务；治疗只使伤员达到返程标准，不在异地直接改成军队可战兵力。
7. 伤员达到返程标准后，使用明确路线为伤员和原救护队建立返程旅行；出发时释放床位，途中仍保持后送军役状态。
8. 返程期间来源军队不得再次行军；全员到达军队位置后，伤员与救护队恢复 `Active`，军队兵力缓存同步，后送和住院记录结案。
9. 完成后送的人物解除普通旅行锁；未完成后送仍只能通过医疗流程移动。
10. 存档升级到 V50；V49→V50 建立空诊疗点、住院和后方治疗集合，并补齐旧后送记录的空返程字段，不伪造历史治疗或归队。

## 三、领域约束

- 一个后送记录至多对应一个住院记录和一次本阶段后方治疗；治疗、库存事务与草药批次必须一一交叉审计。
- 一个仍活动的住院记录恰占一张床；出院返程后立即释放，结案记录永久保留但不再占床。
- 治疗不能降低健康或制造药材；药库无药、医者超时、人物不在场、床位不足或引用不一致时不得产生部分写入。
- 返程路线必须连接诊疗点和来源军队当前地点；返程开始后军队位置冻结到会合完成。
- 玩家关注、冷热分层、地图视角和表现层不得改变占床、耗药、工时、旅行时间或归队结果。

## 四、明确不做

- 不建设新医院，不结算建材、施工、工资、财政拨款或长期维护。
- 不实现多次治疗疗程、手术、感染、残疾、死亡、护理班次或按伤势差异化住院日。
- 不实现多段返程、动态追赶移动军队、再次转院、车辆/舟船或自动目的地 AI。
- 不实现诊疗点自动补药、收费、赔偿、军功、玩家医疗界面或批量命令。
- 不提交、不推送；版本操作仍需用户另行授权。

## 五、验收用例

1. 已接收伤员进入一张真实床位，治疗消耗具体药材批次、占用医者工时并恢复健康，但治疗完成时仍不隔空增加军队兵力。
2. 治疗后伤员与原救护队沿原路返程；全员会合后军役均恢复 `Active`，军队兵力恢复且后送/住院结案。
3. 返程期间来源军队行军原子拒绝；结案后人物普通旅行恢复可用。
4. 床位满、药材不足、错误医者、错误路线或重复治疗时保持原子失败。
5. 篡改床位、住院—后送引用、药材事务、返程旅行或归队状态时世界校验失败。
6. V49→V50 不制造诊疗点、住院、治疗或归队历史；V50 往返保存完整闭环。
7. 全工程编译、聚焦回归、全量核心回归、受控 Unity EditMode、`git diff --check` 和范围审阅分别完成。
