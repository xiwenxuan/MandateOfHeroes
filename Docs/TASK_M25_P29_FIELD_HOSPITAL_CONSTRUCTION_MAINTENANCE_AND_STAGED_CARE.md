# M25-P29 野战医院正式建设、维护与分阶段诊疗任务书

## 一、阶段目标

承接 M25-P28 的既有医馆住院—返程闭环，建立第一条不依赖地点永久 `Clinic` 标记的
正式军用设施建设与运行合同：

```text
军队级权限批准
→ 指定组织、地点、负责人和正式材料仓
→ 一次性支付组织资金并消耗真实木料/皮革批次
→ 具体人物按世界日投入建设劳动
→ 完工生成独立野战医院、药库、床位和维护周期
→ 定期消耗组织资金与木料维持运行
→ 失修停运，补足维护后恢复
→ 重伤员依次完成稳定伤势与恢复返程两个治疗阶段
```

野战医院是地点内的独立动态设施，不把整座地点永久改写为拥有普通医馆；同一地点后续可有
其他组织设施。开放内容使用稳定命名空间 ID，生命周期状态使用封闭枚举。

## 二、正式建设合同

1. 首个内置建设方案保存稳定方案 ID，并把木料、皮革、资金、劳动日和床位冻结到项目记录；
   后续增加普通方案或 MOD 方案不得复用旧 ID，也不应要求改变存档结构。
2. 开工必须由来源军队拥有军队级权限的人批准；项目所有组织与军队一致，项目地点与军队、
   负责人、正式组织材料仓同地。
3. 首个方案开工消耗 20 单位木料、5 单位皮革和 500 钱组织财政。材料必须来自未预留的
   真实组织批次，并由唯一库存事务闭合；材料或资金不足时不得部分写入。
4. 项目需要 3 个具体劳动日。负责人或同军有效在役人物可每日贡献一次；劳动者必须存活、
   同地、未旅行，军队不得正在行军。劳动记录永久保存人物、日期和项目引用。
5. 完工生成 4 张床位、独立军药库和稳定维护策略的野战医院；完工不自动生成药品，不修改
   地点 `Clinic` 特征，也不伪造普通地方医馆。

## 三、运行维护合同

1. 首个维护策略每 10 日到期一次；每次消耗 100 钱组织财政和 1 单位木料。
2. 维护必须由存活、同地且属于所有组织或来源军队的具体人物执行；库存事务、材料批次、
   组织财政开闭值和下一到期日必须可审计。
3. 世界日越过维护到期日后，调度器把野战医院标记为停运；停运医院不能接收新住院，
   但不得删除既有设施、药库、住院或治疗历史。
4. 补足维护后设施恢复运行，下一维护日从实际补修日重新计算；资金或材料不足原子拒绝。

## 四、分阶段诊疗合同

1. 既有医馆保持 M25-P28 的单阶段草药恢复合同和旧存档语义。
2. 新野战医院住院冻结为两个阶段：
   - 第 1 阶段“稳定伤势”：60 分钟、1 单位草药，健康至少恢复到 5,000；
   - 第 2 阶段“恢复返程”：120 分钟、1 单位草药，健康至少恢复到 6,000。
3. 每阶段都有独立稳定治疗 ID、方案 ID、药材批次、库存事务、医者工时、健康和医术开闭值；
   全部阶段完成前，伤员保持 `Wounded`，住院和后送保持治疗中。
4. 第二阶段完成后才进入 P28 的返程资格；出院、返程、军队等待和最终归队继续复用 P28 合同。
5. 医者工时继续与民间、随军和既有后方诊疗共享每日 480 分钟上限。

## 五、存档与迁移

- 世界存档升级为 V51。
- V50→V51 建立空野战医院建设、劳动和维护集合。
- 既有诊疗点补空建设/维护字段；既有住院若已有 P28 治疗，则迁移为 1/1 单阶段并保存原治疗 ID；
  未治疗住院迁移为 0/1。既有治疗迁移为第 1/1 阶段。
- 旧库存事务补空野战医院建设/维护来源字段。
- 迁移不得依据地点、药库、健康、后送或军役状态倒推野战医院、材料消耗、劳动或维护历史。

## 六、明确不做

- 不实现永久砖石医院、征地争议、施工事故、工资分配、营帐拆迁和设施迁移。
- 不实现手术、感染、残疾、死亡、护理班次、不同伤型动态疗程或患者转院。
- 不实现建设委任 AI、自动材料采购、自动维护采购、多段返程或追赶移动军队。
- 不把本阶段首个建设/维护数值写成最终平衡上限。
- 不提交、不推送。

## 七、验收标准

1. 开工真实扣减组织财政、木料和皮革，库存事务逐批闭合；失败不产生部分写入。
2. 三条不同日期的具体劳动记录完成项目，生成独立野战医院、药库和床位，地点不获得普通
   `Clinic` 特征。
3. 维护逾期由世界日程停运；补修真实消耗财政和木料并恢复运行。
4. 野战医院伤员必须完成两次真实治疗才取得返程资格；既有医馆仍一次完成。
5. 篡改项目—材料事务、劳动者、设施—项目、维护账、治疗阶段或库存来源时世界校验失败。
6. V50→V51 不制造野战医院事实；V51 往返保存完整建设—维护—治疗状态。
7. 全工程编译、聚焦核心、全量核心、受控 Unity EditMode、`git diff --check` 和范围审阅通过。
