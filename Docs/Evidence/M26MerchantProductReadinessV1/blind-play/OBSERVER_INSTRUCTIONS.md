# 旁观记录者说明

## 试玩者资格

试玩者必须没有阅读本任务书或实现代码、没有参与开发、事先不知道正确操作流程。若不满足，停止并更换试玩者。

## 允许做的事

- 启动正式 Unity / Demo 和普通玩家 Scene。
- 记录玩家说什么、点什么、看到什么、何时迷失以及如何恢复。
- 每 1—2 分钟填写时间线。
- 记录设备故障、安全问题和外部技术故障。

## 禁止做的事

- 不告诉玩家下一步点哪里。
- 不解释价格、容量、路线、盈亏或目标。
- 不纠正非标准但系统允许的玩法。
- 不改写玩家原话为开发术语。
- 不删除首次失败证据。

结束后填写 `run-info.json`、`timeline.csv`、`defects.csv` 与 `evidence-index.md`，并按 S0—S3 分类。
