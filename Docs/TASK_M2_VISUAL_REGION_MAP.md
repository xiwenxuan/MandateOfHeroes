# M2任务书：涿县—广宗可视化地区地图

## 任务目标

把M1的文字地点列表升级为可视化地区地图，让玩家能够直观看到涿县、中山、安平、下曲阳、广宗和邺县之间的空间关系、道路、军队与自身位置，并直接在地图上选择目的地。

本任务优先验证地图交互和世界状态联动，使用原创程序绘制的占位视觉，不等待最终历史地图和美术资产。

## 本次范围

### 地图数据

- 为六个原型地点增加归一化地图坐标；
- 坐标进入世界状态和存档验证；
- 地点坐标不依赖屏幕分辨率；
- 保留现有道路、距离和治安数据作为连线依据。

### 地图表现

- 原创程序绘制的地区底图；
- 河流、道路和六个地点节点；
- 玩家、旅途中的玩家和军队标记；
- 当前地点、选中地点和可旅行地点使用不同视觉状态；
- 地图图例与缩放提示。

### 地图交互

- 鼠标滚轮缩放；
- 鼠标拖动平移；
- 一键重置视角；
- 点击地点查看人口、治安、粮价和驻军；
- 点击相邻地点后直接出发；
- 旅行中的玩家标记沿道路显示进度。

### 信息图层

- 地形图层；
- 治安图层；
- 粮价图层；
- 战争图层。

图层只改变地图信息表达，不修改世界模拟数据。

## 非本次范围

- 全国地图；
- 精确历史经纬度；
- 三国志系列地图或素材复制；
- 最终地形美术；
- 城市内部场景；
- 山寨、村庄和庄园的完整数据层；
- 战争迷雾；
- 战场地图。

## 验收标准

1. 地图页面不再以纯文字列表作为主要表现；
2. 六个地点和六条道路均可视化；
3. 地点位置在不同窗口尺寸下保持相对关系；
4. 可以拖动、缩放和重置地图；
5. 点击地点显示详细信息；
6. 只有相邻地点提供出发操作；
7. 玩家旅行时标记沿道路显示进度；
8. 官军和黄巾军在所在地显示标记；
9. 四种信息图层可以切换；
10. 地图坐标保存读取后保持不变；
11. 原有核心测试继续通过；
12. 功能分支推送GitHub并建立草稿Pull Request。

## 完成定义

- 地图逻辑、界面、测试和说明全部进入同一功能提交；
- Unity相关程序集编译通过；
- 核心测试无回归；
- 不提交Unity缓存和临时生成文件。

### 视觉定位

本版本属于可交互程序地图，不是最终三国历史地图。它使用原创色块、节点和线条验证地图自由度、信息图层及世界状态联动，后续可以在不改变旅行和战争逻辑的前提下替换为正式地形、美术图标和更大地图。
