# M24-P0任务书：100万永久人物世界与50年自然人口演化

## 一、阶段目标

在进入累计5000万完整游戏负载前，先建立一个开局恰好100万名在世永久人物的人口世界，
让人物在没有玩家干预的情况下连续运行50年，验证家庭形成、生育、死亡、血缘、人口空间
分布、事件调度、永久档案增长和恢复证据。

本阶段回答的是：

> 百万人口能否作为具体人物与家庭存在，并在不扫描完整NPC AI的前提下自然繁衍50年？

它不是“100万份完整游戏AI”验收。生产、消费、战争、疾病传播、迁徙、教育、技能、政治和
历史事件尚未全部进入本负载，因此结果只能称为“人口世界层长跑原型”。

## 二、输入与来源等级

1. 140年105项郡国人口和1182项县级目录来自M13，属于历史事实与既有校录数据；
2. 郡国人口按玩家缩尺归一为100万开局人口；
3. 史料没有提供1182县逐县人口、逐户年龄结构和逐年婚育死亡率，本阶段使用稳定ID、明确
   版本的数据驱动技术参数进行确定性补全，来源等级必须标记为`gameplay_completion`；
4. 玩法补全参数不得写成东汉史实，也不得覆盖原始历史人口文件；
5. 同一输入文件、参数档、种子与工具版本必须产生相同的人口摘要和年度结果。

## 三、永久事实合同

每个人至少保存：

```text
person_id
gender
birth_day
death_day
county_id
household_id
spouse_person_id
father_person_id
mother_person_id
last_childbirth_day
children_count
alive
```

每个开局人物立即获得唯一ID。新生儿在出生事件发生时立即追加永久核心并取得新ID；死亡
只退出在世调度，不能删除、合并或重随机人物。婚姻、出生和死亡均保存可追溯事件记录。

## 四、自然演化规则

1. 使用数据驱动年龄结构、生育年龄段、生育概率、最短生育间隔、婚配年龄和年龄死亡率；
2. 开局家庭按县级人口和东汉户均人口参考确定性建立，人物属于具体县和家户；
3. 同县符合条件的未婚或丧偶人物按稳定人物ID顺序形成婚配，不跨县凭空配对；
4. 只有在世、同县、配偶在世且满足年龄与生育间隔的女性能够产生出生事件；
5. 新生儿保存具体父母和家户，性别、出生日和后续死亡日使用稳定动作坐标确定；
6. 死亡按年龄分段风险生成持久到期事件；配偶死亡后只改变存活者的婚配状态，不抹去
   死者历史关系；
7. 长跑按事件日与稳定事件键处理到期对象，不逐日运行100万份完整AI；
8. 本阶段不使用土地、粮食和疾病承载力，因此人口曲线只代表基准人口学参数，不代表完整
   三国世界的最终人口结果。

## 五、实现与证据

新增独立工具和安全入口：

- `Data/PopulationSimulation/demography_profile.han140_baseline_test.v1.json`；
- `Tools/PopulationBenchmark/PopulationFiftyYearWorld.cs`；

原始人口包、事件账、进度和机器可读结果只写入被忽略的`tmp/m24-p0`。安全入口必须：

- 编译和候选运行使用独立子进程；
- 每个外部进程总时限不超过300秒，候选预算不超过285秒；
- 每隔不超过5秒轮询并保留PID、日志、结果与最后进度；
- 超时只终止本任务启动的进程树；
- 先写暂存工作区，完整校验后才写完成清单。

## 六、验收条件

1. M13审计在启动时确认105项人口来源、1182县目录和通过状态；
2. 开局在世人物严格等于1,000,000，每人拥有永久唯一ID、县、家户和年龄性别事实；
3. 连续推进50年并保存逐年开局人口、出生、死亡、婚配、年末人口与累计人物；
4. 每年满足`年末在世＝年初在世＋出生－死亡`；
5. 最终满足`累计人物＝开局人物＋累计出生`、`在世＝累计人物－累计死亡`；
6. 每个新生儿父母存在、出生早于子女且出生时在世；所有引用和县级人口汇总有效；
7. 永久核心、事件账和年度汇总分别具有确定性摘要；小规模重复运行摘要完全一致；
8. 运行只处理到期人口事件和当年婚育候选，不创建Unity对象或运行完整NPC AI；
9. 100万长跑形成机器可读结果、峰值内存、磁盘体积、耗时和安全包装证据；
10. 全工程编译、核心测试、受控Unity测试、`git diff --check`和范围审阅分别报告。

## 七、不包含

- 100万人生产、市场、消费、战争、迁徙、教育、技能和逐人完整AI同时运行；
- 用本技术参数宣称东汉真实人口曲线；
- 把独立人口包直接替换当前V28主世界快照；
- 直接外推1000万或累计5000万完整游戏负载；
- 创建世界人口档位UI、硬件自动检测、提交或推送仓库。
