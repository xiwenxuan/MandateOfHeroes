# M24-P6多产品食物来源报告

## 一、结论

百万压力世界已经不再需要把所有食品解释为同一种产品。麦粒与干粮分别保存开局来源、
消费、腐败、冲突损失、内部流转和期末库存，并逐年独立守恒；兼容标量、正式桥接源粮和
产品来源账三者完全一致。

## 五、边界

- 开局80%麦粒、20%干粮是技术场景，不是史实结论；
- 不同食品目前按同一“毫口粮”营养折算，尚未引入热量、体积、腐败率和价格差异；
- 市场和赈济保存产品数量来源，但没有输出逐户逐笔成交明细；
- 产品向量仍属于独立百万压力工具，不是V28正式分区库存实现。
