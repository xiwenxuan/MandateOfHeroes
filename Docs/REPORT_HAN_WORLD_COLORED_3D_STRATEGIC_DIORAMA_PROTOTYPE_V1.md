# 天下彩色立体战略沙盘视觉原型 V1 实施报告

## 1. 当前结论

已建立正式任务边界并完成代码实现。`M 天下` 的普通玩家入口已改为原创汉末彩色立体
战略沙盘；水墨原型仅保留为开发对照和兼容入口，不再出现在普通玩家切换按钮中。

## 2. 实现摘要

- 新增 `HanStrategicDiorama` 风格、稳定 Profile ID、彩色分层光照参数和四档冻结镜头。
- 地形 Shader 新增沙盘分段光照、暖光冷影和地貌边缘强化，保留完整彩色地貌。
- 天下远/中景隐藏格线，近战略尺度显示 24×24 个正式 2 km Cell 精确格。
- 依据正式地点数据生成城墙、城楼和屋顶微缩城邑，并合并为一个 Mesh/Renderer。
- 普通 UI 改为“战略沙盘 / 自然地形”，水墨按钮退出玩家入口。
- 三视角、县域 50m 布局、人物位置和 World Schema V79 均未改变。

环境没有提供有效 GPU 时间，帧毫秒仅作运行记录，不作为玩家设备性能结论。

## 4. 图形目检

- 远景地图已摆正并保持 58°斜俯视，山系、平原、河网和道路的颜色层级清楚。
- 中近景行政边界已按相机尺度收窄，不再用固定世界宽度压住地形。
- 远/中景不再显示全国棋盘格；约 180 的近战略尺度才显示 24×24 精确 2 km 格。
- 城邑从二维“邑”方块切换为程序化城墙、城楼和屋顶合批模型；远景仍作为地图符号放大，
  不是其真实地理占地。
- 当前仍是技术美术原型，地形高程采样的多边形层次较明显；是否达到最终审美标准需用户
  在实际 Game View 中确认。

## 5. 限制

- 本轮城邑是原创程序化战略标志，不是全国各城最终独立历史建筑资产。
- 军队、关隘、港口、农田季节色和天气层仍属于后续视觉生产任务。
- 最终美术接受必须由用户检查 Unity 实际画面后确认。
