# 《群雄志：仕途》人物多属性、词条与家族培养设计

## 1. 文档定位

本文统一记录人物能力、专业成长、词条、社会评价和家族培养的长期设计。

主要参考方向：

- 《三国志》系列的统率、武勇、智略、政务和魅力，用于战略层快速阅读；
- 《鬼谷八荒》的多资质、特殊词条、成长路线和人物差异；
- 《九州》系列的职业能力、商业经营和地方专长；
- 《吾今有世家》的家族教育、家学、婚姻、产业和代际培养。

项目只借鉴玩法思想，不复制上述作品的词条名称、属性表、数值、文本、界面或素材。

本文描述目标架构，不表示全部已经完成。当前 M8 已完成 P1：八项基础禀赋、十类专业总能力、人生志向、五维派生、身份与历史人物倾向、新生儿初始化和人物面板；M9 已完成 P2：月度学习计划、教师、时间、个人或家庭费用、软潜力、递减成长、设施与实践岗位，并支持 V3 至 V4 存档迁移。词条、家学与社会认知仍需按 P3 至 P6 分阶段实现。

## 2. 核心原则

人物系统采用：

```text
基础禀赋
→ 决定身体条件与学习特点

专业资质
→ 决定各领域学习效率和软上限

知识＋技能＋经验
→ 决定实际职业能力

性格＋价值观＋志向
→ 决定人物如何选择

身份＋声望＋资源＋职位
→ 决定人物可以影响多大范围

家族教育＋师承＋设施
→ 决定能力如何跨代积累

五维综合评价
→ 为战略层提供简洁摘要
```

人物属性不能直接凭空增加城市产量。

人物必须通过劳动、职位、设施、组织、政策、军队、教学和社会关系影响世界。

## 3. 属性系统层级

人物状态分为七层：

1. 基础禀赋；
2. 通用能力；
3. 专业资质与技能；
4. 知识和实践经验；
5. 性格、价值观和人生志向；
6. 健康、伤病和即时状态；
7. 身份、声望、关系、财富和控制资源。

词条横跨这些层级，负责表达特殊规则、经历和传承。

## 4. 八项基础禀赋

基础禀赋变化较慢，主要影响学习、身体与能力发挥。

| 属性 | 主要作用 |
| --- | --- |
| 体质 | 健康、寿命、恢复、疾病抵抗和持续劳作 |
| 力量 | 负重、近战、重体力劳动和重型工具 |
| 灵巧 | 骑射、操作、手工艺、反应和精细动作 |
| 感知 | 侦察、诊断、识人、发现异常和观察环境 |
| 记忆 | 学习、语言、经书、知识保持和配方记忆 |
| 思辨 | 推理、研究、策划、技术理解和复杂判断 |
| 意志 | 压力、恐惧、长期坚持、自律和痛苦承受 |
| 亲和 | 沟通、共情、教学、建立信任和理解他人 |

基础禀赋只代表潜在条件。

思辨高不等于会医术，灵巧高不等于会锻造，力量高不等于掌握枪术。

## 5. 三国志式五维综合评价

保留五维作为人物概览和战略层摘要：

- 统率；
- 武勇；
- 智略；
- 政务；
- 魅力。

五维由底层能力和当前状态派生，不作为唯一成长来源。

### 统率

```text
统率
= 组织能力
+ 军事知识
+ 指挥技能
+ 军事经验
+ 意志
+ 军中威望
+ 部下信任
```

### 武勇

```text
武勇
= 力量
+ 灵巧
+ 体质
+ 武器技能
+ 实战经验
× 当前健康和伤势修正
```

### 智略

```text
智略
= 思辨
+ 感知
+ 军事与情报知识
+ 谋划经验
+ 对当地和敌人的信息掌握
```

### 政务

```text
政务
= 行政技能
+ 法律、户籍和财税知识
+ 组织能力
+ 治理经验
+ 地方信息
```

### 魅力

```text
魅力
= 亲和
+ 表达
+ 礼仪
+ 分类声望
+ 身份地位
+ 对方对人物的主观认知
```

两个政务同为80的人，可以分别擅长水利和财政，实际作用不同。

## 8. 知识、技能和经验分开

人物可能知道理论，但缺少实践。

例如造船能力由以下内容组成：

```text
造船理论
+ 木工技能
+ 工程设计
+ 船型知识
+ 实际造船经验
+ 对当地木材和水域的了解
```

能力分为：

- 理论知识；
- 实践熟练；
- 重大项目经验；
- 技术传承；
- 地方知识。

重大经验不能只靠读书获得：

- 主持大型水利；
- 完成大型船只；
- 经历守城；
- 控制疫病；
- 管理跨州商队；
- 主持人口和土地清查；
- 指挥真实军队作战。


- 经验、知识和判断可能继续提高；
- 声望、学生和社会关系可能增长；
- 年长人物更适合教学和主持家学。

## 15. 人物影响世界的路径

### 直接行动

亲自劳动、战斗、治疗、交涉、制作或调查。

作用最具体，影响范围较小。

### 管理设施

担任农庄管事、主匠、掌柜或医馆负责人。

```text
设施效率
= 设施条件
× 人员和原料
× 团队技能
× 管理者贡献
```

管理者不能替代缺失的劳动力和原料。

### 担任组织职位

通过官府、军队、商会、家族和宗教组织放大影响。

### 培养和传播

通过弟子、学徒、书籍、图纸、制度和家学产生跨代影响。

### 声望与关系网络

改变其他人物是否投靠、贷款、纳税、开门、供粮、参军、合作或起义。

```text
人物有效贡献
= 能力
× 权限
× 信息掌握
× 执行组织
÷ 管理复杂度
```

## 18. 通用行动结果

```text
行动结果
= 资源基础
× 组织容量
× 团队能力
× 人物贡献
× 环境条件
× 随机与对抗
```

人物贡献不能覆盖资源基础。

没有木材时名匠不能造船；没有船工时主匠只能缓慢亲自制作；没有主匠时普通船工只能稳定制造低级船只。

## 22. 培养的机会成本

人物时间必须在以下事项中分配：

```text
工作
学习
家庭
社交
休息
旅行
任务
```

长期习武会减少读书和经营时间，管理产业会减少游学机会。

家族也受限于教师、资金、书籍、岗位和政治机会，不能培养所有后代成为全能人物。

## 23. 技能成长

```text
成长
= 学习时间
× 教师质量
× 设施与资料
× 对应资质
× 当前健康
× 学习动机
× 实践机会
× 递减系数
```

阶段建议：

| 熟练度 | 阶段 | 主要要求 |
| --- | --- | --- |
| 0～30 | 基础 | 普通学习和练习 |
| 30～60 | 熟练 | 持续实践 |
| 60～80 | 专家 | 名师和重大项目 |
| 80～95 | 大师 | 创新、传承和高难经验 |
| 95以上 | 时代顶尖 | 极少数人物达到 |

使用软潜力：

- 潜力前成长正常；
- 超过潜力后成长变慢；
- 名师、特殊经历和突破可以继续提高；
- 潜力高但不学习不会自动成为人才。

## 24. 词条系统定位

多属性描述基础能力和专业水平，词条描述：

- 特殊身体状态；
- 性格表现；
- 学习方式；
- 专业专长；
- 重大经历；
- 社会评价；

- 隐秘关系；
- 规则变化。

词条优先改变规则、选择、成本、风险和AI态度，少用单纯的属性加成。

## 30. 词条成长和转化

词条可以进阶、退化和转化：

```text
初涉商途
→ 熟悉商路
→ 通行数州
→ 商路巨擘
```

```text
识药学徒
→ 行医有验
→ 一方名医
→ 济世名家
```

```text
旧伤
→ 旧伤复发
→ 肢体残疾
```

转化需要事件和行为条件，而不是经验达到数值后自动变色。

## 31. 冲突与互斥

明确互斥示例：

- 重诺与惯于背约；
- 军纪严明与劫掠成性；
- 畏水与水战如常；
- 乡里仁望与本地恶名。

可以共存的复杂组合：

- 仁慈且严守法律；
- 贪财但重诺；
- 恋家但野心很高；
- 畏战但守城不退。

避免把人物简化为正面和负面词条集合。

## 32. 词条影响方式

### 解锁行动

- 长于治水可以提出高级水利方案；
- 熟悉商路可以发现隐蔽路线；
- 军中旧识可以联系特定军官；
- 辨药入微可以识别劣质药材。

### 改变成本

- 减少试错损耗；
- 缩短特定学习时间；
- 降低判断错误风险；
- 降低特定谈判抵押。

### 改变结果分布

- 降低灾难性失败；
- 提高高品质产品概率；
- 提高发现问题概率；
- 改善伤员生存率。

### 改变AI态度

- 士人对累世经学家族更愿意交往；
- 商人对商誉可信者更愿意赊账；
- 百姓对纵兵劫掠者更加恐惧或仇恨；
- 豪族对善于清查田亩的官员更加警惕。

### 改变事件选项

词条可以解锁选项，但仍需真实职位、资金、人员、原料和关系。

## 33. 词条与数值的关系

```text
基础数值
→ 决定常规能力

技能和知识
→ 决定专业水平

词条
→ 改变特殊规则、选项和风险

当前状态
→ 决定实际发挥

身份与资源
→ 决定能否执行及影响范围
```

只有“军中外伤经验”但医术很低的人不能成为神医；医术高但没有药材、助手和场所，也无法处理大规模伤员。

## 34. 词条继承

### 身体倾向

概率继承，并存在自然变化：

- 体质；
- 身高倾向；
- 疾病风险；
- 感官倾向。

### 家学和职业

依靠教育传承，不是生物遗传：

- 教师；
- 书籍和图纸；
- 实践设施；
- 时间投入；
- 后代意愿。

### 家族声望

后代部分继承家族声望和恶名，个人行为可以加强或摆脱评价。

### 政治关系

父辈故旧可能照顾后代，但长期不维护会淡化；家族仇敌也可能继续敌视后代。

## 35. 稳定生成与防止刷取

人物与后代由稳定世界种子决定。

重复读档、退出场景或重新进入家庭不能改变已经存在的潜质和词条。

未知属性表示玩家尚未了解，不表示系统尚未决定。

人物信息逐步揭示：

```text
幼年：发现体质较弱
少年：发现善于记忆
工艺实践后：发现手指灵巧
```

## 36. 词条数量控制

建议单个人物：

```text
核心人格词条：2～4
身体词条：1～3
专业词条：1～5
经历词条：随人生增加
社会词条：动态变化
隐藏词条：少量
临时状态：单独显示
```

普通代表人物词条较少，玩家家族、历史人物和长期角色可以更丰富。

稀有度只帮助阅读：

- 常见；
- 特殊；
- 稀有；
- 传世。

传世词条表示能够建立家学、流派、制度或历史影响，不一定提供最高战斗加成。

## 39. 平衡原则

### 不允许全能人物

- 时间有限；
- 学习有递减收益；
- 高级技能需要重大实践；
- 资源和教师有限；
- 职业之间存在机会成本；
- 年龄、健康和责任限制成长。

### 词条不能替代经济

词条不能创造不存在的粮食、药材、兵员、船只或税收。

### 一个人不能直接加成百万居民

人物必须通过组织、下属、设施和制度传播影响。

### 优势伴随责任

- 官位带来权限，也带来考核和政治风险；
- 豪族资产带来收入，也带来维护和敌视；
- 名声带来追随，也带来期待；
- 家学带来机会，也需要持续传承。

## 42. 自动测试与守恒要求

未来实现必须测试：

1. 相同世界种子产生稳定初始禀赋；
2. 重复进入场景不会重随机人物；
3. 培养消耗真实时间和财富；
4. 技能成长遵守资质与递减收益；
5. 词条获得满足前置条件；
6. 冲突词条不能同时存在；
7. 词条进阶保留来源记录；
8. 家学中断会逐步退化；
9. 隐藏词条不会被无情报人物读取；
10. 五维摘要能由底层数据稳定重算；
11. 人物死亡后不能继续担任教师、管理者或官员；
12. 词条和属性不能绕过世界人口、库存、财政和职位规则。

## 44. 最终总结

```text
多属性
→ 描述人物基础条件和专业水平

词条
→ 描述特殊经历、专长、性格、传承和规则变化

身份、职位和资源
→ 决定人物能在哪个范围发挥作用

家族教育、师承和设施
→ 让能力跨代积累或失传

真实行动和世界结果
→ 产生新的经验、声望和词条
```

人物培养的目标不是制造一组更高的面板数字，而是让人物通过真实学习、职业、组织和人生经历，获得改变家庭、设施、城市、军队和历史的能力。
