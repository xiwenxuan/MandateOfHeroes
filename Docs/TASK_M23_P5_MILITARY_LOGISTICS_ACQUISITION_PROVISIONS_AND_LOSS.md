# M23-P5 军需取得、承运责任、行旅补给与运输损耗任务书

## 1. 阶段目标

在M19产品批次、M23-P0单路线军械采购、M23-P4多维品质以及既有人物旅行、军队行军、
军事权限和财政底座上，建立第一条不把“取得物资”“运输物资”和“保护物资”混成同一行为的
军粮货运合同：

```text
真实产品批次
→ 有军权人物选择取得方式
→ 明确买方、货源、承运组织和损失承担方
→ 托运军粮与商队自用补给分别装载
→ 商人独立承运或军队随军自运
→ 途中消费自用补给并发生可追溯自然损耗
→ 与目标军队会合并按实到数量入账
```

“守恒”在本任务中表示来源和去向守恒，不表示发出数量必须完整到达。军粮可以被消费、
腐损、征用、抢夺或焚毁，但不得无原因消失，也不得重复进入军队库存。

## 2. 必须完成

1. 使用稳定命名空间ID表示商业采购、内部调拨、补偿征购、无偿征发和劫掠；新增普通
   取得方式不依赖封闭内容枚举。
2. 持久军需货运单分别记录买方组织、货源组织、承运组织、损失承担组织、签发人、
   承运人、目标军队、产品批次、路线、移动方式、价格、数量和状态。
3. 商人承运复用人物`JourneyState`；现役军人自运时附着目标军队的`ArmyMarchState`，
   不创建与军队位置相冲突的第二段个人旅行。
4. 托运军粮与承运队自用补给分账。自用补给存在时先消费自用补给，不扣人物兼容口粮，
   也不擅自食用托运军粮。
5. 发运时快照产品品质、鲜度、重量和易腐参数；运输日按快照确定性结算自然数量损耗，
   不受玩家关注层级影响。
6. 商业采购和补偿征购形成等额双边财政变化；内部调拨不付款；无偿征发与劫掠不伪造
   付款，并对来源地点治安产生可审计负面影响。
7. 所有发运、补给消费、自然损耗和到货均进入独立物流流水；满足：

```text
发运军粮 = 在途军粮 + 到货军粮 + 自然损耗 + 已授权食用
装载补给 = 剩余补给 + 已消费补给
买方付款 = 货源收款
```

8. 存档升级到V19；V18迁移只建立空军需物流集合和新来源字段，不伪造旧货运历史。
9. 自动测试覆盖商人承运、军队随军自运、劫掠后果、无权拒绝、确定性、当前版本往返和
   V18顺序迁移。

## 3. 不在本阶段

- 多段路线、中转仓换装、分批交付和自动寻路；
- 押运战斗、盗匪、天气、税卡、保险、信用与运费竞价；
- 包装、污染、霉变品转饲料、品质逐维衰减与运输损坏；
- 直接从每个家庭粮仓征粮、民夫征发和逐辆车马船只身份；
- 纵兵劫掠中的人物伤亡、纵火、抵抗、犯罪调查和战斗展开；
- 太守、都督、主将的递归军需委任和正式玩家界面；
- 移除旧`commodity.grain`与`ArmyState.Provisions`兼容桥。

## 4. 验收用例

1. 商人装载100单位干粮和独立商队口粮后沿中山—安平路线运输；途中自用口粮减少，
   人物兼容口粮不重复扣除，军粮按产品易腐快照产生确定性损耗。
2. 商人和军队会合后只按剩余军粮增加军队口粮，发运、损耗和到货之和严格一致。
3. 现役军人使用本军运输容器时附着军队行军；其人物位置、军队位置和货运位置一致。
4. 商业采购扣买方财政并等额增加货源财政；内部调拨不付款。
5. 劫掠从真实组织产品批次扣货，不增加货源资金，并降低来源地点治安。
6. 无军权签发人被拒绝，且不新增旅行、物流单、流水、付款或库存变化。
7. 相同世界和指令产生相同快照；V19往返后物流审计继续平衡。
8. V18迁移后新集合为空，不制造历史货运、损耗或劫掠记录。
