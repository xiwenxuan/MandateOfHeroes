# M13-P1任务书：140年首批郡国人口校录

## 一、任务定位

本任务执行
[`TASK_M13_HAN_140_POPULATION_AND_STABLE_GEOGRAPHY.md`](TASK_M13_HAN_140_POPULATION_AND_STABLE_GEOGRAPHY.md)
的P1首批校录，以当前6个运行时地点相关区域作为最小端到端样本：

- 幽州：涿郡、广阳郡；
- 冀州：魏郡、钜鹿郡、中山国、安平国。

首批只建立140年行政截面和郡国级户口事实。稳定地理、人口分配权重、县级目录和
游戏地点交叉映射仍属于M13-P2、P3，不因本批次完成而提前升级状态。

## 二、目标与交付

1. 登记汉、幽州刺史部、冀州刺史部及6个目标郡国，共9个行政单位；
2. 录入6条郡国户口原值，并保留原值与修正值的字段边界；
3. 为每条记录提供《后汉书》卷次、郡国条目和公开文本定位；
4. 登记现代校录表为交叉核对线索，并明确未知许可下不再分发表格的边界；
5. 将人口记录模型版本升级为`han140.p1.batch1.v1`；
6. 扩展自动化测试，固定本批次行数、ID、户口合计和审计差额；
7. 重新生成确定性审计报告。

## 三、来源与校录规则

原始事实采用公共领域古籍《后汉书》郡国志：

- 卷三十·郡国二：魏郡、钜鹿郡、中山国、安平国；
- 卷三十三·郡国五：涿郡、广阳郡。

公开文本载体使用维基文库《四库全书》本。现代研究者公开的
`eastern_han_population.ods`只用于逐项交叉核对，不作为独立原典，也不复制其完整
表格、公式、注释或版式。

本批6条记录未采用显式修正值。若后续校勘发现异文，必须保留当前原值，并在修正字段
中新增修正码、理由和来源；不得原地覆盖。

1. 行政单位为9条，人口记录为6条，来源登记为3条；
2. 首批原始户数合计574,447，原始口数合计3,525,369；
3. 与全国锚点的差额分别为-9,124,183户、-45,624,851口；
4. 6条记录均为H级史籍证据，且能定位到具体卷次和郡国条目；
5. 6条记录均使用`han140.p1.batch1.v1`；
6. 显式修正记录为0，审计报告不得把空修正字段当作0值修正；
7. 负人口、非法年份、缺失来源、重复来源和非法模型版本继续被拒绝；
8. 相同输入产生相同审计结果，检入审计与重新生成结果一致；
9. 适用项目验证与`git diff --check`通过。
