# M26-P5A 中山商号—城镇建筑经营入口纵向切片任务书

> 为这些设施增加持久街区、坐标和占地，并以空间近览替代本任务的卡片式主导航。本文继续记录

## 一、目标

把已有中山商行、人物、组织、市场、商品批次、库存与商旅行动，接入玩家能够理解的城镇空间：
玩家抵达中山后能够进入城镇，看见具体建筑，进入商号主堂、仓库、市场等场所，并从场所进入
已有经营准备与人物行动。该切片是 M26-P5 商号成熟玩法的第一个实现任务，不代表完整商号系统
已经完成。

参考《九州：商旅》的仅是“城镇—建筑—组织—经营行动”层次问题；代码、文案、数据、布局与
数值全部原创。《中华三国志》的参考仍限于共享战略地图、组织和委任边界，不导入其资产或
未隔离源码。

## 二、玩家验收路线

```text
选择张世平或另一名位于中山的人物
→ 地图选择当前地点中山
→ 点击“进入城镇”
→ 看见中山集市、商行主堂、商行仓库、客舍、车马场、行会馆和官署
→ 进入主堂查看真实商号资金、声望、成员与负责人
→ 进入仓库查看真实容器容量和具体产品批次
→ 从主堂、市场、仓库或车马场打开经营准备与人物行动
→ 后续采购、装货、启程继续写回既有正式市场、批次、库存流水和行程
```

## 三、世界合同

1. `TownFacilityState` 是可保存的城镇建筑事实，使用稳定设施种类 ID 与访问策略 ID；普通设施
   类型扩展不要求再升级存档结构。
2. `MerchantBranchState` 是商号在具体地点的据点事实，必须引用真实商号组织、永久负责人、
   真实地点、正式库存容器和具体设施。
3. 建筑是否可见、是否运营、所有者、负责人和访问策略不能只存在于 UI。
4. 商号仓库不得自动补货；其中商品只能来自正式开局事实、采购、运输、生产或其他可审计流水。
5. 进入城镇必须校验人物仍然存活且位于该地点；进入受限建筑还必须校验组织成员或负责人权限。
6. 地图缩放、切换面板、退出建筑和关注度变化不能修改世界事实。
7. 旧 V66 存档迁移到 V67 时只初始化空设施/据点集合，不推定或创造历史建筑、组织、人物、
   资金与货物。

## 四、实施范围

### P5A-1 Domain 与存档

- 新增数据驱动的城镇设施种类、访问策略与操作 ID。
- 新增城镇设施与商号据点持久状态。
- 世界存档升至 V67，增加 V66→V67 顺序迁移、唯一 ID 和引用不变量校验。

### P5A-2 中山开局事实

- 在 184 年原型建立中山七个首批建筑。
- 将中山商行主堂、仓库和车马场绑定到现有 `organization.zhongshan_merchants`。
- 建立中山商行总号及其真实仓库容器；负责人使用永久人物张世平。
- 仓库开局为空，不为了演示生成无来源货物。

### P5A-3 Simulation 查询与权限

- 提供城镇检查、设施进入、所有者/负责人投影和可用操作查询。
- 公共建筑允许当地存活人物进入；商号仓库仅允许商号成员进入。
- 未抵达、无权限、建筑停运或未知访问策略时返回明确原因。

### P5A-4 Presentation

- 当前地点详情提供正式“进入城镇”入口。
- 城镇列表显示真实建筑、所有者、负责人和不可进入原因。
- 主堂显示真实组织资金/声望/成员；仓库显示真实批次数量、重量和容量；市场复用现有报价；
  客舍显示本地永久人物候选，但不伪装成已完成招募合同。
- 可从具备经营操作的建筑进入已有玩家行动页。

## 五、明确不包含

- 完整招募、工资、岗位互斥、载具/牲畜、饮水、疲劳和耐久合同。
- 全国城镇建筑数据、分号建设、产业投资、设施升级、NPC 商号竞争和自动经营。
- 把聚合市场库存误写成商号仓库，或在界面中生成无来源商品。
- 复刻任何参考游戏的地图、美术、界面、文本、配方、数值或任务。

这些内容继续由 M26-P5 后续子任务处理，本任务不得以占位按钮宣称完成。

## 六、自动化与人工验收

自动化至少覆盖：

1. 原型世界存在七个中山设施、一个商号总部和一个组织所有的仓库容器。
2. 张世平可以在中山进入主堂、仓库和市场，并取得正确的经营操作。
3. 异地人物不能进入中山建筑；非商号成员即使抵达也不能进入商号仓库。
4. V67 存档往返保留设施、据点、负责人、容器和访问合同。
5. V66 顺序迁移不创造设施与据点。
6. 全工程编译、定向核心测试、受控 Unity EditMode、`git diff --check` 和范围审阅分别有证据。

人工验收：从 `Assets/Scenes/PlayableDemo.unity` 开始，选择张世平，进入中山并依次查看商号
主堂、仓库和市场；确认能返回地图与行动页，且空仓库不会自动出现商品。
