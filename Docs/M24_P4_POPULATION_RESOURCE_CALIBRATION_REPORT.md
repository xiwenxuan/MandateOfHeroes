# M24-P4人口—资源反馈诊断与校准报告

## 一、结论

P3人口坍缩由两层反馈共同造成：开局种粮与家庭劳力/土地分布不匹配，使首年仅耕作34.08%
土地；绝户土地进入公地后不再形成工单，使第50年耕作率降至1.47%。持续缺粮再被18%的
“完全断粮年度死亡上限”放大，形成死亡—公地闲置—减产—更多死亡循环。

M24-P4没有删除人物或强制人口目标，而是增加只读年度诊断、具体家庭季节性公地租用和独立
参数候选。第三候选在预先声明阈值下通过，证明技术性灭绝循环已经解除；该曲线仍不是历史
人口结论。
