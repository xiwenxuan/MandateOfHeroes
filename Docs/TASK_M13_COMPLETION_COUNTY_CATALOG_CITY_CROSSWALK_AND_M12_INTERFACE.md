# M13收尾任务书：全国县级目录、77城交叉与M12消费接口

## 一、任务定位

本阶段一次性收束
[`TASK_M13_HAN_140_POPULATION_AND_STABLE_GEOGRAPHY.md`](TASK_M13_HAN_140_POPULATION_AND_STABLE_GEOGRAPHY.md)

本任务只建设140年静态历史人口与地理输入，不生成永久人物，不修改V5存档，也不制作县级Unity场景或精确县界。

## 三、史料数量口径

《后汉书》郡国志存在必须并列保存的数量差异：

- 项目早期目标和现代常见概述约为1180个县级单位；
- 原文十三州部、司隶小计相加为1181；
- 郡国志逐项县名校录为1182，其中巴郡标题称“十四城”，正文实际列出十五项；
  另有正文分隔与州部小计之间的传抄口径差异。

本任务以1182条逐项记录作为可追溯目录，不为迎合汇总数删除正文列项；审计报告必须同时输出1180参考值、1181州部小计和1182逐项值，并记录巴郡差异。

## 四、交付范围

1. 将1182条县、邑、道、侯国等县级列项写入140年行政目录；
2. 为每条县级列项建立永久稳定ID和临时`county_area`地理身份；
3. 为每条县级行政单位建立10,000基点的一对一稳定地理关系；
4. 将105个郡国、尹、属国的治所指向其原文首列县级单位；
5. 完成`C001-C077`全部城市目录显式状态；
6. 强化审计报告，区分人口映射、县级映射、城市覆盖和数量争议；
7. 生成供M12直接读取的确定性人口—地理输入文件；
8. 更新数据字典、M13总任务书和系统总纲状态。

## 五、数据规则

- 县级ID不得依赖CSV行号、运行时实例ID或当前时间；
- 县名相同但隶属不同郡国时，以父级稳定ID区分；
- 没有可靠现代定位的县级区域坐标留空，`geometry_status=none`且`provisional=true`；
- 县级稳定映射不拆分郡国人口；M12只从105条人口记录出发读取其人口映射；
- 城市目录允许`exact`、`aggregate`、`approximate`和`unresolved`，不得为追求全解析率伪造对应；
- 原文列项、州部汇总、现代概述和游戏显示身份分别保存。
