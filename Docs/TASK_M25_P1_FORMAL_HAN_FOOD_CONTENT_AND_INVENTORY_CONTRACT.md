# M25-P1任务书：正式汉代多作物食品内容与库存合同

## 一、任务定位

在M25-P0统一世界执行内核和M24-P7百万压力世界证据之上，把小麦、粟、黍、稻、菽及六类食品
从压力工具候选数据升级为正式生产内容扩展包，并建立家庭粮仓可直接使用的食品库存合同。

本阶段不把普通内容硬编码为枚举，也不把压力工具的紧凑来源向量直接塞入`WorldState`。正式库存
继续使用V10以来的`ProductBatchState`和`InventoryTransactionState`：作物、食品、配方、方法与食品
属性均以稳定命名空间ID加载，世界存档用内容清单锁定实际加载包。

审计确认普通产品批次已经能够按任意`ProductDefinitionId`往返保存，因此本阶段保持V28，不增加
存档字段和迁移。新增库存事务类型属于既有封闭事务协议的兼容扩展；旧V28事实和核心内容包哈希
不得改变。

## 二、实现合同

### 2.1 正式内容包

- 新增可由`ProductionContentRegistry`加载的汉代食品扩展资源；
- 扩展包包含粟、黍、稻、菽的作物、原型地方品种、种子、收获物、种植配方和生产方法；
- 小麦沿用核心包定义，扩展包不得复制核心ID；
- 六类食品为麦粒、粟米、黍米、稻谷、菽豆和干粮；
- 历史存在性与数值玩法补全继续分别标注，不把候选比例写成史料结论。

### 2.2 食品属性合同

每个正式食品定义引用一个已有`product.food`产品，并声明：

- 开局候选份额；
- 营养折算；
- 体积折算；
- 腐败敏感度；
- 市场价值；
- 消费优先级；
- 来源层级与说明。

食品定义是开放内容集合，不使用固定食品枚举。重复食品引用、缺失产品、非食品产品、非法范围，
或声明了非零开局候选份额但包内份额合计不等于10000时必须拒绝加载；不参与开局分配的普通内容
包可以全部声明为0。

### 2.3 正式库存操作

- 世界创建或内容适配器可以向家庭粮仓建立任意正式产品的期初批次，同时增加真实仓储占用并写入
  `OpeningBalance`事务；
- 家庭食品消费按“消费优先级、生产日、批次ID”稳定排序，只消耗未预留数量；
- 营养满足量与物理数量分账，消费允许以最后一个离散单位略微超过目标营养，但不得凭空生成或
  重复扣除产品；
- 每次消费写入逐批次负向库存事务，并同步降低家庭粮仓真实占用；
- 食品汇总提供真实数量、营养、体积和市场价值；运输容量按食品体积折算；
- 市场可售查询同时兼容家庭设施批次与组织库存容器，不得因组织批次没有家庭设施而报错。

### 2.4 存档与兼容

- `WorldState.CurrentSchemaVersion`保持28；
- 未加载汉代食品扩展包的核心世界哈希与行为保持不变；
- 加载扩展包的世界在`ProductionContentManifest`保存包ID、版本、顺序和哈希；
- 缺失扩展包时继续明确报告原包ID，不得静默改指为小麦；
- 六类食品批次、消费事务和内容清单必须使用同一注册表完成存档往返。

## 三、工作包

### WP1：内容模型与资源

- 在正式生产内容注册表增加数据驱动食品定义；
- 增加查询、计数、合并、校验和哈希覆盖；
- 建立正式汉代食品扩展JSON资源。

### WP2：库存闭环

- 增加任意家庭产品期初批次入口；
- 增加食品库存汇总、营养目标消费和体积容量接口；
- 修复市场聚合对组织容器批次的兼容。

### WP3：回归与存档

- 验证核心内容资源与内置核心哈希仍一致；
- 验证扩展包五作物、六食品以及非法引用拒绝；
- 验证消费顺序、预留保护、物理数量/营养分账和逐批次守恒；
- 验证V28扩展世界往返以及缺包失败。

### WP4：状态同步与验收

- 更新系统总纲、世界模拟说明和任务路由；
- 执行全工程编译、核心测试、受控Unity测试、`git diff --check`和范围审阅。

## 四、验收标准

1. 正式注册表加载5种作物、6种食品定义，且不增加固定作物/食品枚举；
2. 核心包单独加载时的包ID、版本、内容哈希和既有计数保持不变；
3. 汉代扩展世界的家庭粮仓可以保存并消费至少两种不同食品批次；
4. 消费优先级确定、预留量不被消费、物理库存和事务逐批次守恒；
5. 营养、体积和市场价值来自正式食品定义并产生不同结果；
6. 扩展世界V28往返保存，缺失扩展包时明确失败；
7. 编译、核心测试、受控Unity测试和`git diff --check`分别通过。

## 五、不包含

- 把所有家庭旧`Grain`余额一次性拆成六类正式批次；
- 把县级市场、官仓和跨县运输的所有旧汇总状态一次性迁移为批次；
- 逐地块轮作、土壤、水利、气候适生和仓储环境腐败日程；
- 菜谱、每餐菜单、微量营养素与疾病系统；
- M25运行时命令队列、事务或事件的持久化；
- 100万完整正式Unity世界长跑。
