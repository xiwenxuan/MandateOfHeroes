# HAN-135-260-COUNTY-PRODUCTION-RESOURCE-INDUSTRY-TRADE-AND-SUPPLY-NETWORK-V1

## 任务定位

本任务建立 135—260 年全国 1182 县的生产、资源、产业、商品余缺与供应网络开发参考母版。成果服务于后续开局初始化、Cell 物质化、AI 规划、统计和区域校准，不直接创建永久人物、设施、库存或修改存档合同。

## 强制合同

- 县级稳定 ID 必须与 HanWorldV1 和全国人口母版一致，完整覆盖 1182 县。
- 运行时真实世界账仍为 `Cell + Resource + Facility + Worker + Recipe + Production + Inventory + Transport`。
- 县级农业、工业和运输能力只是初始化与校准参考，不能替代具体设施、劳动者、配方和库存。
- 不要求县、郡或城市自给自足；短缺、输入依赖、运输损耗和未满足需求必须保留。
- 资源潜力不等于历史开发，理论产出不等于可出口量，服务能力不等于实物库存。
- 历史事实、考古证据、重建、模型、未知、无证据和不适用必须明确分级。
- 史料不确定量使用低值、推荐值、高值或明确模型参数，不使用隐藏的全国平衡倍率。
- 184 年为最高细节基准；140、184、189、194、200、207、214、219、223、227、234、249、260 使用快照与 ChangePoint 继承。
- 没有兼容许可的数据不得导入。CHGIS V3 仅登记为研究定位线索，不进入可再分发母版。

## 交付与验收

- `COUNTY_PACKS`：全国 JSON 母版、县包 NDJSON 和索引。
- `MASTER_WORKBOOKS`：任务书规定的 40 份工作簿。
- `REGIONAL_STUDIES`：区域和产业专题说明。
- `MAP_OUTPUTS`：184 县经济点图层、供应走廊图层及图层清单。
- `SOURCES`：来源、许可和使用边界。
- `VALIDATION`：数据、公式、渲染和交付校验。
- 通过 1182 县、13 情景、人口守恒、跨表引用、贸易守恒、范围护栏和文档模式验证。
