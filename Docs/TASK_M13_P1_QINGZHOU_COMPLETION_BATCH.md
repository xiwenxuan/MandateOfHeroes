## 三、来源与校录判断

原始行政和户口事实采用公共领域古籍《后汉书》卷三十二·郡国四。维基文库
《四库全书》网页转录及另一公开古籍转录用于原文核对；现代校录网页只用于
交叉检查，不复制其完整表格、公式或现代文字表达。

两份公开转录的六项户口数一致，但济南条类型不同：维基文库网页转录作“济南郡”，
另一公开转录作“济南国”。《后汉书》本纪所见沿革显示，125年济南王香无子国绝，
126年顺帝又封刘显为济南王，因此140年行政截面按济南国保存，同时将“济南郡”
作为转录异文写入备注并降低行政类型置信度。本批六项未采用现代数值补正。
