# M26-P5B 中山全层级地图纵向切片任务书

## 1. 阶段目标

把中山从“世界地图上的文字节点＋城镇建筑卡片”升级为第一条可验证的全层级地图路线：

```text
天下/州郡世界图上的中山节点
→ 进入中山城镇空间近览
→ 点击真实建筑
→ 使用市场、商号、仓库、客舍、车马场、行会馆或官署功能
→ 结果写回同一人物、组织、库存、市场、任务和时间账
```

本阶段验证地图比例尺可以改变表现和操作入口，但不能创建另一套建筑、库存或人物事实。

## 2. 权威与前置文档

- `GAME_SYSTEMS_MASTER_AND_STATUS.md`
- `TASK_M16_LIVING_WORLD_MAP_INFORMATION_AND_DELEGATION_DESIGN.md`
- `MAP_ART_RESOURCE_PLAN.md`
- `TASK_M26_P5_MERCHANT_ORGANIZATION_GAMEPLAY_EXPANSION.md`
- `TASK_M26_P5A_ZHONGSHAN_MERCHANT_TOWN_OPERATION_SLICE.md`
- `REFERENCE_JIUZHOU_GAMEPLAY_ANALYSIS.md`

M26-P5A 的七座设施、商行组织、正式仓库和进入权限继续有效。本任务只增加空间合同、地图入口和表现，不重新生成经营账。

## 3. 范围

### P5B-1：V68城镇设施空间合同

为每个已布置设施保存：

- 是否已有地图布置；
- 稳定街区ID；
- 以万分比表示的城镇平面中心坐标；
- 以万分比表示的占地宽高。

坐标和占地是领域与存档事实。表现层只能读取，不能按屏幕尺寸或随机数改写。

### P5B-2：中山首批确定性布局

只为P5A既有七个稳定设施ID提供编写布局：中山集市、商行主堂、商行仓库、客舍、车马场、行会馆和中山国官署。布局划分为市廛、商坊、旅舍车马区和官署区。

### P5B-3：世界地图入口

- 中山节点显示已有建筑规模；
- 玩家身处中山且不在旅途中时，节点提供“进入城镇”；
- 选择其他地点仍保持原有旅行和有限信息流程。

### P5B-4：城镇空间近览与建筑进入

- 原创中山全景仅作环境底图；
- 七座建筑按V68坐标叠加为动态、可点击标记；
- 标记显示建筑名称、街区和权限状态；
- 点击后进入P5A既有建筑功能，继续使用同一本世界账；
- 缺少坐标的扩展设施进入“待布置建筑”清单，不随机摆放、不丢失。

### P5B-5：存档迁移与验证

V67迁移到V68时：

- 只为中山七个已知稳定设施ID补入编写布局；
- 未知或MOD设施保持未布置；
- 不创建或删除设施、人物、组织、库存、货物、金钱和历史记录；
- 坐标越界、占地非法、同地点坐标重复必须拒绝。

## 4. 明确不在本阶段

- 全国城镇自动布局和所有历史城市美术；
- 玩家/NPC自由选址建设的完整编辑器；
- 建筑内部自由行走、3D室内或街道人群动画；
- 完整城市攻防、火灾、拆迁和设施损毁；
- 通过地图缩放泄露玩家或组织尚未知的设施情报；
- 复制《三国志11》《九州：商旅》《吾今有世家》画面或资源。

## 5. 验收标准

1. 原型世界包含七座唯一、合法且持久布置的中山建筑。
2. V68存档往返保留街区、坐标和占地。
3. V67迁移只布置已知七座建筑，未知设施数量和未布置状态保持不变。
4. 模拟层按空间顺序投影布局，Unity表现层不维护第二份坐标。
5. 玩家可在世界地图直接进入中山，在空间近览图点击建筑并打开真实功能。
6. 无坐标建筑有明确降级表现。
7. 全工程编译、核心测试、受控Unity EditMode、`git diff --check`和差异审阅通过。
8. 生成独立Windows试玩构建并完成启动冒烟；人工确认完整点击路径单独记录。

## 6. 停止条件

- 不为制造“看起来完整”而伪造库存、价格、NPC或建筑。
- 不把中山布局写死为仅存在于`SimulationDashboard`的UI常量。
- 不让旧存档未知设施被删除、合并或随机挪到任意位置。
- 不在没有兼容许可证记录时引入外部地图或商业游戏素材。
- Unity或外部工具超过300秒即终止本任务启动的进程并报告日志。
