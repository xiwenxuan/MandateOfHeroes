# M24-P7多作物食物生态报告

## 一、结论

百万压力世界已从“多产品有来源”推进到“多产品有不同世界效果”。小麦、粟、黍、稻、菽
通过五种农业绑定生产；营养与物理数量分账，体积影响赈运能力，产品组合影响市场价格，
易腐属性决定损耗对象，县内菽作份额提供有界轮作支持，家庭保存加工把麦粒转换为干粮。

## 六、边界

- 作物身份是汉代历史候选，份额和参数属于玩法补全；
- 当前轮作是县级豆科土地份额的有界支持，不是逐地块多年轮作；
- 家庭加工是1:1保存转换，尚未展开面粉、麸皮和设施工单；
- 总损耗率仍来自既有生存配置，易腐差异决定损失哪种产品，尚未按仓储环境独立计算总损耗；
- 扩展包属于百万压力工具，尚未并入V28正式分区内容与存档。
