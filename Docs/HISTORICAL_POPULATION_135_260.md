# 135—260年东汉至三国人口分布基线

## 1. 文档定位

本文为创建世界、历史人口档位、家庭生成、战争迁徙和长期人口模拟提供
135—260年的逐年人口基线与空间分配方法。

这不是“每年都有一次古代人口普查”的伪造数据。现存史料只有少数户口锚点，
其中140年《续汉书·郡国志》保存了最重要的郡国级空间截面；其余年份必须结合
户籍数字、战争、疫病、迁徙和现代人口史研究进行推演。

本文覆盖：

- 135—219年：东汉；
- 220—260年：魏、蜀、吴三国；
- 全国逐年人口基线；
- 州郡人口分布的计算规则；
- 登记人口与推定实际人口的区别；
- 历史档、标准档和自定义人口档的缩放规则。

本文全国逐年曲线仍为 **V0.1 全国曲线与空间方法版**。后续M13已经完成140年
105项人口来源、1182项县级目录、稳定地理映射和M12消费接口；年度州郡变化表及
220—260年的区域恢复曲线仍需继续校准。结构化现状以
`TASK_M13_HAN_140_POPULATION_AND_STABLE_GEOGRAPHY.md`为准。

## 2. 证据等级

| 等级 | 含义 | 使用规则 |
|---|---|---|
| H | 史籍户口锚点 | 保留原文口径、年份差异和可能讹误 |
| R | 现代研究估算 | 记录作者、著作、估计范围和采用理由 |
| M | 游戏人口模型锚点 | 为连续模拟选择的基准，不冒充史实统计 |
| I | 锚点间年度插值 | 只用于创建世界，精确个位不表示史料精度 |

界面和数据不得只显示一个数字而隐藏证据等级。史料登记人口、研究推定实际人口和
游戏生成目标是三个不同字段。

## 3. 主要史料锚点

### 3.1 永和五年（140）

《续汉书·郡国志》篇末合计：

```text
户：9,698,630
口：49,150,220
```

现存各郡国分项存在缺项或疑似抄写讹误。现代校录者汇总现存分项得到约
47,908,838口，经缺项和讹误修正得到约49,223,783口，与篇末总数接近。
因此本项目采用：

- 全国总量：优先保留篇末49,150,220口；
- 空间权重：使用逐郡校录后的修正版；
- 缺项：保留修正标记，不伪装为原文；
- 州郡边界：采用140年行政截面，再映射到游戏稳定地理单元。

参考：[《后汉书》郡国志人口数据校录说明](https://zae06141.client.jp/gunkokushi.html)。

### 3.2 永寿三年（157）

《晋书·地理志》所引东汉户口总数：

```text
户：10,677,960
口：56,486,856
```

此数只有全国总量，不能直接伪造同年的完整郡国分布。项目允许历史模式在157年前后
超过5,000万人，达到约5,650万；标准性能档仍可封顶5,000万并同比缩放。

参考：[陶元珍《三国食货志·户口》整理的史籍原文](https://www.diancang.xyz/lishizhuanji/sanguoshihuozhi/128636.html)。

### 3.3 东汉末至三国

东汉末以后的户籍数字不能直接等同于实际人口：

- 战争、疫病和饥荒造成真实死亡；
- 大量人口逃离原籍或脱离国家户籍；
- 豪族部曲、依附人口、屯田户、军户和边地族群可能不在同一统计口径；
- 北方减耗通常重于南方，南迁和东北迁徙改变空间分布；
- 同一史籍中的“户”“口”“兵”“吏”可能使用不同统计范围。

三国后期约767万的常见合计主要是政权登记户口，不应解释为天下只剩767万人。
本项目V0.1采用现代人口史中“220年前后实际人口谷底约2,300万”的研究方向作为模型锚点，
但在结构化数据中标为 `R/M`，不标为史籍实录。

《三国食货志》也指出北方减耗较高，而南方和东北相对较低，并列举河东、丹阳、
蜀郡、辽东等地区的不同变化，适合作为空间修正依据。

## 4. 两条人口口径

每个年份和地区至少保存：

```text
registered_population  // 当年政权能够登记、征税或征役的人口
estimated_population   // 包含漏籍、部曲、屯田、流民等的推定实际人口
generation_target      // 创建世界时实际生成的人物数量
evidence_grade
source_ids[]
model_version
```

V0.1逐年表给出的是 `estimated_population` 的游戏基线。
`registered_population`只在存在史料或可解释模型时填写，不能用同一比例机械生成。

## 5. 空间分布方法

### 5.1 稳定地理单元

行政区在135—260年频繁分合，人口不能直接绑定会变化的郡名。底层先绑定稳定地理单元：

```text
StablePopulationRegion
├─ 地理范围
├─ 140年所属郡国
├─ 当年所属政权与行政区
├─ 聚落与县治
├─ 可耕地、水源和交通
└─ 年度人口状态
```

行政区变化只改变管理关系，不凭空迁移或创造人口。

### 5.2 140年空间基准

逐郡校录《续汉书·郡国志》，修正后归入：

- 司隶；
- 豫州；
- 冀州；
- 兖州；
- 徐州；
- 青州；
- 荆州；
- 扬州；
- 益州；
- 凉州；
- 并州；
- 幽州；
- 交州；
- 辽东、西域及其他边地单列区。

州级只用于阅读和粗调，最终人口必须继续分配到郡国、县邑、乡村和城市圈。

### 5.3 年度区域变化

每个地区按以下因果更新，不使用全国同比缩放代替地方历史：

```text
年末人口
= 年初人口
+ 出生
- 死亡
+ 迁入
- 迁出
- 永久失踪
```

模型至少读取：

- 战争强度和实际战场；
- 围城、屠杀、焚毁和征发；
- 疫病、饥荒、水旱和蝗灾；
- 土地承载力与粮食库存；
- 豪族吸纳、户籍隐匿和重新登记；
- 强制迁徙、难民路线和屯田；
- 政权控制力与基层户籍能力。

全国曲线是校准目标，不应覆盖已经由地方事件产生的守恒结果。

### 5.4 分期空间趋势

| 时期 | 主要空间趋势 |
|---|---|
| 135—157 | 全国总体增长；140年郡国分布为核心锚点 |
| 158—183 | 增长停滞，疫病、羌乱和地方灾害造成区域分化 |
| 184—189 | 黄巾战争及镇压重创冀、豫、兖、青、荆北等相关区域 |
| 190—196 | 关东混战、董卓迁都、关中和中原破坏，流民大规模迁移 |
| 197—208 | 北方逐步整合但战争持续；荆州、益州、江东吸纳移民 |
| 209—220 | 荆州争夺、汉中战争和疫病继续压低总量，220年前后进入模型谷底 |
| 221—240 | 三国政权稳定户籍、屯田与恢复生产，局部战争造成区域波动 |
| 241—260 | 总体缓慢恢复，淮南、荆州、汉中和西北战区仍受军事行动影响 |

## 7. 人口档位

### 7.1 历史档

- 使用本文年度推定人口；
- 157年前后允许达到约5,650万；
- 使用140年郡国空间权重和年度区域修正；
- 对史料不确定性提供说明。

### 7.2 标准性能档

- 同一年度最高生成5,000万人；
- 当历史基线超过5,000万时同比缩放；
- 不改变州郡相对分布、家庭结构和事件风险；
- UI明确标为“性能缩尺”，不标成历史实数。

```text
scale = min(1, 50,000,000 / historical_estimated_population)
generation_target(region) = round(historical_region_population × scale)
```

### 7.3 自定义档

玩家可以选择更低人口规模。缩放必须作用到具体家户、聚落、职业、消费和兵源，
不能只修改地图显示数字。

## 8. 与动态世界的关系

本文只提供开局基线和无玩家干预时的校准方向。游戏开始后：

- 人口由出生、死亡和迁徙真实变化；
- 玩家阻止战争或改善防疫后，不强制回落到历史曲线；
- 玩家造成更严重灾难时，也不强制恢复到历史值；
- 历史曲线只用于对照、AI预期和异常审计；
- 每个具体人物仍遵守永久ID、家庭和人口守恒规则。

## 9. 后续数据任务

### P0：140年郡国原表（M13已完成首轮结构化交付）

1. 已校录105项人口来源和1182项县级目录；
2. 同时保存原文值、修正值、缺项和修正理由；
3. 汇总值必须与全国锚点解释一致；
4. 映射到项目稳定地点ID。

### P1：年度事件修正

1. 为135—260逐年建立战争、疫病、灾害和迁徙索引；
2. 为每个事件定义受影响地区，而不是全国平均扣减；
3. 区分死亡、逃亡、迁移、漏籍和重新登记；
4. 校准州级、郡级和城市圈结果。

### P2：三国政权户籍口径

1. 校录魏、蜀、吴亡国或相关年份的户、口、兵、吏数据；
2. 分离政权登记人口和推定实际人口；
3. 建立屯田户、军户、部曲、依附人口和边地人口规则；
4. 与280年西晋户籍锚点进行后向校验，但不把280年结果硬套到260年。

### P3：结构化交付

最终生成：

```text
historical_population_year.csv
historical_population_region_year.csv
historical_population_sources.json
historical_population_adjustments.json
```

所有数字必须带 `evidence_grade`、`source_id` 和 `model_version`。

## 10. 当前限制

- 135、165、173、183及184年以后大多数锚点仍是V0.1游戏模型选择；
- 140年数据已经由M13形成结构化来源、行政目录、稳定地理映射和审计文件，但缺项、
  讹误修正及后续版本仍须保留证据等级；
- 157年没有完整同年郡国分表；
- 220—260恢复曲线需要继续结合三国户籍、屯田和区域研究校准；
- 当前逐年插值没有取代动态出生率、死亡率和迁徙模型；
- 不得把本表用于现实历史人口的精确断言。
