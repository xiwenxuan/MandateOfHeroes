# M3任务书：军府绢图地图美术竖切片

## 目标

在不改变现有旅行、军队、地点、存档和信息图层逻辑的前提下，将M2程序员地图升级为原创的“东汉军府舆图＋绢本设色＋封泥军棋”视觉原型。

地图不复刻任何商业游戏的水墨画面、界面布局、图标或素材，只保留“山河即战场、地图信息清楚、缩放自由”的玩法体验。

## 本次范围

- 生成原创程序化绢布纹理，不引入第三方美术文件；
- 使用赭石、石青、石绿、朱砂和墨色构成统一色盘；
- 以笔触色块表现平原、林地和山地；
- 以原创山形图章、封泥城池和木牌军团替换矩形占位表现；
- 远、中、近三个缩放层级呈现不同密度的地图信息；
- 近景增加农田、林地和地方性地貌细节；
- 保留四种信息图层、路线点击、旅行进度和军队移动；
- 记录后续开放地理数据和第三方资源的许可准入规则。

## 三档视角

### 天下概览

- 突出山河、城市和军团；
- 隐藏小型地方设施和次要说明；
- 用于观察战线与地区关系。

### 州郡舆图

- 显示道路里程、地形笔触和城市信息；
- 用于旅行、运输、任务和地区经营。

### 县乡近览

- 在同一坐标体系上增加农田、林地与地方标记；
- 用于承接商人、农户、医者、剿匪和地方建设玩法；
- 本里程碑仅完成表现验证，不增加新的县乡模拟数据。

## 资源准入

- 优先使用自制、CC0或公共领域资源；
- 每项外部资源记录名称、作者、来源、许可、修改情况和项目位置；
- CHGIS数据不进入公开仓库或商业发行数据；
- OSM衍生数据库必须单独评估ODbL义务；
- Unity Asset Store标准许可素材不得将源文件直接公开到GitHub；
- 不使用从《三国志》系列或其他商业游戏中提取的地图、字体、图标和数据文件。

## 验收标准

1. 地图具有统一、原创的绢本设色风格；
2. 三档缩放层级名称和细节差异可见；
3. 六个地点、六条道路、河流、玩家与军队仍可辨认；
4. 四种信息图层继续工作；
5. 地点选择与相邻地点旅行继续工作；
6. 不提交外部版权素材；
7. Unity程序编译通过；
8. 原有核心测试无回归。

## 当前限制

- 当前竖切片继续使用M2的涿县—广宗六地点原型数据，不代表最终历史地理精度；
- 县乡农田、林地和望楼目前是随缩放出现的表现层，还没有成为可建设地点；
- 程序化绢纹和图章用于确立原创方向，正式版本可在保持色盘与轮廓规则的前提下替换为自制高清素材；
- 图像风格板生成服务本次发生网络错误，因此未将任何生成图片加入工程。
