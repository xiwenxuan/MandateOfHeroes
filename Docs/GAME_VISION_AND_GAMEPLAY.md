# 《群雄志：仕途》核心思路与玩法设计

## 1. 游戏愿景

这是一款以东汉末至三国时代为核心背景的开放式家族人生模拟战略游戏。135—260年是主要可选
开局年份与重点历史内容覆盖区间，但不是游戏的强制结束时间。260年以后，世界、人物和家族仍可
继续发展。

玩家以一名穿越者或时代原住民开始，在乱世到来前经营个人生活，选择从军、入仕、经商、
行侠、学医、务农、从事工艺、加入宗教或成为密探。角色会成长、衰老和死亡，其家产、
知识、关系、事业和未竟目标由后人、养子、弟子或门客继承。

玩家不必成为君主，也不必统一天下。游戏关注的是：

> 一个普通人和他建立的家族，如何生活于三国时代，参与历史，并通过数代人的选择改变世界。

## 2. 参考作品与吸收方向

只借鉴玩法思想和系统优点，所有程序、数据、文本、地图、数值和美术均重新设计。

| 参考作品 | 主要借鉴方向 | 本项目的改造 |
|---|---|---|
| 三国志7/8/10/13 | 全武将扮演、身份、仕途、拜访、任务、人际关系 | 扩展到普通人、职业、家族与多代传承 |
| 三国志11 | 大地图、城市、关港、军团、地图建筑和地形战略 | 作为宏观战争及据点骨架，减少重复内政 |
| 三国志12 | 城市分工、有限设施和快速反馈 | 用于城市特色及任务结果的即时反馈 |
| 三国志14 | 土地、府、地区、城市圈和补给线 | 减少逐格操作，强化道路、地区和后勤任务 |
| 九州：商旅 | 城际贸易、商品供需、商队、产业和商会竞争 | 经济与战争、灾害、任务和势力军需联动 |
| 九州：立志 | 商道、武道、开放成长和多路线养成 | 改为可转变、可交叉的身份道路 |
| 吾今有世家 | 家族产业、门客、联姻、入仕和世家经营 | 玩家控制当前家主，其他族人由AI生活 |
| 古代人生 | 普通人的一生、职业差异和生活事件 | 每种身份获得独立玩法，并进入同一世界模拟 |

## 3. 六条设计原则

### 3.0 身份即玩法入口

本项目不把所有系统平均分配给所有角色，也不把身份做成附加属性。玩家当前的主要身份决定其
核心操作界面、日常循环、可见信息、可控制对象和主要胜利方式。

每种主要身份都对应一套足以独立成立的玩法：

| 当前主要身份 | 核心玩法 | 主要参考方向 |
|---|---|---|
| 武将/军人 | 编制、训练、行军、补给、野战、攻城、守城和军团指挥 | 三国志系列战争玩法 |
| 官吏/士人 | 政务、案件、评定、举荐、派系、升迁和地方治理 | 三国志仕途 + 吾今有世家官场 |
| 商人 | 商品供需、跑商、商队、产业、分号和商会竞争 | 九州：商旅 + 九州：立志商道 |
| 侠士 | 武道、游历、委托、同道、门客、比武和私人武装 | 九州：立志武道 |
| 医者 | 诊疗、药材、医案、疫病、军医和师徒传承 | 古代人生职业体验 + 原创医者系统 |
| 家主/世家 | 族产、教育、婚姻、门客、分家、继承和政治投资 | 吾今有世家 |
| 农户 | 土地、耕作、赋税、灾害、债务和乡里关系 | 古代人生职业体验 + 原创农业系统 |
| 工匠 | 材料、订单、制造、作坊、工艺和学徒 | 古代人生职业体验 + 原创生产系统 |
| 宗教人士 | 修行、传道、赈济、信众、组织和官府关系 | 东汉社会背景下的原创系统 |
| 密探 | 掩护身份、线人、情报、策反、破坏和反间 | 三国志计略 + 原创谍报系统 |

玩家转变主要身份，相当于进入另一套主玩法，但过去积累的关系、能力、产业和历史不会清空。
次要身份提供有限行动和跨系统优势，不取代当前主要身份的核心循环。

### 3.0.1 多身份结构

角色可以拥有多重身份，但不同身份承担不同作用：

- **主身份**：同一时间一个，决定核心玩法、主要界面、时间消耗和可控制对象。
- **社会身份**：可以有多个，例如士人、医者、商人或家主，提供有限行动、关系和社会认可。
- **组织职位**：角色在势力、军队、官府、商会、家族、师门和宗教组织中的具体位置。
- **隐藏身份**：密探、走私者、叛军合作者或秘密教团成员，拥有掩护度和暴露风险。

角色拥有某项能力不等于获得相应社会身份。身份形成分为三个阶段：

1. 学习能力；
2. 从事实践；
3. 获得师门、组织、官府或社会认可。

切换主身份需要真实条件和人生事件，例如辞官、退伍、拜师、获得商号、受组织征召或被迫逃亡，
不能通过菜单无成本切换。

### 3.0.2 身份冲突

多身份的主要价值是产生责任和利益冲突，而不只是叠加能力：

- 官吏兼家主：依法查处族人，还是维护家族？
- 商人兼官吏：能否使用政务情报谋取商业利益？
- 医者兼武将：优先救主将，还是救更多普通士卒？
- 侠士兼继承人：继续游历，还是回家承担家业？
- 商人兼密探：商路既是生意网络，也是情报网络。

这些选择会改变身份认可、组织忠诚、家族关系和社会评价。

### 3.0.3 首版限制

为控制操作量，首版采用：

- 1个主身份；
- 最多2个活跃社会身份；
- 最多1个隐藏身份；
- 组织职位不设硬上限，但职位义务会占用时间；
- 其他完整身份玩法由家族成员或门客承担。

家族成员由AI经营自己的主要人生，玩家通过家族会议、资源分配和关键事件影响他们。必要时可以
在重大事件中临时切换到相关家族成员，但不能日常微操所有族人。

典型复合身份包括儒将、官商、军医、豪侠家主、方士医者和商旅密探。

### 3.1 天下自行运转

势力、军团、官员、商队、家族、部落和普通人都由AI行动。玩家不介入时，战争、贸易、
迁徙、疾病、任命和人物关系依然变化。

### 3.2 每种身份都像一款小型游戏

身份不能只提供属性加成。每种身份必须拥有独特资源、关系、任务、风险、晋升路线和结局。

### 3.3 所有身份共享同一个世界

商人的粮食会成为军队补给；医者控制疫病会保存城市人口；官吏的征税会影响农户生计；
侠士保护商路会降低地区风险。职业玩法不能成为互不相干的小游戏。

### 3.4 历史是动态舞台

著名事件具有史实条件和变体条件。玩家可以参与、旁观、阻止或改变事件，历史不会因微小偏差
完全消失，也不会无视世界变化强制照演。

### 3.5 角色会死，传承不会停止

死亡不是简单失败。玩家可以将主角身份交给后人、养子、弟子或门客，继续经营家族与事业。

### 3.6 不统一天下也算完整人生

名医、豪商、名士、工匠、侠客、地方官、农庄主和隐士都拥有独立的成功标准与结局。

## 4. 一局游戏的结构

### 4.1 开局

玩家选择：

- 开始年份和地区
- 穿越者或时代原住民
- 年龄、性别和家庭背景
- 原始能力与现代知识方向
- 初始身份和社会关系
- 史实、演义或沙盒模式

主要历史开局年份在135—260年之间。不同开局提供当年的势力、人物、城市、家族和事件状态；
玩家也可以从推荐剧本进入，不必从135年开始完整游玩。

穿越者拥有有限的历史印象和现代常识，但受材料、工艺、身份、人脉和历史偏移限制。

### 4.1.1 260年后的开放发展

260年只表示重点史实资料逐渐结束，不触发结算或强制通关。此后游戏转入“历史延续阶段”：

- 已存在的人物继续衰老、死亡和传承；
- 家族继续繁衍、分家、联姻、兴盛或衰落；
- 势力继续战争、结盟、篡位、统一或再次分裂；
- 城市、商路、产业、宗教和地方组织继续运行；
- 史实人物减少后，由历史后代与系统生成角色补充社会；
- 事件由既有世界状态、人物关系和组织目标动态生成；
- 若世界已严重偏离历史，不强制出现西晋统一等固定结局。

游戏可一直进行到玩家主动结束、家族彻底断绝且无合法继承者，或达到玩家设置的年代上限。
年代上限属于开局选项，不作为固定规则。

### 4.2 月度循环

每月分为六个阶段：

1. **天下演算**：势力战略、军团行动、市场、人口、疾病和迁徙。
2. **地方演算**：城市政策、县邑状态、豪族活动、治安和商品供需。
3. **家庭阶段**：收入支出、教育、婚姻、健康、产业和家族关系。
4. **行动阶段**：玩家安排移动、工作、拜访、学习、经营和任务。
5. **事件阶段**：历史、职业、家庭和随机事件发生。
6. **月报阶段**：展示与玩家有关的天下变化及家族记录。

平时使用月度推进；战争、远行和危机期间可进入旬或日级时间。

### 4.3 一生与传承

角色可能因年龄、疾病、战斗、政治斗争或意外死亡。继承者可以是：

- 子女或其他血亲
- 养子
- 配偶
- 女婿或儿媳
- 弟子
- 门客

不同继承者能继承的财产、关系、官职影响、技术和名望不同，并可能引起家族内部争议。

## 5. 世界结构

### 5.1 地图层级

| 层级 | 主要功能 |
|---|---|
| 都城 | 朝廷、称帝、中央官职和全国政治 |
| 主要城市 | 完整内政、征兵、太守、市场和大型任务 |
| 县城/支城 | 县令、地方治安、小型市场、驻军和职业任务 |
| 府/聚落 | 人口、粮食、马匹、矿产、药材等地区资源 |
| 关隘 | 道路控制、驻军和防御 |
| 港口 | 水运、水军、贸易与补给 |
| 营寨/根据地 | 临时军营、侠客据点、宗教据点或个人基地 |
| 战场地标 | 赤壁、祁山、街亭等历史事件和战术入口 |

城市全集采用系列与历史清单的77城并集，但不同剧本只开放适当数量的完整管理城市。

### 5.2 城市状态

- 人口与流民
- 农业、商业、文化和工艺
- 粮食、资金、兵力和军需
- 治安、民心和疫病
- 豪族、商会、士人、军方和宗教势力
- 商品库存与价格
- 所属县邑、府、聚落、关隘和港口

## 6. 身份与人生道路

角色可以拥有多种能力，但每个时期只有一个主要社会身份和若干次要身份。转变身份需要实际经历、
人脉或组织接纳，而不是点击转职按钮。

### 6.1 军人

#### 核心资源

军功、军阶、部下忠诚、部队经验、装备和主将信任。

#### 核心循环

训练 → 执行军令 → 参与战斗或后勤 → 保护部下 → 获得军功 → 晋升或获得独立指挥权。

#### 发展路线

乡勇、士卒、队率、军侯、校尉、将军、都督；也可能成为逃兵、佣兵或地方武装首领。

#### 核心矛盾

服从军令、保护部下、追求军功和维护百姓之间经常冲突。

### 6.2 士人

#### 核心资源

学识、清名、师承、著述、门生和士人评价。

#### 核心循环

求学 → 拜师 → 文会/论辩 → 获得评价 → 举荐他人或接受征辟 → 出仕、讲学或隐居。

#### 发展路线

学子、名士、幕僚、教师、史官、军师和隐士。

### 6.3 官吏

#### 核心资源

官阶、政绩、君主信任、上司评价、地方支持和派系力量。

#### 核心循环

接受职务 → 处理政务和案件 → 完成考核 → 应对同僚与豪族 → 升迁、外放、贬谪或辞官。

#### 官职职责

县令治理县邑；太守管理城市和属县；都督负责军团；中央官员参与制度、财政和人事。

官位受空缺、资历、举荐、派系、家世和信任影响，不只看能力数值。

### 6.4 商人

#### 核心资源

资金、货物、商誉、运力、产业、行情和商会关系。

#### 核心循环

调查供需 → 采购 → 组织商队 → 选择道路和护卫 → 运输 → 销售 → 投资产地与分号。

#### 发展路线

小贩、行商、商队主、店主、豪商、商会领袖、官商、义商或走私者。

#### 世界作用

商品库存影响城市生活和军需。战争会切断商路，商人可以救济城市，也可以囤积居奇。

### 6.5 侠士

#### 核心资源

武名、侠名、同道、门客、江湖关系、装备和私兵。

#### 核心循环

拜师习武 → 游历切磋 → 接受委托 → 结交同道 → 介入地方冲突 → 建立个人名声或根据地。

#### 发展路线

游侠、剑客、豪侠、义军首领、门客首领、刺客、盗魁或地方豪强。

### 6.6 医者

#### 核心资源

医术、医德、药材、诊疗经验、医案、师门和名医声望。

#### 核心循环

问诊 → 判断抽象病类 → 选择治疗方案 → 消耗药材和时间 → 观察结果 → 记录医案。

疾病使用寒热、虚实、外伤、疫病、中毒、情志等游戏化分类，不模拟真实医疗建议。

#### 发展路线

药童、游医、坐堂医、军医、名医、太医和医学宗师。

### 6.7 世家

世家是一种跨身份的长期组织，不是单一职业。

#### 核心资源

族产、田地、商铺、宅邸、藏书、部曲、门客、族望、婚姻网络和家学。

#### 核心循环

培养族人 → 分配事业 → 经营产业 → 联姻和结盟 → 举荐入仕 → 应对政治风险 → 传承家业。

玩家控制当前家主或代表人物，其他族人由AI生活，并可能拒绝安排、分家或投向敌对势力。

### 6.8 农户

#### 核心资源

土地、劳力、种子、牲畜、农具、粮食、债务和宗族互助。

#### 核心循环

耕作 → 应对天气与赋税 → 储粮或出售 → 修建水利 → 扩地、租佃或逃荒。

#### 发展路线

佃农、自耕农、富农、地主、庄园主和地方豪强。

### 6.9 工匠

#### 核心资源

技艺、配方、工具、材料、作坊、订单和学徒。

#### 核心循环

学习工艺 → 采购材料 → 接单制造 → 控制质量与成本 → 扩建作坊 → 培养学徒。

可从事农具、兵器、铠甲、船只、车辆、攻城器械、陶器和建筑等方向。

### 6.10 宗教人士

#### 核心资源

信众、教义影响、赈济资源、神秘声望、组织网络和官府态度。

#### 核心循环

修行/传道 → 治病赈济 → 建立信众 → 处理地方危机 → 与官府合作、保持独立或组织反抗。

宗教组织既可能安定地方，也可能发展为起义力量。

### 6.11 密探

密探是隐藏身份，可以覆盖在商人、官吏、侠士、仆役等公开身份之下。

#### 核心资源

情报网、身份掩护、线人、秘密、上级信任和暴露风险。

#### 核心循环

建立掩护 → 接触目标 → 收集或伪造情报 → 传递情报 → 破坏、策反或反间 → 撤离。

## 7. 身份联动

每个世界危机都会向不同身份提供不同参与方式。

### 示例：城市爆发疫病

| 身份 | 可执行内容 |
|---|---|
| 医者 | 诊疗、隔离、研究和培养助手 |
| 商人 | 采购药材、运输、平价销售或囤积 |
| 官吏 | 封锁、赈济、拨款、公开或隐瞒 |
| 侠士 | 护送药队、维持秩序、调查假药 |
| 士人 | 撰写告示、劝说豪族、记录事件 |
| 军人 | 控制城门、保护仓库、维持隔离 |
| 农户 | 提供粮食、逃难、出售或失去土地 |
| 工匠 | 制作医疗工具、车辆和临时设施 |
| 宗教 | 赈济、安抚、祈禳或扩大信众 |
| 密探 | 调查投毒、敌方破坏或官员隐瞒 |
| 世家 | 开仓赈济、资助医者或兼并破产土地 |

## 8. 历史事件参与机制

每个著名事件不是一段只能观看的剧情，而是一组可占据的“参与席位”：

- 核心人物
- 军事参与者
- 政治参与者
- 后勤参与者
- 情报参与者
- 地方参与者
- 见证和记录者
- 受害者

### 示例：桃园结义

- 商人可以提供资金、马匹和物资。
- 工匠可以打造兵器。
- 官吏可以批准或阻止募兵。
- 侠士可以加入乡勇或与三人结交。
- 医者可以处理募兵和战斗中的伤病。
- 农户可以提供粮食、加入队伍或反对征发。
- 密探可以调查这支新兴私人武装。

### 事件状态

- **史实事件**：人物、地点和条件接近历史。
- **变体事件**：主题保留，但参与者、地点或结果变化。
- **蝴蝶事件**：历史已明显偏离，由系统生成新的事件链。

## 9. 家族系统

### 9.1 家族成员

父母、兄弟姐妹、配偶、子女、养子、姻亲、门客和弟子均可进入家族网络。

### 9.2 家族会议

玩家可以提出：

- 教育和职业方向
- 婚姻与联姻
- 产业投资
- 家产分配
- 投靠或离开某个势力
- 迁居
- 选择继承人
- 处理犯错、分家和背叛

族人根据性格、关系和利益作出回应，不保证服从。

### 9.3 家族传承

可传承内容包括：

- 财产和产业
- 技术、配方和藏书
- 商号、医馆、作坊和庄园
- 同道、门客、学徒和客户
- 家族声望与仇恨
- 政治恩荫和连带罪责
- 穿越者留下的秘密知识

### 9.4 家族世录

游戏自动记录：

- 出生、婚姻、继承和死亡
- 官职、产业和成就
- 参与的历史事件
- 家族分支和关系
- 重大选择造成的世界变化

世录是整局游戏最重要的最终成果之一。

## 10. 战略、任务与人生的连接

```text
天下局势变化
→ 势力和军团形成目标
→ 城市、县邑、组织和个人产生需求
→ 不同身份获得不同任务
→ 玩家选择参与方式
→ 任务结果改变人物、家庭、城市、经济和战争
→ 新的世界状态继续产生事件
```

任务至少有成功、部分成功、失败和放弃四类结果。任务不能只增加经验值，必须尽可能回写世界。

## 11. 武将身份与完整战争玩法

战争是武将身份的完整主玩法，不只是事件或后台结算。参考三国志系列保留以下核心内容：

- 大地图行军、道路和补给线
- 城市、县城、关隘、港口和营寨争夺
- 兵力、士气、军粮、装备、兵种和训练
- 军团编制、将领搭配和部队职责
- 地形、天气、阵形、计略和战法
- 野战、攻城、守城、关战和水战
- 伤亡、俘虏、撤退、追击和战后处置
- 太守、都督和君主层级的战略命令

玩家的战争控制权随军职变化：

| 军职 | 主要战争体验 |
|---|---|
| 乡勇/士卒 | 执行局部命令、求生、立功和保护袍泽 |
| 队率/军侯 | 指挥小队、完成战术目标 |
| 校尉 | 管理一支部队的编制、训练和作战 |
| 将军 | 指挥多部队，决定布阵、目标和战法 |
| 太守 | 组织城防、征兵、军需和地方战役 |
| 都督 | 制定军团战略、调动多城兵力和补给 |
| 君主 | 决定全国战争目标、联盟和总体资源分配 |

战争仍分为三种运行方式：

1. **世界自动结算**：玩家未参与的远方战争。
2. **职责式参战**：低级军人或其他身份完成局部任务。
3. **完整战术指挥**：拥有指挥权时进入三国志式战争玩法。

商人、医者、工匠、密探等身份可以影响战争，却不会因此自动获得军事指挥权。例如商人负责军需，
医者负责伤兵，工匠负责器械，密探负责情报；只有取得相应军职后，玩家才进入完整指挥玩法。

## 12. 成功、失败与结局

### 个人结局

名将、名臣、名士、豪商、豪侠、名医、名匠、宗教领袖、隐士或平凡善终。

### 家族结局

皇族、权门、将门、世家、商族、医家、工匠世家、地方豪族、侠义门庭、隐逸家族、
家道中落、流散或断绝。

### 世界结局

历史统一、提前统一、长期割据、异族政权崛起、地方联盟或玩家家族建立新政权。

失败不是只有死亡。破产、被流放、家族分裂、事业失传和政治清算都可能成为新的传承起点。

## 13. 开发阶段

### 第一阶段：证明核心循环

- 时间：180—200年
- 地图：24座主要城市及附属节点
- 身份：军人、官吏、商人
- 系统：世界演算、任务、家庭、继承、贸易和简化战争

### 第二阶段：丰富个人道路

- 加入侠士、医者
- 加入同道、私兵、疫病和个人根据地
- 时间扩展至220年

### 第三阶段：形成家族社会

- 加入世家、农户和工匠
- 完整家族AI、产业、联姻和多代继承
- 完成135—260年重点历史人物与事件内容

### 第四阶段：完成东汉社会

- 加入宗教人士和密探
- 时间前推至135年
- 完整党锢、民间宗教、边疆动乱和黄巾起义前史
- 加入260年后的开放历史延续、生成角色和动态政权事件

## 14. 最小可玩原型

首个原型采用：

- 时间：184年黄巾起义前后两年
- 地区：幽州南部与冀州北部
- 地点：蓟、涿县、广宗等城市和附属聚落
- 身份：乡勇、县吏、行商
- 家庭：配偶、子女或一名可培养继承人
- 核心事件：募兵、粮价波动、黄巾传播、地方治安和桃园结义变体

验收目标：

> 三种身份能以不同方式介入同一场危机；第一代角色的选择能改变家庭处境、地方状态和后续历史事件。
