# 05 城防模型报告

- 城防网络：3（大城1、南北宫城2）；大城失守不自动摧毁宫城。
- 城垣Facility：130；字段含高度、厚度、材质、最大/当前耐久、具体守军Person和 `WallState`。
- 城门Facility：14；十二大城门均具Owner、Controller、开闭、耐久、小时通行容量和守军；另有宫门。
- 护城壕Feature：80；`Flooded` 阻止普通移动，须桥、填壕或受控门路。
- `Intact/Damaged` 城墙阻止Force；云梯有效高度达到墙高才可越墙；耐久归零转为 `Breached` 并产生可通行交叉点。
- V0不含完整冲车、投石机、地道、火攻、攻城后勤；这些按任务边界延期，不能标成已实现。
